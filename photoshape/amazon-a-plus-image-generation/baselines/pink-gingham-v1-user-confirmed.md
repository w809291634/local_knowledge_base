# 粉色格子墙纸：已确认基线 V1

## 确认状态

- 确认日期：2026-10-16
- 用户反馈：粉色效果基本 OK，可作为后续同款粉色场景图的基线。
- 保留约束：不得出现左下或边角的紫色阴影；如果新场景或新视角发生色偏，先回到本色卡和母版重新校验。

## 颜色唯一标准

颜色从原始高分辨率粉色格子 TIF 母版的纯色中心区域提取。母版含嵌入式 ICC；后续制作须以该原文件为色彩权威，不可从聊天预览图或旧场景截图重新估色。

| 区域 | RGB | HEX |
|---|---:|---:|
| 白底 | (255, 255, 255) | #FFFFFF |
| 竖向粉色条 | (255, 209, 240) | #FFD1F0 |
| 横向粉色条 | (252, 209, 239) | #FCD1EF |
| 横竖交叠色 | (247, 179, 231) | #F7B3E7 |

## 花型和应用规则

1. 花型必须是白底、等宽竖条、等宽横条和明确交叠色；不是普通棋盘格。
2. 使用原始母版作为无损纹理并进行透视映射；不得让生成模型重新绘制粉色格子。
3. 格子比例以当前用户确认版本的视觉比例为准。新场景中保持同一实物尺度；如需调整，只按用户指令相对上版微调并再次确认。
4. 光线保持明亮、中性。格子区域的阴影只允许降低明度，不能产生紫色、灰色、黄色或冷暖偏色。
5. 970 × 600 的 Amazon A+ 场景图统一导出为 RGB PNG、300 DPI；交付前在无遮挡格子中心抽样验收。

## 复用方式

后续生成同款粉色效果图时，先加载本色卡和原始母版，再按 Amazon A+ 场景图 SOP 选择场景、构图与应用面。生成完成后先展示代表图并询问用户颜色、格子比例和场景是否达到预期；只有用户再次确认，才能把变更写入本基线。
