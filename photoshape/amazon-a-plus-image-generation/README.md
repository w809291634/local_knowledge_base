# Amazon A+ 墙纸场景图：严格取色与一次成图 SOP

> 用于墙纸、墙贴、柜门贴等产品的 Amazon A+ 场景图。目标是先锁定原花型与颜色，再生成场景；最终用像素数据验收，而不是凭“看起来接近”。

## 1. 今日问题与固定规则

| 发现的问题 | 根因 | 后续固定做法 |
|---|---|---|
| 蓝色、粉色视觉接近但仍被判定颜色不对 | 依据缩略图或自然语言估色，模型还会自动加入环境色 | 只能从原始 TIF 或高分辨率 JPG 取样；每款花型记录白底、竖条、横条、交叠色四组 RGB/HEX。 |
| 格子出现紫色、灰色、黄调或脏色阴影 | 模型把环境光、阴影和反射烘焙进花型 | 格子区域只允许目标色相；重点检查左下、墙角、家具遮挡边缘。严格色准时使用母版纹理映射，不让模型重绘花型。 |
| 格子尺寸忽大忽小，场景之间比例不统一 | 未记录母版的单元节距和实物尺度 | 记录白区宽、竖条宽、横条宽、完整循环宽；不同场景按同一世界比例透视映射。用户说“稍大/稍小”时，只在上版基础上微调 10%–15%。 |
| 花型糊、边缘不直 | 使用聊天预览或低清附件作为源图 | 只用母版文件；保留无损纹理后再做透视贴图，输出后检查条带边缘。 |
| 场景重复、地板露出太多、家具都横着排 | 只写“换场景”，缺少构图约束 | 先锁定六张场景、镜头距离、墙面占比、家具方向和地板材质；至少一张有人物。 |
| 成图尺寸和 DPI 不一致 | 直接使用生成器默认输出 | 最终统一导出为用户要求的像素、RGB PNG 和 300 DPI；若只要求不低于 72 DPI，仍交付 300 DPI。 |
| Windows 素材附件路径无法读取 | 误把 /C:/ 形式当成本地可读路径 | 先用真实 C:\... 路径打开，核对像素和 ICC；不要依赖失效的虚拟附件路径。 |

## 2. 开工前的花型规格卡

每款花型必须先填规格卡，缺一项不进入批量出图。

| 字段 | 必填内容 |
|---|---|
| 母版文件 | 原始 TIF 或原始高分辨率 JPG |
| 原始像素与 ICC | 宽 × 高、ICC 名称或 sRGB |
| 四色 | 白底、竖条、横条、交叠色的 RGB 与 HEX |
| 单元几何 | 白格、色带和完整循环节距的像素值及比例 |
| 应用面 | 墙面、柜门、洗衣房挡板或局部背景 |
| 输出 | 数量、像素、格式、DPI、命名规则 |
| 已确认比例版本 | 原比例 / 略小 / 略大，以及相对上一版的变更百分比 |

## 3. 严格取色流程

1. 打开原始母版，不用聊天预览图、截图或已生成场景图反推颜色。
2. 保留正确的 ICC 色彩空间，在白底、竖条、横条、交叠格的无阴影中心区域各取至少 10 × 10 px 均值。
3. 将 RGB 和 HEX 写入规格卡；提示词、纹理合成、验收全部引用同一张色卡。
4. 最终图片在无遮挡格子中心抽样。严格项目的目标误差为 ±3 RGB；阴影只可降低明度，不可把色相推向紫、灰、黄或绿。
5. 若用户说“颜色不对”，不要继续目测微调。返回原母版重新取样，更新规格卡，并同步修正整组六张图。

### 本次浅蓝格子：已验证母版色卡

| 区域 | RGB | HEX |
|---|---:|---:|
| 白底 | (255, 255, 255) | #FFFFFF |
| 竖向浅蓝条 | (219, 247, 250) | #DBF7FA |
| 横向浅蓝条 | (215, 243, 244) | #D7F3F4 |
| 横竖交叠色 | (194, 238, 237) | #C2EEED |

不要用“薄荷蓝、婴儿蓝、青蓝、更鲜艳一点”等描述替代这四个数值。每款新花型必须重新取样，不能沿用其他颜色的视觉印象。

## 4. 花型应按工程纹理处理

正确格子由白底、等宽竖条、等宽横条与明确交叠色组成，不是两种颜色交替的棋盘格。

- 条带必须平直、平行、清晰；不能有水波、手绘感、随机渐变、断裂或加粗。
- 正面墙按母版比例平铺；斜视墙和柜门要有真实透视，远端缩小但所有格线共线。
- 人物、床、窗帘、柜门边框遮挡时，格子必须连续，不能在遮挡边缘突然变形或改变大小。
- 色准要求极高时，模型只负责场景、家具和光影；墙纸/柜门面板使用母版纹理经遮罩和四点透视映射回最终图片。
- 纹理贴回后禁止整体暖色滤镜和紫色局部阴影。只允许极轻微的中性明暗层，且不能改变 HSV 色相和饱和度。

## 5. Amazon A+ 六图默认场景模板

| 序号 | 场景 | 构图与产品展示要求 |
|---|---|---|
| 01 | 儿童游戏区，含人物 | 小孩自然地坐在地毯上玩积木；墙纸是主要背景，人物不能覆盖全部花型。 |
| 02 | 儿童卧室 | 床、床头柜或单椅用轻微斜向摆放；墙面占比高，地板只保留必要前景。 |
| 03 | 学习区 | 书桌可在左或右；避免所有家具都横向居中，有留白但不空洞。 |
| 04 | 洗衣房 | 洗衣机、收纳和台面逻辑真实；墙纸用于后挡板或整面背景，整体明亮。 |
| 05 | 简约客厅 | 背景干净，沙发、单椅与茶几形成层次；装饰不喧宾夺主。 |
| 06 | 柜门翻新 | 木柜或斗柜正面/轻微透视；花型清晰贴在门板，把手、门缝和边框真实。 |

构图红线：

- 不要六张都是墙角，也不要所有家具横着排成一列。
- 镜头略拉近，墙纸或柜门才是产品；除非用户明确要求，地板不超过画面约三分之一。
- 同组至少使用两种地板或地毯材质，但保持同一产品调性。
- 人物只作为生活化辅助，须自然、安全、年龄相符。

## 7. 交付前检查清单

### 文件
- [ ] 每张为目标像素，例如 970 × 600。
- [ ] RGB PNG，DPI 不低于用户要求；默认 300 DPI。
- [ ] 命名采用 color-序号-scene-970x600.png。
- [ ] 六张图和 ZIP 均可打开，无临时稿和重复图。

### 花型
- [ ] 白底、竖条、横条、交叠色均按规格卡抽样验收；严格模式误差不超过 ±3 RGB。
- [ ] 横竖条平直，交叠关系正确，无模糊、断裂、随机渐变。
- [ ] 同场景格子尺度连续；柜门两扇之间不因门缝产生不合理跳变。
- [ ] 左下、边角、家具后方无紫色、粉灰或脏色阴影。

### 场景
- [ ] 六张场景和家具摆放不同，人物只在指定图出现。
- [ ] 墙纸是核心展示对象，地板和装饰不过度抢画面。
- [ ] 洗衣房、柜门等应用面符合真实结构与透视。

## 8. 最小交付物

1. 六张最终 PNG；
2. 一个 ZIP；
3. 一张可追溯的花型规格卡，含母版、四色、比例、输出规格和版本；
4. 用户确认后，将该版本作为同款花型后续全部场景图的唯一颜色与比例基线。
