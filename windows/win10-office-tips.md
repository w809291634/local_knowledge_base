# Windows 10 系统与 Office 使用技巧合集（更新/Defender/用户名/自启/Word）

> 适用：Windows 10 + Office 2013 时代环境（部分方法对 Win11 仍有效）
> 来源：《问题解决和汇总 v1.2》"window / word文档"章节
> 目标：系统维护与 Office 卡顿的处置清单；改注册表前建议备份或建还原点。

## 结论先行

- 阻止 Win10 自动更新要**四种机制一起关**（服务/任务计划/组策略/设置），只关一种会被另一种拉起来。
- Word 卡、慢、存不上，三板斧：**禁用硬件图形加速、关后台保存/自动保存、校对全关**。

## 1. 关闭 Windows 自动更新（四法并用）

1. **服务**：`services.msc` → Windows Update → 停止并禁用，**"恢复"选项卡里第一次/第二次/后续失败全设"无操作"**（否则会被拉起）；
2. **任务计划**：`taskschd.msc` → 任务计划程序库→Microsoft→Windows→WindowsUpdate，全部禁用；
3. **组策略**（专业版）：`gpedit.msc` → 计算机配置→管理模板→Windows组件→Windows更新→"配置自动更新"=已禁用（只想不自动重启可选"已启用+自动下载并通知安装"）；用户配置→管理模板→系统→Windows自动更新也一并禁用；
4. **设置**：更新和安全→高级选项，关掉更新选项。
   关机菜单若出现"安装更新并重启"，回到设置里更新报错后即不再显示。

## 2. 关闭 Windows Defender

- 设置：更新和安全→Windows 安全中心→病毒和威胁防护→管理设置→关实时保护/云保护/自动提交样本；
- 组策略：`gpedit.msc` → 计算机配置→管理模板→Windows组件→Windows Defender 防病毒程序→"关闭 Windows Defender 防病毒程序"=已启用；
- 注册表：`HKLM\SOFTWARE\Policies\Microsoft\Windows Defender` 新建 DWORD `DisableAntiSpyware=1`。
  注意关闭后的安全风险，装好第三方杀软再关。

## 3. 修改用户名（C:\Users 目录名）全流程

1. 注销（Alt+F4 选注销），用 **Administrator** 登录；
2. 改 `C:\Users\<旧名>` 目录名。若提示"文件夹在另一程序中打开"：重启后再用 Administrator 进；退出电脑管家/360 后台；任务管理器→性能→资源监视器→CPU→搜用户名，结束占用进程；
3. **注册表** `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList` 下找到对应用户 SID，改 `ProfileImagePath`；
4. 注销切回原用户，**同步修改环境变量**里指向旧路径的项（默认装 C 盘用户目录的软件都会失效）；
5. 计算机管理里可改账户显示名。msys32/mingw 终端用户名为中文的问题，同样靠把管理名称改英文解决。

## 4. 任务计划自启动程序

- 任务计划程序→创建基本任务→触发器选登录时→操作指向程序；
- **两个坑**：① 要"使用最高权限"运行，否则启动不完整；② 必须填"**起始于**"路径（程序所在目录），否则依赖相对路径/配置文件的软件（如 FastGithub.UI）启动后卡死不正常。

## 5. 内置应用打不开（"无法使用内置管理员账户打开"）

`gpedit.msc`（或 `secpol.msc`）→ 计算机配置→Windows设置→安全设置→本地策略→安全选项，启用三项后重启：
- 用户账户控制：用于内置管理员账户的管理员批准模式
- 以管理员批准模式运行所有管理员
- 账户：管理员账户状态

## 6. 浏览器/证书类

- **"您的连接不是私密连接"**：点"不安全"查看证书，发现是本机某软件劫持——本例是卸载破解版 VMware player 后恢复正常（夸克/Chrome 同理）；
- 虚拟机里火狐访问 github 图片不显示：F12 看被拦资源，接受风险或换网络；
- **"您的组织策略阻止"（默认浏览器改不了）**：注册表 `HKCU\SOFTWARE\Classes\.html` 的"（默认）"数据改成 `Htmlfile`（试 htmlFile/htmlfile 变体），重启生效。

## 7. 系统杂项

| 问题 | 修法 |
|---|---|
| 跳过开机硬盘自检 | 注册表 `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager` 的 `BootExecute` 数值清空 |
| Alt+Tab 切换样式 | `HKCU\...\Explorer` 新建 DWORD `AltTabSettings`：1=Win7 样式，2=Win10 样式，重启 |
| 自动关机排查 | 看系统日志定位触发源；再查 Intel 能源管理设备/更新 BIOS/用联想官网驱动（不用助手） |
| 打开文件夹慢 | 文件夹选项→查看→勾选"始终显示图标，从不显示缩略图" |
| 一键进屏保 | `C:\Windows\System32` 搜 `.src` 文件，建快捷方式 |
| 桌面快捷方式箭头变空白方块 | `HKLM\...\Explorer\Shell Icons` 的字符串值 `29` 留空/删除可恢复箭头（该键存在即隐藏箭头） |
| `vcruntime140.dll` 缺失 | 电脑管家/360 的"微软 VC++ 运行库合集"安装；装了 2017 后 2015 可能装不上（正常）；VMware 安装也需要运行库 |
| 护眼色 | 显示设置→高级显示设置→颜色校准，一路下一步并适当减少蓝色色调后保存 |
| parsec 远控 Alt+Tab 失效 | `Ctrl+Shift+I` 进入沉浸模式锁定被控端后即可切换 |
| 沙拉查词浏览器外可用 | 扩展设置开"后台保持运行"；Chrome 设置搜 background/后台保持勾选；或用 quicker 全局唤起 |

## 8. Word / Office

| 问题 | 修法 |
|---|---|
| 无法撤销 | 注册表 `HKCU\Software\Microsoft\Office\15.0\Word\Options` 新建 DWORD `UndoHistory`=20（十进制）重启 |
| 用电池时很卡 / 编辑卡顿 | 文件→选项→高级→勾选"禁用硬件图形加速" |
| 保存很慢 | ① 禁用硬件加速；② 虚拟机别把全部 CPU 分给客户机；③ 关后台保存；④ 关自动保存 |
| 编辑卡顿 | 校对选项全部关闭 + 关自动保存 + 禁硬件加速 |
| Tab 键总出现制表符 | 没用首行缩进：中文排版用首行缩进代替 Tab |
| 保存时闪退（特定字符） | 关闭自动更正中的"英文日期第一个字母大写"类选项（原文：关闭英文字母大写） |
| 项目符号降级/升级 | 项目符号行尾再按一次回车即回到上一级（一级标题） |
