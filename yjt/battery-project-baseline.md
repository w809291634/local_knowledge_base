# 电池类项目功能基线（必备项）

> 适用：后续所有带电池的新项目
> 来源：用户要求（2026-11-21）
> 性质：立项/方案评审的必备检查项，不替代具体产品需求

## 必备功能

### 1. 补电功能

- 充满后电池电压下降到设定阈值时，必须能自动恢复充电。
- 补电必须可重复，不能只充一次。
- 硬件充电管理或软件逻辑实现均可，但必须可验证。

方案评审需明确：补电触发条件、回差、状态显示。

### 2. 熄屏二级显示

- 主屏熄灭后，必须有二级显示继续展示关键状态。
- 二级显示的内容、器件、亮度/功耗、熄屏条件在方案评审中明确。

## 评审检查

- [ ] 补电功能已实现并验证
- [ ] 熄屏二级显示已实现并验证
- [ ] 缺项已说明理由并记录

## 说明

- 本条只约束后续新项目，现有项目不自动追溯。
