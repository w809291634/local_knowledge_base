## 5. 模板自身缺陷（交付前要处理）

1. **2 个空段挂 `outlineLvl`**（p290、p535）→ 删除或降级为 `outlineLvl=9`；两者都**不是**分节符所在段，可安全处理，但仍要先确认。
2. `OL0` 60 段里含大量正文小节（`1.2 预期适应症` 等），标题树粒度不均。
3. 红字 36 run 是编写指引 → 转黑，文字不删。
4. T10 与 T18 同一问卷两种措辞 → 按注册人口径统一。
