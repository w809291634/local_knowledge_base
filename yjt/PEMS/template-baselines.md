## 2. 与模板的关系（注册人 2026-10-24 定）

- **章节标题的文字必须与模板逐字一致**：章名、小节名、编号形态、点线目录条目文字都照模板，不改写、不增删、不换说法。
- **导航树（`outlineLvl`）不必照模板**：模板的大纲级别常常是错的（漏挂、空段挂级、正文段挂级），以正确性为准重建。
- **模板里可作通用描述的正文保留原句**（方法句、目的句、范围句式、术语条目结构）；只有项目事实才替换。
- **字体一律按字体基线统一**：模板自带的混排（雅黑章标题、楷体正文、黑体目录条目、同级一半 Times 一半宋体）
  视为**模板错误**，不再"按模板原样保留"。唯一例外：Symbol/Wingdings 私用区 run（改了变方块，见 `font-and-style-normalization.md` §9）。

**族级判据（各清单不再重复写）**

1. 标题序列比对：基线件标题序列与交付稿逐条等值；不等只允许出现在注册人点名处，并写进版本说明。
2. 非基线字体 run 计数 = 0（排除私用区 run）；同级标题字体唯一。
3. 大纲树：空段不挂 `outlineLvl`、正文段不挂标题样式、编号标题全部入树。
4. 通用正文保留：基线件里的通用句在交付稿中逐字命中 ≥1。

第 1、2 条已封装为原语，直接调用不要另写：`tools/docx_ops.py:heading_text_sequence` /
`check_heading_text_against_template` / `non_baseline_font_runs`。抽取已排除目录条目、点线式静态目录与含软回车的多句正文；
比对报差异时先人工确认标题集合，再决定是不是真差异。

## 3. 其余通用口径

- **页数判据要写明测量程序**：同一份文档 WPS、Word、LibreOffice 分页可差 1 页（RD-057 43/42，RD-068 5/6，RD-028 2/3）。
  闸门里比较页数时，必须固定用同一程序，并把程序名写进证据。
- **结构判据一律按主通道（WPS 转出稿）测量**，LibreOffice 稿的数字会系统性偏小或偏大，不能混用：
  RD-030 正文级段落 280（LO 257）、`toc` 样式条目 21（LO 判成 0）、`numPr` 4（LO 5）；
  RD-029 段落 214（LO 213）、红字 1（LO 2）；RD-028 封面大标题无 `numPr`（LO 多挂 1 个）、7pt run 19（LO 26）。
- **同版号的"属性漂移"也要登记**：模板可能在版号不变的情况下被改过分页/大纲属性
  （RD-057 实测：内容残留一字未变，但 `pageBreakBefore` 96→0、`outlineLvl=0` 77→60、`numPr` 159→134、红字 30→36）。
  发现漂移先做"内容 vs 属性"二分对照，再决定是重做基线件还是只更新判据；两版哈希与差异都写进档案的"版本历史"节。
  不登记的话，下一轮会按旧属性判据把正常文档报成缺陷。
- **基线件入库判定分两档**：模板原件必须**零项目残留**才可作为"空白基线件"直接复制进 `templates/<版号>/`。
  有残留的（残留包括正文段、表格值、页眉页脚、形状与文本框内文字、内嵌图片）也可以入库，
  但要按 `generality-boundaries-and-precedence.md` §二的例外条款登记为**格式档案**：档案里逐处列出残留位置、计数与生成时的处理方式，
  并声明"不提供任何新项目事实、不得当空白模板批量生成"。两档都要登记 SHA-256 与来源原件哈希。
- **旧版档案只在版号不同时建**：旧稿页眉版号与当前模板一致的，旧稿就是当前模板的项目实例，不另建旧版档案；
  版号不同的（026、032、057）才需要旧版档案做历史稿对账。

## 4. 建档方法（每份同法）

1. 通道：`.doc` 用 WPS 转 docx 作主通道，LibreOffice 只交叉核对（`pitfalls.md` §1）。
2. 普查：节数与方向、页边距、页眉页脚域、目录形态、表格行列与列宽、内嵌图与形状、字体字号行距分布、
   大纲级别与 `numPr`、红字 run、残留词表。
3. 登记：写进 `template-baseline-rdXXX-<版号>.md`，每条都要能被脚本反查。
4. 判定残留：零残留才复制基线件进 `templates/<版号>/` 并登记 SHA-256。
5. 验收：跑该版档案 §闸门判据 + 渲染 + Word 只读打开。
