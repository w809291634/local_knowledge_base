# 04KF006R2507 PEMS 参考模板格式要求

## 使用范围

本档案仅描述 `Docu_Pems/pems文档` 中 9 份参考模板的版式要求，不提供任何产品型号、功能、参数、测试结论或项目事实。模板内容中的其他项目名称、功能、图片和结果不能继承到当前项目。

## 全部模板共用要求

- 纸张：A4，纵向；多数模板页边距为上/下/左/右 2.50 cm，但 RD-057、RD-068、RD-069 使用不同页边距，必须原样继承；
- 封面：首页为独立页，包含大标题、文控页眉、6 行 × 4 列封面信息表；
- 封面表字段：文件编号、项目名称、项目编号、编制/日期、审核/日期、批准/日期；仅更新允许的值单元格，保留行列、合并关系、边框、对齐与签署栏；
- 页眉：保留 `QR/RD/xxx` 与受控版本号的模板格式；项目编号和版本如属于可控槽位，必须全套文档同步更新；
- 目录：保留目录域、目录标题、章节顺序和页码机制；不合并或重写含 PAGEREF、TOC、页码等域代码的段落；
- 正文：保留原有章节级别、自动编号、直接格式、表格边框、图题、页码和分节；
- 图与文本框：每次必须视觉检查图内文字、模块名、接口名、箭头和图题；仅替换正文文字不等于图文已更新；
- 结果和签署：草稿或待执行版留空；不得复制模板的测试通过、姓名、日期、评分或结论。

## 各文档格式基线

| 文档 | 参考页数/分节 | 封面后结构 | 表格与版式要求 |
|---|---:|---|---|
| RD-026 | 3 页 / 2 节 | 封面、目录、确认计划正文 | 封面表 6×4；确认条款表 13×4；保留测试分组与表头 |
| RD-028 | 2 页 / 2 节 | 封面、体系构架正文与架构图 | 封面表 6×4；架构图为项目化内容，图框、箭头和图题需重新核图 |
| RD-029 | 12 页 / 3 节 | 封面、章节目录、需求正文 | 封面表 6×4；后续保留 2 列、6 列、5 列等功能/环境/测试表的列结构 |
| RD-030 | 15 页 / 4 节 | 封面、前言、目录、详细设计正文 | 封面表 6×4；保留前言样式、目录层级、流程图位置和 6 列功能表结构 |
| RD-032 | 3 页 / 2 节 | 封面、目录、确认过程/范围/方法/记录/结论 | 封面表 6×4；确认记录表 13×4；结果栏不得预填模板结论 |
| RD-052 | 25 页 / 3 节 | 封面、目录、基本信息、实现过程、算法、软件版本 | 封面表 6×4；15 张表、多个关系图与流程图；不得缩减为无依据的简短通用说明 |
| RD-057 | 11 页 / 1 节 | 封面、可用性规范、使用情景、验证和统计结论 | 页边距与其他模板不同；封面表 6×4；2 张 11 列统计表和 2 张 4 列用例表必须保留结构，实测数据留空直到取得证据 |
| RD-068 | 7 页 / 2 节 | 封面、目录、验证方法与验证计划 | 封面表 6×4；3 张三列验证计划表，计划条款与需求/设计追溯一致 |
| RD-069 | 7 页 / 3 节 | 封面、目录、验证记录与结论 | 封面表 6×4；3 张四列结果表；实际结果、异常和结论只能来自受控证据 |

参考页数只用于检测明显的空白页、章节缺失或异常压缩；项目实际内容变化后页数可以变化，但必须保持目录、分页、表格和图文的逻辑完整。

## 模板继承操作要求

1. 先记录模板文件名、版本、SHA-256、页数、分节、页边距、页眉页脚、表格索引及图清单。
2. 创建新版本输出目录，复制模板后原位更新已登记槽位；禁止从空白文档重新拼封面、目录和页眉。
3. 段落替换必须按整段内容处理，保留 `pPr`/`rPr`；含域代码、图片、文本框和分节符的段落不得用简单 run 合并。
4. 表格仅在已确认的可增删行区域修改；不得改变封面表、统计表、记录表的列数、合并关系、边框、宽度和表头层级。
5. 正文扩充优先使用模板已有的章节、段落和表格样式；新增内容必须克隆同类结构，不引入未批准的颜色、字体、页边距或通用自建表格风格。
6. 生成后检查全部页面，重点检查封面独立页、封面后空白页、目录页码、跨页表格、图中文字、页眉页脚和签署栏。

## 当前项目的格式选择原则

- 缺失 RD-032、RD-052、RD-057 时，必须直接继承这三份对应参考模板，不能使用其他 RD 文档或自建蓝色/彩色表格替代；
- 原有 RD-026、RD-028、RD-029、RD-030、RD-068、RD-069 应在原项目文档基础上进行最小槽位替换，避免破坏历史封面和分节；
- 参考模板中的产品事实、测试结果、适用范围、图中文字、参与者信息及结论一律不是当前项目事实，需由 `facts.yaml` 和受控证据重新提供。
