# PEMS 通用模板格式档案模板

## 使用说明

本文件是每个新项目建立模板格式档案时使用的空白文字模板。填写后的项目化档案只能保存在该项目工作目录或受控参考目录，不写入通用经验库。

## 1. 模板身份

- 模板文件名：
- 模板 SHA-256：
- 文档类型/编号：
- 适用项目状态：草稿 / 待执行 / 待审核 / 受控发布：
- 参考页数（仅用于异常检测）：
- 分节数量与页面方向：

## 2. 页面和文控格式

- 页面尺寸、页边距、页眉/页脚距离：
- 首页是否独立成页：
- 封面标题的位置、字体、字号和对齐：
- 页眉、页脚、页码和修订记录的位置：
- 目录类型：自动目录域 / 静态目录 / 无目录：
- 目录刷新方式和复核方式：

## 3. 封面信息表

- 封面表索引、行数、列数及合并关系：
- 可替换字段：文件编号、项目名称、项目编号、软件名称、型号、版本：
- 必须留空字段：编制、审核、批准、日期、测试人、测试时间、结果：
- 不可改动字段：表格定位、边框、单元格尺寸、签署栏、文控标识：

## 6. 生成与发布限制

- 模板只读；
- 输出必须是新版本目录；
- 未命中槽位、旧项目残留、缺少必备图示、无证据的实际结论均阻断发布；
- 生成后必须全页渲染、逐图核验并归档模板哈希、事实快照、输出哈希和检查报告。
