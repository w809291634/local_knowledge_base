# PEMS 通用性边界与规则优先级

## 规则目标

本规则用于确保 PEMS 经验库可跨产品、跨型号、跨芯片、跨软件形态和跨 Word 模板复用。经验库提供流程、结构、检查方法和工具原语，不提供任何新项目的事实、结论或强制技术方案。

## 一、规则优先级

1. 法规要求、质量体系程序、已批准模板和当前项目受控变更；
2. 当前项目事实基线与证据索引；
3. 当前项目源码、硬件/BOM、技术要求、说明书、风险文件和受控测试证据；
4. 通用 PEMS 方法、格式档案和工具规则；
5. 历史项目、案例、示例表格和参考文档。

后层不能覆盖前层。发现冲突时，停止自动写入冲突字段，建立待办并要求确定权威来源。

## 二、通用规则不得包含的内容

以下内容只能出现在项目事实基线、受控模板或明确标注的案例中，不能作为所有项目的通用默认值：

- 产品名称、项目编号、型号、制造商、地址、波长、量程、精度、阈值、功率、时间、版本号、哈希值；
- 芯片、操作系统、开发工具、架构模式、通信协议、联网方式、语音/显示/存储能力；
- 软件安全性等级、适用标准、法规清单、预期用途、禁忌证、风险等级和控制结论；
- 测试人员、受试者数量、日期、通过率、缺陷数量、签署信息、实际结果和最终结论；
- 某个项目的图数量、表格行数、页数、图号、章节正文和案例经验。

项目参考文件可以展示这些内容，但必须在文件名、首段或目录中标注为“案例/格式档案”，并声明不提供新项目事实。

## 三、事实来源按类别判定

不同类型的陈述应追溯到相应证据，而不是机械要求全部来自代码：

| 陈述类型 | 优先证据 |
|---|---|
| 型号、配置、用途、适用范围、技术指标 | 产品技术要求、受控说明书、型号差异表、设计输入 |
| 软件状态机、按键、时间、通信、显示、异常处理 | 当前受控源码、接口定义、构建配置、台架测试 |
| 波长、光学/电气性能、机械尺寸、供电和附件 | 图纸、BOM、技术要求、检验/型式试验记录 |
| 软件版本、哈希、发布状态 | 受控版本库、构建记录、发布清单、软件命名规则 |
| 风险、残余风险、可用性和临床相关结论 | 风险管理文件、可用性研究、临床评价、批准记录 |
| 实际测试结果和签署 | 原始测试记录、样机编号、执行人、日期、审核批准记录 |

代码可证明“实现了什么”，不能单独证明物理性能、临床效果、法规符合性或实际测试通过。

## 四、文档状态与证据边界

- 草稿：可生成结构、需求、设计、测试计划和空白记录栏；不填实际结论和签署；
- 待执行：仅在受控结果/状态栏使用批准的状态词；正文不写过程性提示；
- 待审核：已有执行证据，等待审核；
- 受控发布：有完整原始记录、审核/批准和版本归档后方可填写最终通过结论。

不得因为模板含有“通过”“OK”“符合要求”或样例姓名而继承这些内容。

## 五、模板与参考文件的使用边界

1. 模板用于封面、目录、页眉页脚、分节、表格结构、标题层级和图示位置。
2. 案例用于理解文档深度、追溯关系和常见风险，不用于复制项目事实。
3. 格式档案记录某一模板的结构特征；它不是所有项目都必须使用的页数或章节内容。
4. 当前项目模板的格式要求应放在项目目录或 `reference_profiles/` 中；通用经验库只保留提取方法和通用约束。
5. 新项目至少需要一个适用模板、一个事实基线、一个证据索引和一个槽位清单，缺少任一项不得批量生成正式资料。

## 六、图示的通用强制规则

图示是否需要由当前项目的软件系统、模板章节和追溯关系决定。下列情形必须有当前项目图示：

- 体系架构章节：软件体系架构图；
- 存在多模块、通信、外部接口或执行输出：模块关系/拓扑图；
- 存在状态切换、关键控制、自动处理或异常恢复：流程图或状态图；
- 有生命周期、配置、验证或变更过程要求：相应过程图；
- 有关键用户任务或高使用风险：任务流程图或界面示意图。

每张图必须有图题、正文引用、事实来源、当前项目模块/接口名称和最终页面渲染核验记录。无依据时不能用其他项目的图替代；应阻断该章节发布并列入待办。

## 七、通用工具要求

- 事实配置可采用 `facts.yaml`、`facts.json` 或受控 `config.json`，但每个项目只能指定一个主事实文件；
- 生成器必须校验配置 Schema、槽位命中、残留词、文件范围、模板哈希和输出目录版本；
- 一致性检查必须按文档范围/型号范围判断，不能要求所有文档拥有相同型号集合；
- 差异、缺失或残留必须返回非零状态；
- `.doc` 转换副本、PDF、PNG 和临时文件只能写入工作临时目录；
- 渲染工具使用隔离配置或只读 Word 导出，不能终止用户正在使用的进程；
- 发布归档必须包含事实快照、证据索引、模板/产物哈希、检查报告和变更清单。
