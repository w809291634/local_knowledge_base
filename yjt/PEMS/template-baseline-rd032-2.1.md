# 公司模板 2.1 版式基线：RD-032 软件确认报告

> 只描述 **2.1**。1.0 口径另见 `template-baseline-rd032-1.0.md`，两套判据不得互用。族总表见 `template-baselines.md`。

## 1. 身份

| 项 | 值 |
|---|---|
| 页眉原值 | `QR/RD/032   2.1`（两节同文） |
| 页数 | WPS 5 页／Word 5 页 |
| 分节 | 2 节，均 A4 竖排，边距 2.50 四边 |
| 目录 | 形态 D：无 TOC 指令、无目录样式段 |
| 页脚 | `footer1/2` 含 `PAGE` + `NUMPAGES \* ARABIC`，`footer3` 空 |
| 段落 | 正文级 90，非空 48，空段 42 |
| 表格 | 6 张：封面 6×4（值空）；用例表 12×8（用例编号/预期结果/执行步骤/实际结果/测试者/Bug/质量特征/测试日期）；阶段表 5×4 与 3×4（用例编号/阶段名称/描述/测试结果）；结论表 4×3（序号/测试功能或项目名称/是否通过）与 7×4（多「测试结果」列） |
| 图形 | 无图片、无形状 |

## 2. 版式要点

- 封面大标题「软件确认报告」宋体 36pt 加粗居中，`outlineLvl=0` + `numPr`。
- 小节名是手写编号文字（`1.1 目的：`、`1.5.1硬件环境`、`6.4 测试结论：`），全部 `Normal` 样式，无标题样式。
- **编号跳号**：可见 1.x、2.x、6.x，缺 3/4/5 级标题；另有两条 `2.1 用移动端软件（微信小程序）` 与带 `numPr` 的 `2.1移动端软件` **同名并存**（`pitfalls.md` 的"同名不同号"形态）。
- `outlineLvl=0` 挂了 2 段：封面大标题 + 一段正文（`鼻炎光疗仪：作用机理…`）——模板自身的大纲异常，交付前要降级。
- 字体混排：`微软雅黑` 13 个 run（集中在第 2 章，LibreOffice 稿会报 20），其余宋体；行距 `288`（单倍）15 段、`None` 31 段；首行缩进取值有 `0/200/250/374`。
- 带 `numPr` 的段落 2 个（WPS 稿；LibreOffice 稿多报 2 个），就是上面那对重复的 2.1／2.2 小节。

## 3. 模板自带的旧项目内容（必须替换）

`鼻炎光疗仪` 作用机理段（×6）、`650nm` 激光参数（×2）、`微信小程序`（×7）、`蓝牙`（×18）——
整段属于上一项目的确认对象描述，换项目时必须按当前产品重写，不能沿用句式里的波长与通路名。

## 4. 槽位与生成口径

- 只填封面表三值 + 各表实际结果；「实际结果」「是否通过」「测试者」「测试日期」没有受控原始记录就留空。
- 不补目录（形态 D）。
- 交付前必做三件：清 §3 残留计数为 0、把误挂 `outlineLvl=0` 的正文段降级、合并同名双写的 2.1/2.2 小节。

## 5. 闸门判据（可脚本反查）

分节 2、页眉 `QR/RD/032   2.1`、TOC 指令 0、页脚含 `PAGE`+`NUMPAGES`、表格 `[[6,4],[12,8],[5,4],[3,4],[4,3],[7,4]]`、
正文级段落 90、非空 48、`outlineLvl=0` 段数改后为 1、残留词 `鼻炎/650nm/微信/蓝牙` 计数 0、无"同名不同号"小节。

## 6. 基线件不入库

模板自带旧项目正文（鼻炎光疗仪、650nm、微信小程序） → 不满足零残留判定，基线件留在项目目录。
