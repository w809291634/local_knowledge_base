# 公司模板 1.0 版式基线：RD-057 可用性报告

> 只描述 **1.0**，用于历史交付稿对账。当前模板是 3.0，见 `template-baseline-rd057-3.0.md`；两套判据不得互用。

## 1. 身份

| 项 | 值 |
|---|---|
| 页眉原值 | `QR/RD/057  1.0` |
| 分节 | **1 节**，A4 竖排，边距 上1.60/下1.85/左1.50/右1.50 cm（与 3.0 的 2.50 四边完全不同） |
| 目录 | 形态 D：无 TOC 指令、无 `toc` 样式段 |
| 页脚 | 单页脚含 `PAGE` + `NUMPAGES \* ARABIC` |
| 段落 | 正文级 267，非空 239，空段 28 |
| 表格 | 5 张：封面 6×4；两张 9×11 场景评价表（正常使用场景／最坏情况场景，列宽 1021/1005/737/921×7/922×2/927）；两张 9×4 用例表（测试用例/检查/合格标准/结果） |
| 大纲 | `outlineLvl=0` 3 段；`numPr` 184 段（编号主要靠自动编号） |

## 2. 版式要点

- 标题用 `Heading 2/3/4` 样式，正文用 `列表段落1` 与 `Normal`。
- 字体最杂：样式默认 322、`Arial` 15、`宋体;SimSun` 11、`Times New Roman` 9 混排；字号绝大多数走样式默认，11pt 与 36pt 少量。
- 行距基本不显式写（235/239 段为 `None`）。
- 1.0 是**单份报告**，不是 3.0 的五合一；两张 9×11 场景表是它的评价记录主体。

## 3. 生成与验收

- 只在核对 1.0 历史稿时使用本节；新项目一律按 3.0。
- 判据（可脚本反查）：分节 1、边距 1.60/1.85/1.50/1.50、页眉含 `1.0`、TOC 指令 0、表格 `[[6,4],[9,11],[9,11],[9,4],[9,4]]`、
  正文级段落 267、`numPr` 段数 184。
- 参考件是已填写的历史项目产物（含项目名、型号、场景内容），按通用性边界不入库，位置记在项目目录。
