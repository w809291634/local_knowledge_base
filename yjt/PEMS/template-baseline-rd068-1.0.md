## 2. 版式档

- 封面大标题 p2「软件验证计划」宋体 36pt 加粗居中，`outlineLvl=0`，**无 `numPr`**。
- 目录标题 p24「目录」黑体 16pt 居中；条目 `toc 1` 样式，西文 `Times New Roman`、中文走默认，`line=360 auto`。
- 四个一级章 p58/p61/p65/p68：`软件验证和确认过程的描述`／`测试的目的和范围`／`测试方法`／`验证计划`，
  14pt、`outlineLvl=0` + `numPr`；p58/p61 的西文字体是 `Times New Roman`，p65/p68 是宋体 → **同级标题西文字体不统一**。
- 正文 12pt；p59 首行缩进 `firstLine=480`+`firstLineChars=200`，p63 `line=219 auto`，其余多不写 `spacing`。
- **p66「采用白盒测试方法」挂的是 `Figure` 样式**（`ind` 四项全 0）—— 正文段挂图形样式，
  属"文字正文·样式非正文"一类（`pitfalls.md` §67 的同类），会被正文基线判据与图题判据双双放过。
- 样式集：`Body Text`、`Default`、`Figure`、`Normal`、`toc 1`。

## 4. 生成与验收口径

- 只填封面表三值；三张记录表的用例按当前产品重写，「测试人员」「测试时间」无受控记录留空。
- 不补第二份页眉页脚部件，但**两节的页眉页脚都要各自核对**（部件不链接）。
- 页脚保持只有 `PAGE`，不要按 026/2.1 的习惯补 `NUMPAGES`。
- 四个章标题的 `numPr` 自动编号保留；同级西文字体要么统一 `Times New Roman`，要么统一宋体，别一半一半。
- p66 的 `Figure` 样式要降回正文样式再改内容。
