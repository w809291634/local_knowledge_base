# 人员花名册（私有，不入库）

本目录存放各注册人/生产企业的员工花名册，含身份证号、住址、电话等敏感信息。
`yjt/PEMS/personnel_rosters/` 已加入 `.gitignore`，不得提交到通用经验库，也不得把姓名、身份证号等写入交付文档或经验库正文。

## 目录与版本规则

```
personnel_rosters/
  普莱/     员工花名册-普莱-YYYYMMDD.xlsx
  泽生康/   泽生康花名册-YYYYMMDD.xlsx
  益健堂/   益健堂花名册-YYYYMMDD.xls
  INDEX.md  当前版本、历史版本、哈希
```

1. **按单位分目录**，一个单位一个目录。
2. **文件名带日期版本**：`<单位>花名册-YYYYMMDD.<ext>`；日期取花名册版本日期，不取收到日期。只有年月时用 `YYYYMM`，不补造日。
3. **新版本另存新文件，绝不覆盖旧版**；旧版保留在同一目录，状态改为“历史”。
4. 每次新增或替换后更新 `INDEX.md`：登记当前版本、历史版本、SHA-256、状态。
5. 选人时只提取「姓名｜部门｜职位」，不复制身份证号、住址、电话。
6. 每次使用最新已确认版本，并在项目事实文件/manifest 登记 `personnel_version`、`personnel_date`。
7. 人员有变动时，重新生成五类职责候选名单交注册人确认，确认后才改文档。

## 使用流程

1. 按项目注册人/生产企业匹配对应目录。
2. 从 `INDEX.md` 找当前版本，核对 SHA-256。
3. 只提取「姓名｜部门｜职位」三列。
4. 先按五类职责生成候选名单：需求与设计、软件编程、黑盒测试、白盒测试、风险管理。
5. 候选名单交注册人确认；确认后才写入 RD-052 人员表、RD-032 测试组、RD-026/068/069 签署行及封面签署。
6. 花名册没有对应岗位时标注「缺」并请注册人指定，不得用其他岗位硬套。
