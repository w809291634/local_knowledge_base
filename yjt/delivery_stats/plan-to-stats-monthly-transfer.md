# 月度项目计划表 → 软件交付数据统计：按人补录的方法

> 适用：把研发中心《N月项目计划定版》里"一行一个项目"的计划，转成《软件交付数据统计（月度统计）》里
> "一行一个软件节点、一行一个工程师"的条目。换月份、换工程师都走同一套判据。
> 来源：2026-11-02 实做一轮（11 月计划表 → 统计表补录 汪浩 9 行、王迎曙 3 行）。
> 两份 xlsx 的存放位置属**B 类机器路径**（见 `embedded/README.md` 第 6 节），本文与脚本一律用 `{占位符}`，
> 每次跑由用户给当轮真值，不得写回正文、不得扫盘猜。

## 1. 两个文件各自是什么

| | 计划表 | 统计表 |
|---|---|---|
| 一行代表 | 一个项目 | 一个工程师的一个软件节点 |
| 人怎么记 | "关联责任人/负责人"一格里塞一串人名 | D 列只写一个人 |
| 列 | 每月列位会变，先读表头行 | 固定 34 列 A..AH，表头在第 1 行 |

**唯一落点**：统计表里那行 `ai在如下位置进行新增` 标记之下。标记行本身不删、不改、不覆盖。

## 2. 月份分组行

- 统计表靠"月份行"分段：`A=11月份`、`B=********************`。
- 补录区自己再起一行，写作 `A=<N>月份（<姓名>·从<N>月项目计划表补录）`；同月份不同人不合并成一组。
- 月份行样式复制自表内既有月份行，数据行样式复制自任一既有数据行（`_style` 整体拷贝，不要手设字体）。

## 3. 取人：谁的任务怎么找

- 要搜的是**责任人列**（一串人名），不是"项目经理"列；按人名子串匹配，整行扫到最后一列。
- 同一项目会在计划表里分段重复出现（ID 段 / 订单段 / 样机段 / 注册段），**逐条都取，不按项目名去重**。
- 计划表各分段的列位不一致：有的段 J:K 合并是"负责人"，有的段 M 是"类别"，有的段 L 才是进度说明。
  落笔前先把该分段的表头行打印出来核对，禁止照抄上一段的列号。
- 只认"带责任人/负责人表头"的分段。放宽容错会把 10 月计划分解表、8-10 月延误记录表里的同名项目一起捞进来
  （实测汪浩从 10 条涨到 17 条），那些表的口径与本月计划不同，不能当补录来源。
- 一个项目挂多个主体、编码相同时（同码不同注册主体），两条都要保留，靠 B 列主体前缀和 AB 列区分，禁止自行改码。

## 4. 列映射口径

| 统计表列 | 字段 | 取值来源与口径 |
|---|---|---|
| A | 项目编号 | 计划表 D 列原样照抄，**含错也照抄**（实测有少一个前导 0 的码），存疑只登记不修改；编码格带"（订单）"后缀时去掉后缀，`A/B` 双编码保留整串并记一条告警 |
| B | 项目名称 | `<主体或业务部门> -- <计划表项目名>`；该工程师在本表已有写法时沿用其习惯，同一人区内保持一致 |
| D | 软件工程师 | 本轮补录的人名（谁的任务填谁，不是填"接手的人"） |
| G | 项目阶段软件 | 由计划表"类别/目标"推：`注册送检/注册体考/新产品送检/体考(未出报告)` → `注册`；目标含"中试" → `中试跟进`；`模具样机/手板样机/样机/模具物料回厂` → `开发阶段`；**认不出就留空并记一条告警，不许猜** |
| H | 节点事件 | 计划表"交付任务目标"原文照搬（本表 10 月块已有整段搬运的先例，如 355/356/358 行） |
| I | 需求时间 | 计划表"计划完成时间"，统一成表内文本口径 `11月13日`；原文是 `TBD/预排12月/实时` 就照留 |
| R | 备注事项 | 计划表该行的"进度状态说明"原文（如"要确认投模""关注有效性资料"） |
| U | 需求变更 | 目标原文里"需求变更…"那一句抽出来单放，避免 H 与 U 重复 |
| AA | 项目经理 | 计划表 B 列 |
| AB | 客户/主体 | 订单与样机段取"业务部门"，注册段取"注册主体" |

## 5. 不代填的列（红线）

E/F 硬件与需求版本、J 开始时间、K 结果时间、L 实计工时、M 外部工时、N 估计工时、P 完成进度、Q 完成事项。
这些是工程师本人的实际数或估算，计划表里没有；填了就是编数字，月末统计会失真。
要填只接受用户直接给数值，或用户点名"这几行按 X 天估"。

## 6. 归属与去重四条

1. **同一项目同一人已在本月区块有条目 → 不再加行**，只在汇报里点名让用户裁决是否拆节点（加行会重复计工时）。
2. 用户说"某人挪到我这里"这类归属变化，**D 列仍按计划表里的实际责任人填**，改归属是另一条指令，别自作主张换人。
3. 计划表"排队项目/预排下月"段的项目照抄进本月补录区时，**I 列留原文时间**，并在 R 列写明来源段与原文类别。
4. 写前先查重：编码按片段比（去"（订单）"后缀、双编码拆两段），只有落在"本月分组行 → 标记行之间"的命中才算真重复；
   标记行以下（上一轮补录区）与历史月的命中只作参考，不因此拒写。

## 7. 源表数据卫生（照抄前要知道的坑）

- 计划表的日期一列混用真日期、文本（"实时""即时""11月""11月份"）和 Excel 序列号；序列号要先换算再格式化。
- 计划表右侧的达成率打分区（单位系数/结构/硬件/软件/实际达成/是否达成/未达成原因/责任部门）常有上月残留，
  个别行还有"是否达成=否"这类旧判定。**残留不是本月结论**，别搬进统计表。
- 计划表里"进度状态说明"列偶见与列义无关的值（如"联网"），照搬前先看列名。
- 注册表表头可能还写着上一个月的月份（"10月度交付任务目标（注册）"），内容却是本月——按内容月份走。

## 8. 写入五步与门禁

1. **备份**统计表到工程 `tmp/`，文件名带"备份前"与日期。
2. **干跑**出预览表，逐行核对 A/B/G/H/I/AA/AB 七项（脚本默认只预览不落盘）。
3. **锚点断言**：标记文本命中、标记之下若干行必须全空、被引用的既有行内容与预期一致；任一断言失败就整批不写。
4. **写入**：样式从模板行整体拷贝，只赋 D 与映射列；月份分组行单独一行。
5. **对账**（写后必做，判据可量化）：
   - 新增区以外，旧文件里任何**非空**单元格值改变 → 必须为 0 处；
   - 公式单元格数旧/新相等（openpyxl 保存会重算，公式丢失=结构损了）；
   - 各表 sheet 数、合并单元格数、筛选区、维度不变；
   - 新增行数 = 预览行数，且 D 列归属、AB 主体逐行回读一致。

## 9. 保存通道的已知副作用（不是错误，别当缺陷报）

- openpyxl 存盘会把 `""` 归一成 `None`（一轮实测 3502 处）。这是规范化，不丢内容；对账要按"非空值是否变化"来判，
  否则会刷出一片假差异。
- 用 `data_only=True` 读回自己刚存的文件，公式列会读成 `None`（openpyxl 不写缓存值）。**对账必须用 `data_only=False`**，
  否则会把公式判成"被清空"。
- 原文件里的图片/图表 openpyxl 保留不全。统计表这类纯数据表可走 openpyxl；**带图的计划表只做只读，不回写**。
- 表尾新行落在自动筛选区（AutoFilter ref）之外时不会被筛选隐藏，永远显示；不必为补录去扩筛选区。

## 10. 脚本

`yjt/delivery_stats/tools/delivery_stats_ops.py`，`sys.path.insert` 直接 import，不要另写一份。

| 子命令 | 作用 | 会不会改文件 |
|---|---|---|
| `find --plan {计划表.xlsx} --person <姓名>` | 扫计划表，回传该人全部任务行 | 否（只读） |
| `preview --plan ... --person ... [--name-style sector\|register]` | 按第 4 节映射出待写行，打印并给出 G 列告警 | 否 |
| `write --plan ... --person ... --stats {统计表.xlsx} --sheet <表名>` | 备份 + 锚点断言 + 写标记行之下 | **是** |
| `audit --stats ... --backup ... --from-row <首行>` | 第 8 节四条对账 | 否 |

机器路径参数（`--plan` / `--stats`）是 B 类真值，每轮由用户提供；脚本**没有默认路径**，不给参数就不跑。
`write` 默认只预演落点，加 `--apply` 才落盘，落盘前自动备份到统计表同目录 `tmp/`。
