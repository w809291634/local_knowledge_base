## 1. 交付形态

单文件 HTML：CSS/JS/数据全内联，零外部请求（`<a>` 数=0、Network 失败数=0 是硬判据）。
交付方式（2026-11-04 用户定，PR-0450/0451）：**给工程内 HTML 的绝对路径，由用户自己在浏览器打开；
不做对话内嵌预览，也不单独生成「设计图查看器」页**（`design_review.html` 这类）。设计图的载体就是
「高清设计图」页签本身。生成器顺带出的 `overview_pro.fragment.html` 只在要把评审页嵌进自有页面时用，
不是核对通道；其能跑的前提是 bootstrap 写成 `readyState!=="loading" 就立即 boot()`。
**载体定档**（2026-11-04 用户定，PR-0446）：设计阶段的 UI 显示与跳转演示**就以 H5 为主要交互载体**。
动线 GIF、PPT 翻页只是被评估过的备选，**不落地**——它们要么路径写死、要么得重摆一遍变成第二真值。
要"更快"就往载体形态上要（整页 + 可内联片段双出），不要换载体。

三个视图，顶栏页签切换：

| 视图 | 干什么 | 关键交互 |
|---|---|---|
| 分层总览 | 每层一行横向卡片，看清单与分类 | 点跳转标签→行内滑到目标页并加选中外框；点卡片本体→右侧停靠栏出带标注大图 |
| 跳转演练 | 单页大图，控件就是能点的控件 | 点帧上按钮真跳页（按真机方向横滑）；`‹ 上一页`/`回主控`/路径胶囊 |
| 高清设计图 | 每层横向原尺寸无标注图 | 点卡片→右侧停靠栏 |

## 2. 单一真值怎么接

```
design/simple_control.py   基元 + 几何常量（控件框只在这里定义一次）
design/pages.py            每页帧 + 控件语义表（名称, 分类, 点击后, 行为层, 控件框）
design/nav_map.py          跳转目标表 {(页, 控件名): 目标页}
design/export_ui.py        page_data() → {页: {svg, rows, entry, exit}}
design/overview_pro.py     ← 模板 tools/h5_overview_template.py 的工程实例
```

标注框、热区框、序号点共用同一个 `box`，所以标注图与 H5 不会漂。
改呈现＝改设计源再重跑生成器；**永不手改产出的 HTML**。

## 3. 控件分类口径（6 类，按数据流向）

`内部读 / 外部读 / 内部写 / 外部写 / 跳转按钮 / 跳动手势`，一类一色。
判据来自控件语义表的 `行为层`，个别控件按语义用 `OVERRIDES` 显式覆盖，不靠通用规则猜。
颜色只在设计源与生成器里定义一次（`IO_COLORS`），帧上描边、序号点、卡片标签、图例全部取同一处。

## 4. 排版与交互硬规则（用户口味，逐条来自改判）

- 不用跟随鼠标的浮层。放大图一律「点开 → 钉在右侧停靠栏」，宽窗口是 grid 右栏（sticky），
  窄窗口（<1400px）自动降为右侧固定浮层 + 遮罩。
- **点开的面板要点空白处就能收起**（PR-0454）：不要逼用户去找关闭键。停靠栏的关闭途径＝
  再点同一张卡 / 点页面任意空白 / Esc / ✕ / 点遮罩；但点停靠栏**自己内部**不能误收。
- 清单按分类分行，一行只放一类。固定顺序：跳转按钮 → 跳动手势 → 外部写 → 内部写 → 外部读 → 内部读（可操作在前）。
  行首放同类名胶囊（描边=该类色）+ 计数。
- 计数要带文字，不能只给色块加数字——`2472` 这种读起来是乱码。
- 跳转/手势类要高对比（实心 + 黑字 700 + 粗箭头）；数据类可以弱化但不能糊成一片灰。
- 行内滑动跳转要真的"滑"过去：跳转期间临时关掉该行的 `scroll-snap`，动画结束再还原，
  否则 snap 会把平滑过程拽回卡头，看起来像瞬移。
- 返回要回到上一次浏览位置，不是回到顶部：历史栈存 `{view, cur, y, rows[]}`，
  `popState` 在 rAF 里同时回填窗口 `scrollY` 和每一行的 `scrollLeft`。
- 按钮就得是按钮：热区是铺满控件盒的透明 `rect`（`pointer-events=all`），
  标注框本身 `fill=none` 只有描边，拿它当热区会"中间点不中"。
  三态可测：常态浅底（提示可点）→ 悬停加深 + 描边加粗 → 按下最深。
- 每屏能进能回：跳转演练里 `‹ 上一页`（无历史置灰）、`回主控`、路径胶囊三件套常驻。
- **高清设计图与实时效果同源同步**：核对通过后再改 H5 的跳转/动效/交互，「高清设计图」页签必须一起改，
  不允许只动一边；也不另出查看器页把图复制一遍。

## 5. 门禁

生成器自证（跑一次就打印）：

```
[GATE] 页 22 层 [1,2,3,4,5] 控件 168 手势边 21 分类计数 {...}
```

- 6 类里任何一类计数为 0 → 断言失败（说明分类口径漏了）。
- `OVERRIDES` 只许改"数据类"归属，**不许吃掉 `behav=换页` 的跳转**：生成器里直接 assert，
  一旦某条覆盖把换页控件判成非 nav 就当场报错（w78 就靠这条抓到「设置·关于」点不进去）。
- 目标页必须存在于页序；状态页（无入口页）单独标出、不单独成层。

无头真实验证（判据要能量出来，见 §6）：

- 卡片宽度、行 `scrollLeft` 起止与中途值、选中外框数量=1、停靠栏尺寸与标注框数、
  每行类别数 ≤1、`<a>` 数=0、Network 失败=0。
- 交互闭环：真实鼠标点按钮中心 → 面包屑变目标页；点非跳转控件中心 → 面包屑不变。
- **入口可达性**：跑 `design/nav_audit.py`（七查，见 `UI_BEHAVIOR_CONTRACT.md` 通用铁律 3），
  FAIL 不许交付。它专治「这页怎么进来的」——把"跳转表说有点、界面点不到"的漂移当场抓出来。

## 7. 坑（都踩过）

1. **`element.dispatchEvent` 造出假通过**：它绕过浏览器命中测试，"点了能跳"其实中间根本点不中。
   判交互必须走 CDP 真实鼠标坐标，或至少 `elementFromPoint` 反查命中的是谁。
2. **同 URL 再 `Page.navigate` 只算文档内跳转**，页面状态不清零；要干净状态就给 URL 加时间戳。
3. **`render()` 重建 DOM 后攥着旧节点**读值 → 全是 0，看着像"返回没还原"。改读 `document.querySelectorAll` 的活节点。
4. **`scrollIntoView` 与 `scroll-snap` 打架**：滑完被 snap 拽回卡头，判"没滑动"。见 §4。
5. **Edge 会多开 `edge://sync-confirmation/` 页面 target**，取第一个就连到空页；按 URL 选（工具已内置）。
6. **关掉启动它的 shell ≠ 关掉浏览器**：msedge 是独立进程树，profile 被锁，`rm -rf` 报一堆 busy。
   按 profile 路径找根进程再递归杀整棵树，只杀匹配这台 profile 的。
7. **别拿对话内嵌预览当核对通道**：`present_visualization` 只收片段（整页判 invalid），且渲染与脚本
   是否放行由客户端决定。用户要的是**文件路径 + 自己开浏览器**；临时手搓片段还会和交付件漂移。
8. **cache-buster 不能拼在 `#fragment` 之后**：`page.html#jump?v=…` 的 hash 变成 `#jump?v=…`，
   按 hash 选视图的白名单匹配不上，页面**静默停在默认视图**，后面所有选择器都找不到元素。
   `h5_probe.js` 已改为把 `?v=` 插在 `#` 之前。
9. **呈现层小灶吃掉入口**：`OVERRIDES` 把 `behav=换页` 的控件判成数据类 ⇒ 该页在 H5 里没有入口，
   用户只能问"这页怎么进来的"。判类覆盖只许补真值、不许推翻行为，且要配 assert（§5）。
10. **静态扫描类名会假阳性**：`enterR/exitL` 由字符串拼出来，扫不到不等于死码；
   `@media` 里的同名选择器是合法覆盖，不算重复。删东西前要有可指认证据（死链、真正重复的规则、非法属性）。

## 8. 边界

- H5 只验「清单/分类/层级/跳转关系 + 交互闭环」，像素级字号、配色、动效仍以 EEZ 画布与仿真截图为准。
- H5 里的切换动画是设计口径演示，真机节奏要到第⑥步烧录后由用户核。
- **H5 通过不等于 ④⑤ 免做**。
