# 13 设计图 v2：SVG 静态总览 + H5 可点原型

> 定稿：2026-11-03（用户定，PR-0423）。适用：EEZ / LVGL 界面在"设计冻结"之前，
> 需要**人亲手点一遍、核验跳转逻辑**的场合。
> 与 v1 的关系：v2 = v1 的静态交付物 + 一个可点的单文件 H5，**不是替换**。

## 1. 交付物

| 文件 | 作用 | 判读方式 |
|---|---|---|
| `designer_simple/00_page_map.svg` | 分层方框图：方框=同一层，内含各页缩略 | 看层级和每层入口 |
| `designer_simple/01_preview_pages.svg` | 逐屏长图：真实帧 + 序号框 + 控件表 | 逐屏核对控件与行为 |
| `prototype/index.html` | **可点原型**：点界面控件跳到目标页 | 亲手点，核跳转对不对 |

三条都从同一份设计源生成；H5 只**内嵌**设计源渲染出的帧 + 叠透明热区，**绝不重画界面**
（重画即出现第二真值，违反"界面只在设计源里定义一次"）。

## 2. 单一真值怎么拆

```
design/simple_control.py   基元 + 主控 + 房间模板 + 几何常量（ROOM_GRID/TILE_GRID/BACK_BOX/CAT_COLORS）
design/pages.py            其余页面帧 + 每页控件语义表 (名称, 分类, 点击后, 行为层, 控件框)
design/nav_map.py          跳转目标表 {(页面, 控件名): 目标页面}
design/preview_pages.py    出 01_preview_pages.svg（逐屏长图）
design/export_ui.py        出 00_page_map.svg + prototype/index.html
```

**控件框坐标只写一次**：页面上画控件和热区用的是同一个 `box`，标注图与 H5 因此不会漂。

## 3. H5 结构

- 左栏：按层分组列页（一级 / 房间 / 设备详情 / 工具页），点即切页。
- 中间：800×480 舞台，内联 `<svg viewBox="0 0 800 480">` + 绝对定位热区 `div.hot`。
- 右栏：当前页控件表（序 / 控件 / 分类 / 点击后 / 行为层），点行也能跳。
- 顶部：面包屑 + `‹ 返回`（历史栈）+ `回主控`；Esc = 返回。

热区规则：**只给"换页"类控件叠热区**（分类 `nav` / `back`）；开关、滑条、场景只做视觉反馈，不跳页。
热区悬停显示 `控件名 → 目标页`，用户不需要猜哪里能点。

## 4. 门禁（缺一不可）

1. 每个 `target` 必须能在页面清单里找到（防指向不存在的页）。
2. 非根页恰有 1 个 `back` 行，且行为层为"换页"（导航闭环）。
3. 每页控件行数 ≤ 表格高度能容纳的行数（当前 14），否则表格溢出。
4. 同一页序号唯一；每个控件框宽高 > 0。
5. 屏数下限（本工程 20）与跳转控件数打印出来，作为交付证据。

## 5. 实测证据（w78 智能家居，2026-11-03）

- `[GATE] 屏 22 跳转控件 63`。
- 浏览器真点：主控→客厅→灯详情→`‹ 返回`→客厅→`回主控`；
  通知→查看①→灯详情→返回；全部设备→＋添加→选类型→配网中→上一步。
- 灯详情只有 1 个热区（返回），其余 7 个是开关/滑条 —— 说明热区只叠在换页控件上。

## 6. 坑（都踩过）

| 现象 | 根因 | 处理 |
|---|---|---|
| 房间页只有"返回"一个热区 | 房间设备格的目标表建了但忘记合并进主表 | 建完 `ROOM_TARGETS` 立即 `NAV_TARGETS.update(...)`，并靠门禁 1 兜底 |
| 界面上的圆形徽标盖住按钮文字 | 徽标半径固定 10px，控件缩到 0.5 后只有十几像素宽 | 框高/宽 < 22px 时用半径 7.5、字号 7.5 |
| 表格底部溢出/行挤成一团 | 行高固定 30 | 行高 = min(30, 可用高度 / 行数) |
| 内联 SVG 不显示 | 设计源产出的是 `<svg>` **片段**，没有外层尺寸 | 包一层 `<svg viewBox="0 0 800 480" width height>` 再插 |
| 4 个入口按钮挤在一起 | 主控顶部固定 64px 宽 | 入口数变化时重算起始 x 与宽（本工程 4×56，x=540 起） |

## 7. 边界（写进交付说明）

H5 只证明**跳转逻辑与页面内容**。像素、字号、圆角、动效节奏仍以 **EEZ 生成 + 仿真截图**为准；
H5 是核对工具，不是像素验收依据。
