# 17 布局间距规则：安全净距 + 同尺寸等距

> 定稿：2026-11-07（用户定）。来源：w78「设置」页 Wi-Fi 整行卡贴死自动锁屏卡
> （行距 60/60/52/60，D5 与 L2 都没查出来）。
> 自动检查：`tools/layout_check.py` 的 L6 / L7（先 `--warn` 出报告，清零后转硬门禁）。

## 1. 适用范围

只约束**同页、非同父子、都可见**的独立控件。以下不参与：
装饰/背景 rect、隐藏浮层、父子控件、以及**同一分组内允许 0 间距**的分段控件/标签页。

> 卡片是装饰 rect，EEZ 工程里没有对应控件；D5 比"像不像"、L2 查控件重叠，都看不见
> "两张卡贴死"。所以这两条必须靠设计源导出的分组几何来判。

## 2. 规则

### R1 安全净距

互相独立且**可交互**的控件，水平/垂直净距 **≥8px**；纯文字标签之间 ≥4px。

- 例外：分段按钮 / 标签页组内允许 0 间距，但组必须有明确边界（共用底、描边、分组容器），
  且组内仍要满足 R2。
- 判定只看净距（两框之间空隙），不要求外边距等于内部间距。

### R2 同尺寸等距

同一组内、同尺寸的个体，**pitch（相邻个体起点距）必须一致，允许 ±1px**；gap 同步一致。

- 靠左排版：外侧边距＝内容边距（如 40px），内部 gap 单独等分；
- 居中/通栏：左右外边距也必须相等；
- 最后一行不满：保持同一 pitch、与首列对齐；若要居中，须在设计源显式声明；
- 不同组（如场景按钮 vs 房间卡）不硬比间距。

## 3. 判定数据（唯一来源）

设计源导出 `layout_boxes.json`：`{页: [{x,y,w,h}, ...]}`，只含真正的卡片框。

- w78：`simple_control.card()` 输出带 `data-card="1"` 标记，`design/layout_boxes.py` 解析导出；
- **不要**用 EEZ 控件反推卡片，也不要从文字标签 y 猜行距（误报率高，已撤）。

## 4. 自动检查

```bash
python <kit>/tools/layout_check.py <工程.eez-project> \
  --divider 88 --layout-json design/layout_boxes.json --warn
```

| 项 | 判据 |
|---|---|
| L6 | 同页同尺寸卡片，纵向/横向 pitch 一致（max-min ≤1px）；组内至少 3 个才判 |
| L7 | 独立可交互控件（按钮/开关/滑条/输入/列表/键盘…）净距 ≥8px |
| `--warn` | 只打印 `~` 告警，不改退出码；清零后去掉该参数转硬门禁 |

动态条目区（`DYN_ZONES`）不参与 L6/L7：条目不进设计图，运行期由应用代码创建。

## 5. 落地流程

1. 改布局 → 先跑 `--warn` 出全量报告，列清单；
2. 新增整行卡只从统一常量推导（`ROW_H / ROW_GAP / PITCH`），**禁止写死 y**；
3. 存量告警逐项修完，再转 FAIL，纳入「四件套 + layout_check」汇报；
4. 汇报格式：`[LAYOUT] ... L6/L7 n`，0 才算清。
