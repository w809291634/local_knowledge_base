## 1. 精灵动图自检（仅在使用精灵动图时）

工作流只持索引、不复述规则：交付前逐条跑下表，**全绿 + 附首/中/末三帧目检证据**才给用户；
规则细节与实测数字索引到 `ANIMATION_ASSETS.md` §6，门禁实现索引到工程 `design_sprite.py` / `design_view.py`。

| # | 自检项 | 门禁入口（必须可跑且静默） | 规则索引 |

| 1 | 逐帧动图底图不含精灵控件本体 | `page_with` skip_ids + 幽灵像素计数（反向测试：不 skip 须检出 >0） | ANIMATION_ASSETS §6-1 |

## 2. 控件标注与动态条目区

**标注范围（唯一判据）**：凡会随设备或时间变化的值、以及用户能操作的元素，都是控件，必须编号。
包括：可操作件（跳转/返回/动作按钮、开关、滑条、输入框、列表、键盘、进度条、图表）、
整卡交互区（整卡 + 卡内开关/滑条本体各标一次，整卡虚线示点击范围）、设备读数
（温湿度/百分比/功率/电量/信号/开合度/在线状态/开关状态/数量/日期时间/版本网关）、
隐藏弹层的展开态（密码半页/对话框单独成卡）和随状态变化的纯数字角标。
**滑条/进度条与数值显示成对出现时，数值一律标内部读 `in_read`（UI 自己控制），
不标外部读、不当静态文本；生成器按邻近 + 单位后缀（% / K / 进度值）自动识别。**
不标：固定标题、字段名、说明步骤、按钮文案、空态文案、装饰字符/图形；同一元素只标一次，
按钮文字不重复标。

**动态条目区（2026-11-06 用户定，设计原则）**：数量会随程序/环境变化的列表
（Wi-Fi 扫描结果、设备列表、通知、动作/定时条目）在设计阶段**只框出区域、不画任何对象**；
条目**不进设计源/EEZ**，运行期由应用代码创建。确需临时测试对象时只许 1 个、名称带「示例」，
联调结束必须删除，决不能变成固定控件。
唯一真值＝设计源 `pages.py` 的 `DYN_ZONES`；H5 画青色虚线框 +「动态区 · 运行期由应用代码生成」，
控件清单单列「动态条目区」；改区域只改 `DYN_ZONES` 再重生成，不手改 HTML/工程。

开机自检页与开机流程以 `18_boot_selftest_page.md` 为准；H5 控件每页使用统一序号，与页面清单对应，分类使用颜色区分。
