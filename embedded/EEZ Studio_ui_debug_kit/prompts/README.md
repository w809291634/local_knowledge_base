# prompts/ —— 提示词日志

> 记录**用户与 AI 之间每一次输入**，用于日后追查「当时为什么要改这个」。
> 写入规约见 `../INTAKE.md`；写入器 `../tools/log_entry.py prompt`。

## 为什么单独放一处

- 问题（`intake/`）回答"改了什么、为什么"；提示词（本目录）回答"**谁在什么时候要求的**"。
- 二者用编号互引（`PR-####` ↔ `P-####`），就能还原出完整的因果链：
  `用户原话 → AI 定位 → 修复 → 沉淀成断言`。
- 用户的原话是**不可再生**的信息 —— 一旦丢失，复盘时只能靠猜。所以逐字抄。

## 规矩

1. **只追加，不改历史**（`PROMPT_LOG.md` 只往后加）。
2. **逐字抄**用户输入，不改写、不润色、不翻译。
3. 补录历史时，时间写 `"YYYY-MM-DD（补录）"`，并在"产出/结论"里写清当时的结论。
4. 当前 AI 工具名填进 `工具` 字段（如 `WorkBuddy` / `Cursor` / `ChatGPT` / `人`）。

## 怎么加一条

```bash
python ../tools/log_entry.py prompt "用户的原始提示词" \
    --tool WorkBuddy --ask "用户想达成什么" --out "这轮做了什么" --link P-0001
```

或按 `PROMPT_LOG.md` 里已有条目的格式手写追加。
