# P-0032 设置页内容压左栏：撤子页时把 place 起点 RAIL_W+206 改成了 RAIL_W

- **状态**：fixed
- **发现日期**：2026-09-30
- **提示词**：PR-0059
- **标签**：布局, 外置左栏, place起点, RAIL_W, tab pager, 对照门禁, 均值盲区, 目检

---

## 一、现象（用户原话：「界面发生重叠，你自己截图没看出来有问题吗」）

07 设置主页 / 08 语音唤醒 / 10 显示与音量三屏：外置左栏 `rail_cats`
（网络与连接 / 显示与音量 / 语音唤醒 / AI 与个性化 / 隐私与安全 / 关于本机）
与 pane 内容（设备卡「小艺 · 智能屏 8 · 检查更新」+ 无线网络 / 语音唤醒 /
主音量 / 屏幕亮度 / 勿扰模式 五行）**两组内容错位叠加**；
内容右缘 594..800 反而空一截。09 浮层因背景就是设置页，同样中招。

而对照门禁报告里 07 只有 **12.90%** 明显差异，「通过」。

## 二、复现

```bash
python design/all.py --shots
# 打开 build/sim_shots/07_settings.png 即见两组内容叠字
# 或量 ui.json：set_gen 子节点 x≈94（正确应 ≈300）
```

## 三、根因

1. **几何契约被顺手改掉**。设置左栏 `rail_cats()` 是外置单实例（§11.9 tab pager
   通用规则），固定盖在内容区左侧 `[76, 282]`（206px）。设置三子页的 pane 起点
   **必须**是 `RAIL_W+206`（=282），pane 宽 `SW=CONTENT_W-206`（518）。
   撤「设置 · 网络」子页时误以为「没有网络子页了，内容应该占满内容区」，
   把三处 `place(...)` 起点从 `RAIL_W+206` 改成 `RAIL_W` → 内容 76..594，
   左半压在左栏下面、右边空 206px。
2. **为什么以前没发现**：
   - `check_bounds` 门禁只查「**子超出父**」，不查「**兄弟重叠**」——全部合法通过；
   - `compare.py` 对照门禁只看 **11 屏平均**明显差异（阈值 25%）：单屏结构性错位
     只把 07 拉到 12.90%，整体均值 10.05% 照样绿；
   - 出图后目检只看了浮层卡片本身，没放大检查被遮罩压暗的背景。

## 四、修复

`design/build_ui.py`：

```python
SET_X = RAIL_W + 206          # 提常量，写明「外置 rail_cats 盖住左侧 76..282」
set_gen["children"]  = place(pane_settings(...), SET_X, SB_H, "set_")
set_disp["children"] = place(pane_display(...),  SET_X, SB_H, "disp_")
set_wake["children"] = place(pane_wake(...),     SET_X, SB_H, "wake_")
```

（当时还同步把钉态页 shot_disp/shot_wake 改 `x=RAIL_W+206, w=SW`——第一次重建被
`check_bounds` 拦下 `282+724=1006>800`，收宽后通过；后按 P-0033 钉态页整体删除。）

## 五、证据

- 对照差异：07 **12.90% → 6.54%**、08 **12.90% → 7.65%**、10 **10.60% → 6.47%**，
  11 屏平均 **10.05% → 8.62%**（`all.py --shots` EXIT=0）。
- 逐屏放大目检 07/08/09/10：左栏分类、内容卡、右缘控件全部归位，无叠置。
