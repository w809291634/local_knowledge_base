# P-0239 控件批注菜单挪到右侧清单行，效果图右键只做页面批注

> **检索别名**：控件菜单在右侧 / 清单右键 / 效果图右键页面批注 /
> 控件列表右键 / 页面 pin。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`
- **触发**：用户要求在右侧控件清单处右键选功能，页面批注在效果图里右键。

## 改法

- 右侧控件清单行（跳转演练的 `.item`）加 `data-page/data-rn` 与提示；
  **右键清单行** → 控件菜单（标记删除/修改说明/控件上加提示/清除）。
- **右键效果图**（分层卡片、跳转大图、放大停靠栏）→ 只做页面级批注：
  空白处落坐标 pin；右键已有 pin 可修改/删除。
- 效果图不再弹控件菜单；控件菜单统一走右侧清单。
- 菜单仍为 HTML 浮层，点空白/Esc 关闭。

## 自证（Edge headless + CDP）

| 操作 | 结果 |
|---|---|
| 右键清单行 `#5 客厅卡` | 菜单 `主控 · #5 客厅卡` |
| 点标记删除（干净 profile） | localStorage 写入 action=delete，total=1 |
| 右键跳转大图空白 | 菜单 `主控 · 页面`（不是控件菜单） |

## 注意

- 分层总览里的 pill/tag 暂不接右键菜单；控件操作统一在右侧清单/跳转演练。
- 效果图右键页面 pin 与控件左键跳转互不冲突。
