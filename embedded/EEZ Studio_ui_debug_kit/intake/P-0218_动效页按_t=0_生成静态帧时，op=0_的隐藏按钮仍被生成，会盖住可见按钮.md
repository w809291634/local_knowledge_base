# P-0218 · 动效页按 t=0 生成静态帧时，op=0 的隐藏按钮仍被生成，会盖住可见按钮

- **工程**：w78-tabview-smart-home
- **日期**：2026-10-30
- **工具**：Qoder
- **状态**：fixed
- **标签**：EEZ,动效,opacity,静态帧,控件,层叠
- **关联提示词**：PR-0402

## 现象（看到什么）

门铃页 t=0 应显示“接听/忽略/对讲”；生成器把同页 op=0 的“挂断/静音/免提”也生成成不透明原生按钮，叠在上面，静态画面出现错误按钮。

## 复现（怎么稳定重现）

页面 draw(0) 的 btn 元素：接听/忽略/对讲 op=1.0，挂断/静音/免提 op=0.0；旧生成器不读 op，6 个全部生成。修复后 intercom 只剩 3 个原生按钮 c_intercom_0..2。

## 根因（真正的原因）

生成器 controls_for/labels_for 只看元素类型，不看 e['op']；按钮默认 bg_opa=255，隐藏态元素会以不透明控件遮住可见态。

## 修复（做了什么）

生成器跳过 op<=0.01 的元素（文本与控件），背景仍保留；重新生成后门铃页只生成 3 个原生按钮，标签 13 个。

## 证据（数字 / 命令输出）

修复前 6 个 btn（3 个 op=0）→ 修复后 3 个原生按钮；PC 仿真 800×480 截图门铃页与设计图一致，平均通道差 1.23。

## 沉淀（新增断言 / 案例 / 文档）

README 批2自检修复段；本 intake 记录；后续动效页静态帧生成遵循“op=0 不生成控件/文本”。
