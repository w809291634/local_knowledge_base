> **检索别名**：UI 控件没实现 / 控件数对但点不动 / 行为覆盖审计 /
> 69 个未接 / behavior_audit / A12 只查类型。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`
- **触发**：用户发现 UI 很多控件没实现，质疑控件数核对。

## 结论

控件数/类型核对没有错，但口径只覆盖“存在/类型”：

- A2/A12：按框存在 + 类型正确（281 = 281）；
- D5：视觉相似度；
- ⑤：导航闭环；
- **⑦ 行为接线没做完**，所以“有控件但点了没反应”。

已接：
- 导航 72 条（nav_bind）
- Wi-Fi 10 个动作（wifi 层）
- 滑条数值标签 5 条（value_bind）

- 开关 **28**（房间格、详情页、设置、安防、场景动作）

显示值：`out_read` 90 + `uivalue` 9 多数仍是设计静态值，未接真实数据源。
