# P-0236 整卡开关/滑条的序号要标在控件本体上

> **检索别名**：开关没标 / 滑条没标 / 序号在卡片角落 / 整卡交互 / glyph 标注 /
> 开合 70% / 房间格开关。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`
- **触发**：用户截房间格开关/滑条，指出这类控件很明显却没标在控件上。

## 根因

房间格是“整卡交互区”：控件行 box = 整张卡，H5 序号画在卡片左上角。
实际可见的开关/滑条 glyph 在卡内右下角，序号看起来不在控件上。

## 修复

- `overview_pro` 为整卡 toggle/slider 增加 `markBox`：从设计帧里反查卡内
  switch 轨道（44×24）或 slider 轨道（h≤8、w≥80），H5 标注框与序号画在 glyph 上；
- 整卡仍画一圈 0.28 透明度的虚线外框，表示真实点击区域；
- 序号放在 glyph 左侧，避免盖住开关/滑条本体。

## 结果

- 房间格开关序号直接贴在开关旁，滑条（开合 70%）同理；
- 控件 282 条、读数 100 条不变；H5 重新生成，JS 语法检查通过。
- 没有启动 EEZ（按用户要求只改设计/H5）。
