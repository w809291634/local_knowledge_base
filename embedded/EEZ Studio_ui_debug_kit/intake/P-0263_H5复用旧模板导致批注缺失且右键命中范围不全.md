# P-0263 H5 复用旧模板导致批注整块缺失，右键只绑两处

- 工程：patient-monitor（床旁多参数监护仪）
- 工具：Trae
- 日期：2026-11-07
- 标签：H5评审页,批注,右键菜单,模板复用,命中范围,门禁
- 状态：fixed

## 现象

用户在 H5 评审页的两个位置右键都没有菜单，浏览器默认菜单直接弹出：

1. 分层总览里页面卡片下方的跳转胶囊（`1.新建患者 → 患者信息` 这一类）；
2. 高清设计图页签的页面卡片（带黄色控件标注框的大图）。

顶栏也没有「导出批注」按钮，无法产出 `annotations.json`。

## 复现

1. 打开 `designer_simple/overview_pro.html`；
2. 在跳转胶囊或 `.pcard svg` 上点右键；
3. 结果：浏览器默认菜单；`#cmenu` 始终 `display:none`。

代码侧取证：

```bash
grep -c "contextmenu\|annotations\|导出批注" design/overview_pro.py
# 修复前 = 0
```

## 根因

两层叠加：

1. **模板代差**：工程侧 `design/overview_pro.py` 是从早期 car-hmi 工程整体复制的版本，
   早于 `reference/14 §8` 的 H5 批注模式（2026-11-05 定稿）。三视图、停靠栏、标注都在，
   但批注模块（右键菜单 / 图钉 / localStorage / 导出 JSON）从未存在。
2. **命中范围过窄**：补批注时只给 `[data-cpage]`（右侧控件清单行）和
   `#bigbox svg, #dock svg`（跳转演练 / 停靠栏）绑了右键；
   分层总览的跳转胶囊没有控件标识，高清设计图卡片也不在选择器内，两处全部落空。

## 修复

1. 补批注模块：`localStorage` 持久化、右键菜单（标记删除 / 修改说明 / 加提示标签 / 清除）、
   页面图钉 `p1/p2`、导出 `annotations.json`、顶栏实时计数。
2. 右键命中改为：
   - `[data-cpage]`：控件清单行、跳转胶囊、静态胶囊、图上控件标注框；
   - `svg[data-page]`：所有由 `mark()` 生成的 SVG（总览缩略图、演练大图、停靠栏、高清卡片）。
3. 给跳转胶囊 `pill(p,r)` / 静态胶囊 `tagIo(p,r)` 补 `data-cpage / data-cn / data-cname`，
   并把 `tags(d)` 改成 `tags(d,p)` 传入页名。
4. 工程门禁新增 C7：H5 必须同时含「导出批注按钮 / contextmenu 监听 / annotations.json 导出 /
   localStorage」，缺一即 FAIL，防止下次再复制到旧模板。

## 证据

无头浏览器实测（临时 selftest，验证后已删）：

```text
data-selftest="y|3|y|1"
```

- 跳转胶囊右键：菜单弹出 `y`，3 项；
- 高清设计图空白右键：菜单弹出 `y`，1 项（在此处加提示）。

修复后 `grep` 四项全部命中；`step1_gate` C7 PASS。
