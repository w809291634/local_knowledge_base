# P-0204 · 退场动画要把"逻辑已关闭"和"视觉已隐藏"分开，隐藏放 ready 回调

- **工程**：app-wifi-scan-conn-no-flow
- **日期**：2026-10-24
- **工具**：Qoder
- **状态**：fixed
- **标签**：LVGL,动画,状态语义,模态
- **关联提示词**：PR-0376

## 现象（看到什么）

半页加了入场动画后，用户要求"退出也要"。天真的做法是在关闭时先跑动画、动画完再设
"已关闭"——结果逻辑层的判据（"半页开着就必须有密码"、模态互斥、`saved` 刷新）会被
动画时间拖住，出现"关掉之后还能被当成开着"的怪状态。

## 复现（怎么稳定重现）

把 `s_sheet_open = false` 挪到退场动画的 ready 回调里：点击 × 的同一拍里
`wifi_nav_sheet_open()` 仍为真，`wifi_logic` 的"半页开着才校验密码"分支会继续生效。

## 根因（真正的原因）

模态有两套状态：**逻辑的**（能不能再操作、要不要互斥、算不算打开）和**视觉的**
（还在不在屏幕上）。动画只属于后者；把逻辑状态绑到动画结束，等于让"界面还在动"变成
"业务还没关"。

## 修复（做了什么）

`wifi_nav_close_sheet()`：立刻 `s_sheet_open = false`，然后启动退场动画；
`overlay_root` 的 `HIDDEN` 放到动画 `ready_cb` 里。退场途中被重新打开
（`open_sheet`）或被对话框互斥切走（`open_dialog`）时，`lv_anim_delete` 掉动画并立刻落位/隐藏。

## 证据（数字 / 命令输出）

`[NAV] RESULT: PASS 49 / FAIL 0`，新增断言「点 × 后半页正在滑下去（退场动画在跑）」；
反向测试（关闭改回立刻隐藏）→ 该条 rc=1；`preflight` 全绿。

## 沉淀（新增断言 / 案例 / 文档）

**给"消失"加动画时，逻辑状态必须在动画开始前就落地**，只把"隐藏/移除"推迟到动画结束；
并且给退场单独留一条"动画在跑"的断言，否则退场被删成瞬切也不会被发现。
