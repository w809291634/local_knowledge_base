# P-0126 · EEZ 会话状态损坏导致工程无法打开（首页按钮无效/双击条目崩溃）

- **工程**：Design Watch（watch UI 工程）
- **日期**：2026-10-16
- **工具**：Qoder
- **状态**：fixed
- **标签**：EEZ,应用状态,工程打不开,恢复
- **关联提示词**：PR-0210

## 现象（看到什么）

排障过程中（多次强制结束挂起的 EEZ 进程后）工程无法打开：首页 Edit Project 按钮无效、双击条目整进程崩溃、带参数启动停在首页。工程文件本身完好（JSON 校验通过、mtime 未变）。

## 复现（怎么稳定重现）

连续强制结束挂起实例后复现；仅重启不清状态依旧。

## 根因（真正的原因）

EEZ 应用持久会话状态（Local Storage / Session Storage）损坏。

## 修复（做了什么）

备份并删除 %APPDATA%/eezstudio 的 Local Storage + Session Storage → 带参数重启即恢复打开（实测）；本次备份留档 sim_watch/eez_state_backup_*。

## 证据（数字 / 命令输出）

清除前后对比：清后带参启动工程即开（编辑画布 410x502 在位）。
