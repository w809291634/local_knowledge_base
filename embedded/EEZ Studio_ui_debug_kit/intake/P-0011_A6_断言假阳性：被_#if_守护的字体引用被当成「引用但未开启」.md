# P-0011 · A6 断言假阳性：被 #if 守护的字体引用被当成「引用但未开启」

- **工程**：（待补）
- **日期**：2026-09-23
- **工具**：WorkBuddy
- **状态**：fixed
- **标签**：audit,false-positive
- **关联提示词**：（无）

## 现象（看到什么）

audit_ui A6 报 2 条 ERROR：'生成代码引用 lv_font_montserrat_8/10，但运行时配置中开关为 0'；而该工程零错误、仿真器编译链接都正常

## 复现（怎么稳定重现）

生成器产出的字体查表自带 #if LV_FONT_MONTSERRAT_8 … #endif 守护（共 21 档）

## 根因（真正的原因）

A6 用全文正则统计 lv_font_* 引用，没有识别『该引用本身就在 LV_FONT_* 条件编译块内』——开关为 0 时这些引用根本不会编译进去，不构成「引用但未开启」

## 修复（做了什么）

新增 strip_font_guards()：按 #if/#endif 栈剥掉 LV_FONT_* 守护块后再统计；另加 checks.font_switch_ignore 排除工程自烘焙字体（不走 LV_FONT_* 开关，其存在性由 A2/A8 覆盖）

## 证据（数字 / 命令输出）

修复前 A6 = 2 ERROR（全在守护块内）；修复后 A6 = OK，无条件引用的内置字体 0 种
