# P-0240 底部控件标签右键仍是浏览器菜单：标签未带产物数据

> **检索别名**：下面的控件标签右键 / 标签右键浏览器菜单 / pill 右键 / tag 右键。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`
- **触发**：右键页面卡下方的控件标签，弹出的仍是浏览器菜单。

## 根因

右键菜单只挂在右侧控件清单 `.item[data-rn]`；分层总览卡下方的标签是
`pill()` / `tagIo()` 生成的 `.pill`，没有 `data-page/data-rn`，也不在右键选择器里。

## 修复

- `pill(r,page)` / `tagIo(r,page)` 输出 `data-page/data-rn`；
  `tags(d,p)` 传入页面名。
- 右键选择器扩展到 `.item[data-rn], .pill[data-rn]`。
- 右键标签 → 控件菜单（删除/修改/加提示/清除），浏览器默认菜单被 preventDefault。

## 自证

Edge headless + CDP：右键 `.pill[data-rn]`（`5. 客厅卡 → 客厅`）→ 菜单标题
`主控 · #5 客厅卡`；点标记删除 → localStorage 写入 action=delete。

## 边界

- 跳动手势标签（✋）不是控件，不接控件菜单。
- 效果图右键仍是页面级 pin。
