# P-0257 全部 24 页设计图对照：运行时选中色 + 轨道/图表差异

> **检索别名**：所有界面检查 / 按钮绿色 / ui_behavior COLOR_ACCENT /
> 滑条轨道粗 / 进度条粗 / 图表网格 / D5 98.27。

- **时间**：2026-11-06
- **工程**：`w78-tabview-smart-home`
- **触发**：用户令——“不只是Wi-Fi界面，我说所有界面进行检查，和设计图差异”。

## 检查方式

1. D5 全量 24 页并排图逐页看；
2. 仿真器逐屏实拍 24 张，与设计帧对照（运行时才是真机口径）；
3. 自动化核对：A1–A14、按钮背景 vs 设计矩形、按钮文字色 vs 设计 `<text fill>`。

## 修掉的差异

| 差异 | 原因 | 修正 |
| --- | --- | --- |
| 仿真器选中按钮发绿 | `ui_behavior.c` 的 `COLOR_ACCENT=0x5FD3A6` | 改为设计琥珀 `0xF2B45C` |
| 开关选中绿、关闭灰 | EEZ 样板源工程色 | 改 `#F2B45C` / `#222B38` |
| Slider 轨道整条 20px | 触摸区高度被填满 | `pad_top=0, pad_bottom=14`，轨道 6px 贴顶 |
| Bar 轨道整条 20px | 同上 | `pad_top=4, pad_bottom=8`，轨道 8px |
| Wi-Fi 自定义页按钮白字 | `make_button` 未设文字色 | 增加 `fg`，按设计补色 |
| 图表网格线 | EEZ 画布预览默认 grid | EEZ 侧设 `line_opa=0`；**仿真器实际无网格** |

## 仍存在的差异（非阻塞）

1. **Slider 旋钮仍 20px**（设计 14px）：LVGL 旋钮尺寸跟对象高度走，保持 20px 触摸区就会偏大；
   要完全一致需改控件高度或运行时缩放，暂不做。
2. **字体字形/字重**：设计用系统字体多字号，工程受“镜像字库 ≤3 档、仅 1 档汉字”约束，
   只能近似映射到 cn12/cn24/cn32。
3. **EEZ 画布图表网格**：D5 截图有网格，仿真器/真机无；是画布预览差异。
4. **Wi-Fi 列表**：设计为空态，运行时是真扫描结果。
