# P-0139 · Run 预览画布坐标随窗口操作漂移：写死 clip 的连拍截到编辑器画布，制造"整体平移+假静止"双伪影

- **工程**：watch (Design Watch)
- **日期**：2026-10-17
- **工具**：Qoder
- **状态**：fixed
- **标签**：cdp,burst_shot,截图裁剪,canvas,假静止,误诊,测量伪影
- **关联提示词**：PR-0231

## 现象（看到什么）

三个连锁假象（各浪费一轮）：
1. 连拍图整列图标"右移 ~63px"——疑似 v7 引入的布局 bug（静态样式、生成 JSON 全查了一遍都正常）；
2. 随后连拍"完全静止、点击无响应"——疑似 Run 预览冻结/wasm 崩溃；
3. 蓝底白环特效"不渲染"——高阈值白色像素计数恒定，疑似叠层失效。

## 复现（怎么稳定重现）

burst_shot.js 写死 `clip:{x:755,y:283}` → 期间 EEZ 窗口被移动/Run 开关过 →
页面内 canvas 实际位置变成 @(576,281)（编辑器画布）或 @(692,281)：
clip 落点不再是 Run 预览，而是**编辑器画布**（它也在同一 renderer 里、也是 410×502）
→ 编辑器不跑 flow → 假静止；clip 与画布左缘错位 → 伪"整体平移"。
白环案是独立第三坑：抗锯齿后环像素亮度 ~150-240，`>200` 阈值+缩略图目检双重漏判。

## 根因（真正的原因）

① CDP `Page.captureScreenshot` 的 clip 是**页面坐标**，Run 预览画布在页面内的位置
不是常量（窗口拖动、Run 重开都会变）；② 编辑器画布与 Run 画布同尺寸同 renderer，
截错后从图上无法直接分辨；③ 检测阈值不贴背景亮度 + 缩略图目检跳过细节。

## 修复（做了什么）

burst_shot.js v2：**每帧截取前 `Runtime.evaluate` 自量最大 canvas 的
getBoundingClientRect** 作 clip（fixed 参数仅作显式覆盖）；判别动画存在性改用
"盘心质心轨迹 + 面积档位"这类连续量指标；观感结论前先放大裁剪图目检。

## 证据（数字 / 命令输出）

自量 rect 后：计步盘心 cy 轨迹 224.5→219.0→223.6 连续 ~1px 步长、蓝面积 4200↔4340
两档周期切换（≈1.2s/轮）；秒表表冠角绕 -90° 摆 ±8~12°；理疗外环带 63→73→63——
四条通道分立可测，此前"假静止/假平移"全部消失。

## 沉淀（新增断言 / 案例 / 文档）

PLAYBOOK §3.2 警示块（与 P-0138 并列）；skills §11.39；断言：
**凡按页面坐标截图/点击，先自量目标元素 rect，禁止沿用上一轮的写死坐标**；
"叠层不渲染"结论前必须：放大裁剪目检 → 借已知可渲染位图做受控二分 → 才允许怀疑控件。
