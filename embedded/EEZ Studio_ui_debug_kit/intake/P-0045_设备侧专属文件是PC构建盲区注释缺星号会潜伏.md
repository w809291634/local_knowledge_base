# P-0045 · 设备侧专属文件是 PC 构建盲区（注释缺 `*/` 潜伏到真机构建才爆）

- **日期**：2026-10-01（PR-0090）
- **工具**：WorkBuddy
- **症状**：真机 `idf.py build` 报 `-Werror=comment`（"/*" within comment）+
  `'cmd' was not declared`——`io_esp.cpp` 第 54 行 wifi TODO 注释漏写收尾 `*/`，
  吞掉 battery 段、`io_sample_inputs` 收尾 `}` 和 `io_wifi_command` 函数头。
- **根因**：`src/native/platform/io_esp.cpp` **只在设备构建编译**（PC 仿真选
  io_pc.cpp），G1-G5 门禁全绿也照不到它——TODO 注释块被手改/搬移时少个 `*/`
  就静默潜伏，直到第一次真机编译才爆，且报错位置（吞掉的下游代码）与病灶
  （缺 `*/` 的那行）相距数十行，容易误判。
- **规则**：凡改过 `io_esp.cpp`（哪怕只加注释/TODO），提交前：
  1. 数一遍 `/*` 与 `*/` 是否配平（一行 Python 即可）；
  2. 有条件就跑一次 `idf.py build`（或至少 `idf.py build` 前目检新增注释块）。
