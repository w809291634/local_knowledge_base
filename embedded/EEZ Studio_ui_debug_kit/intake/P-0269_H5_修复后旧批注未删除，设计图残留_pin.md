# P-0269 · H5 修复后旧批注未删除，设计图残留 pin

- **工程**：多参数监护仪 UI（multipara_monitor_ui）
- **日期**：2026-11-08
- **工具**：Trae
- **状态**：fixed
- **标签**：H5 / 批注 / 设计评审
- **关联提示词**：PR-0619 / PR-0620

## 现象（看到什么）

按 annotations.json 修改设计源并重生成 H5 后，浏览器 localStorage 仍保存已修复批注，设计图上继续显示红色 pin，用户误以为未修复。

## 复现（怎么稳定重现）

1. 在 H5 里右键控件/空白处添加两条 pin 批注并导出 annotations.json。
2. AI 按 JSON 改设计源并重生成 H5。
3. 刷新 H5：旧 pin 仍显示在设计图上，localStorage 里也仍有旧记录。

## 根因（真正的原因）

H5 只追加批注、不清理已处理项；重生成 HTML 不会清 localStorage。

## 修复（做了什么）

生成器维护 RESOLVED_ANN_IDS；H5 加载时过滤已修复 id 并回写 localStorage；交付前用 Edge/CDP 断言旧 pin 不存在、未处理批注保留。

## 证据（数字 / 命令输出）

多参数监护仪 H5：seed 两条已修复 pin + 一条保留 pin，刷新后仅保留 keep123，annTotal=1。

## 沉淀（新增断言 / 案例 / 文档）

- 模板 `tools/h5_overview_template.py`：新增 `RESOLVED_ANN_IDS`，H5 加载时过滤已修复 id 并回写 localStorage。
- 流程 `EEZ_FIRST_WORKFLOW_NO_FLOW.md` §2.0c：新增「修复后清理批注」检查项。
- 规格 `reference/14_h5_review_overview.md` §8/§10：写入规则与自测项。
- 交付断言：Edge/CDP 预置「已修复 pin + 保留 pin」，刷新后旧 pin 消失、保留 pin 仍在。
