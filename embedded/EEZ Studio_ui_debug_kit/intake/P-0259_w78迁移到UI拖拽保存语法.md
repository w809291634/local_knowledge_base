## 迁移

以 `eez-widget-templates/templates/` 为字段真值，保留 w78 设计值/样式/行为：

1. `design/eez_defaults.json` 的已用类型/组合样板：
   - 去掉 `hiddenFlag`、`checkedState`；
   - 补 `clickableFlag`、`flagScrollDirection`、`scrollSnapX/Y`、`group`；
   - 去掉 `widgetFlags` 里的 `CLICKABLE`（点击改由 `clickableFlag` 表达）；
   - 保留设计自定义 `localStyles`、颜色、字体、几何值；
   - Keyboard 保留 `textarea` 绑定字段，Screen 保留 `CLICKABLE`。
2. `design/eez_gen.py` 的 `no_click()` 同步设置 `clickableFlag=false`，
   避免装饰容器/进度条/图表被重新加回可点击。
3. `design/eez_check.py` 的 A14 允许：
   - `identifier`（放置/克隆时赋值）；
   - `hiddenFlag`（仅隐藏遮罩）；
   - Keyboard 的 `textarea`（绑定字段）。
   其余字段仍必须等于 UI 拖拽模板。
