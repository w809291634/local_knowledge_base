# P-0255 设计图与 EEZ 核对：开关/滑条/进度条配色对齐

> **检索别名**：设计图核对 / 开关绿色 / 滑条黄色 / 进度条绿色 / 设计色琥珀 /
> D5 98.19 / 灯详情 96.32。

- **时间**：2026-11-06
- **工程**：`w78-tabview-smart-home`
- **触发**：用户令——“核对一下设计图和eez”。

## 核对结果

D5 全量 24 页通过，但灯详情只有 95.89%，并排图显示三类控件颜色与设计源不一致：

| 控件 | EEZ 原色 | 设计源 |
| --- | --- | --- |
| Switch 选中轨道 | 绿 `0x34C759` | 琥珀 `0xF2B45C` |
| Switch 关闭轨道 | 灰 `0x3A3A3C` | 深灰蓝 `0x222B38` |
| Slider 轨道/填充 | `0x2A2A35` / 黄 `0xFFC531` | `0x222B38` / 琥珀 `0xF2B45C` |
| Bar 轨道/填充 | `0x2A2A35` / 绿 `0x2BD97C` | `0x222B38` / 琥珀 `0xF2B45C` |

设计源 `simple_control.ACCENT = #F2B45C`，`toggle/slider` 都用它；EEZ 样板仍带源工程的
绿/黄配色。

## 修改

只改 `design/eez_defaults.json` 的设计值（字段集不变，A14 不受影响）：

- Switch：`MAIN.DEFAULT/CHECKED`、`INDICATOR.DEFAULT/CHECKED` 颜色；
- Slider：`MAIN.DEFAULT` 轨道、`INDICATOR.DEFAULT` 填充；
- Bar：同上。

重新生成 EEZ、重构建、重跑 D5。设计源未改，D5 确认哈希不变。

## 仍存在的差异

灯详情滑条在 EEZ 里轨道仍比设计图粗：EEZ 控件高度 20px（触摸区），设计只画 6px 轨道。
这是“触摸区 vs 视觉轨道”的差异，未用 padding 收窄；要像素级对齐可再调 Slider MAIN 上下 padding。
