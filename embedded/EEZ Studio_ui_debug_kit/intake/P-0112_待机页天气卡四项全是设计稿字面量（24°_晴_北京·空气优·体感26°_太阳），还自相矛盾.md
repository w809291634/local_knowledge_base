# P-0112 · 待机页天气卡四项全是设计稿字面量（24° / 晴 / 北京·空气优·体感26° / 太阳），还自相矛盾

- **工程**：eez-test
- **日期**：2026-10-04
- **工具**：Qoder
- **状态**：fixed
- **标签**：静态文案,假反馈,天气,绑定,图标四态,UnboundLocalError,数据源待定
- **关联提示词**：PR-0173

## 现象（看到什么）

用户点单「修复天气，适配UI」。实况：待机页那张卡的温度、天气、明细、图标四项全不变；且大字写 24°、小字写 体感 26°，同一张卡自相矛盾

## 复现（怎么稳定重现）

开机进待机页看右上卡；断网、改时间、连任何网络，那张卡永远一模一样

## 根因（真正的原因）

build_ui.py:896-908 用 badge(...)+label(...) 直接写字面量，既没绑变量、native 也没有对应输入 —— 与 P-0100（待机页最近对话）、P-0111（设置页网络行）同一类：设计稿占位文案被当成实现交付

## 修复（做了什么）

四项全绑变量：weather_kind(int 0晴/1多云/2雨/3无数据) + weather_temp/cond/detail(string)。图标改为四态叠放靠 hiddenExpr 互斥（P-0080 语义），SYM 表补 cloud(F0C2)；温度 label 给**固定宽度** tw(88°,22)，否则绑变量后内容从 24° 变 -- 会把右边的晴拉动（P-0083 定宽同一类）。native_vars.cpp 加 4 组 getter/setter（input 型，setter 空）；io_pc 发演示值保截图基线，io_esp 发**诚实空态** kind=3 / -- / 暂无天气数据，并在注释里写清两条待选数据源方案

## 证据（数字 / 命令输出）

目检 build/sim_shots/01_standby.png：卡片与设计稿一致（24° 晴 / 北京·空气优·体感26° / 太阳），说明绑定链路通；门禁 all.py --sim = 9 屏 9.92% 无缺屏；_glyph_lint（venv 解释器）= DSL 可种 6864 码位、运行时中文 161 字全覆盖；真编译 4 文件 0 错 0 警。★ 中途 build_ui.py 直接崩：UnboundLocalError: icon —— 同一函数后面的 tiles 循环把模块级工厂函数 icon() 遮蔽成局部名（Python 整函数判局部），改循环变量名为 ic 后恢复

## 沉淀（新增断言 / 案例 / 文档）

通则再确认一次：设计稿里的状态类文案/图标不许留字面量。新记一条 DSL 陷阱：pane 函数里**不要**用 icon/label/box/badge 这些模块级工厂名当循环变量（本轮 tiles 循环用 icon 中招）。数据源待用户定：A Open-Meteo 免 key 走工作任务定时抓；B 小智服务端经 MCP 下发（与 P-0092 一起卡住）
