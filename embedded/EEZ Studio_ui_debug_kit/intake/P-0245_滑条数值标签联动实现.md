# P-0245 滑条→数值标签联动（in_read 行为接线）

> **检索别名**：滑条联动 / 开合随进度条 / 数值标签更新 / value_bind /
> LV_EVENT_VALUE_CHANGED。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`
- **背景**：开合/亮度等数值已定为 `in_read`，需要随滑条实时变化。

## 实现

新增 `src/native/value_bind.c/.h`，在 `ui_init()` 后由 PC/目标 main 调用 `value_bind_init()`：

| 滑条 | 数值标签 | 格式 |
|---|---|---|
| living_hw03_sl | living_r01 | `开合 %d%%` |
| master_hw03_sl | master_r01 | `开合 %d%%` |
| detail_curtain_hw01_sl | detail_curtain_r01 / r02 | `客厅 · 南向 · 开合 %d%%` / `%d%%` |
| detail_light_hw02_sl | detail_light_r01 | `%d%%` |
| settings_w03_sl | settings_r01 | `无操作后 %d 秒` |

- 事件：`LV_EVENT_VALUE_CHANGED` → `lv_slider_get_value` → `lv_label_set_text_fmt`。
- 色温（0–100 → 3000–6500K）暂不接，需单独值域映射；后续⑦补。

## 自证

临时 `W78_VALUE_TEST` 无头模式跑完即删：

```
[VALUE] light=55%
[VALUE] living=开合 42%
[VALUE] curtain=客厅 · 南向 · 开合 33% | 33%
```

## 注意

- 滑条对象是整卡交互的 `_sl` 子对象（compound），不是外层容器。
- 测试脚手架已移除，终态只保留 `value_bind.c/.h` 与 `value_bind_init()` 调用。
