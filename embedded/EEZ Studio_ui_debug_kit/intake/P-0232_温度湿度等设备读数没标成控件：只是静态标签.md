# P-0232 温度/湿度等设备读数没标成控件：只是静态标签

> **检索别名**：温度没标注 / 数值不是控件 / 读数控件 / value 类 / out_read /
> 湿度 电量 功率 百分比 / H5 数值没号。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`（24 屏）
- **触发**：用户指出温度这类从设备读取的值也应该是控件，必须标注。

## 根因

控制表原来只收录用户点名的交互件；设计帧里的温度、湿度、百分比、功率、电量、在线状态
都只是静态 `<text>`，生成器按 `st` 标签输出，既不在控件表也不在 H5 标注里。
（房间卡、设备格、只读卡里的读数同样漏掉。）

## 修复

新增 `design/values.py`，从同一份设计帧自动补 `value` 类控件行：

- 判定：带单位（°C / % / W / kWh / Mbps / ms / dBm / 次 / 分钟）的数字，或
  `开/关/在线/离线/已连接/已布防/强/弱/正常` 等状态词。
- 排除：标题（如“近 24 小时”）、说明（请/支持/约需/距离/调至/升温…）、
  开关/滑条小框里的状态字、按钮文案、输入框内容。
- 保留：宽卡片、房间格、只读卡里的读数（如房间温度、信号强度、电量、累计用电）。
- 生成：`value` → `out_read`（`hr` 码）→ 真实 `LVGLLabelWidget`；进入控件表、
  H5 高清设计图标注、EEZ 工程。

## 结果

- 自动补 **57 条读数**：总控件行 182 → **239**（out_read 27 → 84）。
- 例：主控天气/室内温湿度、4 个房间温度与湿度、房间格 80%/开合 70%、
  传感详情 23.5°/48%、插座 46W/今日 0.18kWh、安防电量 92%、能源占比 38% 等。
- `eez_check` A1–A12 **PASS**；导航 **72/72 PASS**；D5 当前 **98.03%**（最低 96.07%，
  工程已变，确认标记需刷新）。
- 资源：ESP32 `-O2` 只编译 **442KB（字体 236KB）**。
- H5 证据：`designer_annotated/h5_design_annotated.png`。

## 坑

- 单字“开/关”只有在字号 ≥20 时才算状态值；小号是开关右侧状态字，标了会重复。
- “近 24 小时（只读）”是标题，不是读数（含数字+单位也会误判）。
- 读数在卡片里也要标；只有“本身就是控件”的小框（开关/滑条/按钮/输入）不重复标。
