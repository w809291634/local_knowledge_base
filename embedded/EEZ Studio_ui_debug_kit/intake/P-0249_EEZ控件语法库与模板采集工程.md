> **检索别名**：EEZ 控件模板 / 新建控件语法 / 控件语法库 / eez-widget-templates /
> 拖拽样板 / 克隆控件 JSON / A10 / A13。

- **时间**：2026-11-05
- **工程**：根目录新工程 `eez-widget-templates`；经验库 `reference/eez_widget_syntax`
- **触发**：用户令——“以后严格按照流程要，现在可以新建一个 eez 控件模板，你可以在根目录中新建一个
  项目，表示获取 eez 控件的模板，然后将每个 控件的模板保存到经验库中，以后按照这个经验库来新建控件，
  就不会出现问题，我建议单独创建一个 eez 控件的语法库，这个语法库先添加 新建 初始控件的 模板语法。”
- **更正**：P-0249 初版只校验字段集，属性值还带源工程样式；后续又按 classInfo 复位（P-0250）。
  **现行模板已按 P-0258 用 EEZ UI 拖拽保存对象重建**，不再按本文或 P-0250 的复位口径判断。

## 问题

- 生成器此前从 `eez_defaults.json` 取控件样板，样板来源不透明，可能采到被改过的工程；
- P-0248 已证明：Switch 样板缺 `CHECKABLE` 会导致点击不切换；
- 手写或随手抓控件 JSON 会破坏字段集，触发 A10/A12/A13 门禁。

## 方案

1. **模板采集工程** `eez-widget-templates/`
   - `build_templates_project.py` 从**真实工程**提取拖拽创建的控件 JSON；
   - 归一化：objID → `__OBJID__/__STYLE_OBJID__/__LOCAL_STYLE_OBJID__`，
     清空事件/时间线，表达式字段改 literal 并给默认值；
   - 生成 18 页 gallery 工程（每页一个控件），用 EEZ CLI 无头构建验证；
   - `validate_templates.py` 初版只做字段集与关键标志体检；标准值校验见 P-0250。
2. **经验库语法库** `reference/eez_widget_syntax/`
   - `README.md`：用途、克隆步骤、硬规则；
   - `templates/<Type>.json`：19 种初始控件模板；
   - `manifest.json`：类型 → 源工程 / 源 identifier / 备注。

## 使用口径

- **新建控件唯一来源**：`eez-widget-templates/templates/*.json`（或经验库同名副本）；
- 克隆只改 identifier / 几何 / 文本 / 样式值，不得增删字段（A10）；
- Switch 必须保留 `CHECKABLE`（A13）；Button 文字在唯一子 Label（A4）；
- 表达式字段克隆后必须复位为 literal；
- 换样板只改 `build_templates_project.py` 的 `SOURCES` 后重跑，不手改 `templates/*.json`。
