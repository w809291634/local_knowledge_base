# P-0044 · 设置 tab 页数/顺序变更的三处同步点

- **日期**：2026-10-01（PR-0088）
- **工具**：WorkBuddy
- **症状**：设置从 3 页改 4 页（网络子页恢复）后，断言全绿但截图串位——
  09 出显示页、10 出唤醒页，内容整体偏移一位。
- **根因**：工程里「设置页序」存在 **三处独立副本**，改页数只改了一处：
  1. `build_ui.py` 的 `CATS` 表（rail 行 → tab 索引映射）✅ 改了；
  2. `sett_nav["onTabChange"]` 的 add 分组（换页高亮归属）✅ 改了；
  3. **`sim.py` 模板的 `nav_btn_for()` 设置层映射** ❌ 漏了 —— 仿真切页
     优先点分类按钮（走真机同款动作链），idx1/2 还指向旧页的按钮，
     于是「切到 1」实际点的是显示行。
- **为什么断言没抓住**：[wifi]/[swipe] 断言只查 `lv_tabview_get_tab_active`
  序号和高亮 CHECKED（序号与高亮都"正确"），只有截图目检能看到内容串位 ——
  **对照门禁只看 11 屏平均差异，单屏串位会被平均稀释，必须目检**。
- **规则**：凡动 sett_nav/main_nav/ai_nav/mus_nav 的页数或顺序，同步检查：
  CATS（或对应 rail 表）、onTabChange 分组、sim.py 的 nav_btn_for + VIEWS
  索引，四处一次改完；改完必看该层全部子页截图各一眼。
- **状态**：fixed（nav_btn_for 已按 通用0/网络1/显示2/唤醒3 重写）
