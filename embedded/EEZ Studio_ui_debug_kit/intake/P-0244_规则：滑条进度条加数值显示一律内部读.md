# P-0244 规则：滑条/进度条 + 数值显示，一律内部读 in_read

> **检索别名**：滑条数值 in_read / 进度条数值 / UI 自己控制 / 百分比跟随滑条 /
> 自动识别滑条旁数值 / 开合值分类。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`
- **用户令**：明显属于进度条/滑条 + 数值显示的组合，直接标内部读，不用逐条说。

## 规则

滑条/进度条与其数值显示成对出现时：

- 数值显示 = **`in_read`（内部读，UI 自己控制）**；
- 不标 `out_read`（外部读），也不当静态文本；
- 滑条/进度条本身仍是 `out_write`（控制硬件）或 `bar`；
- 生成器按“邻近滑条 + 数值后缀（% / K / 进度值）”自动识别，设计源只保留必要例外。

## 实现

- `design/values.py`：
  - `_near_slider()`：滑条/进度条框 ±20px（横）/±10px（纵）内、名称含 `%` 或以 `K` 结尾的数值 → `uivalue`；
  - `UI_READ` 显式补：`窗帘详情 70%`、`设置 无操作后 60 秒`、`添加设备·配网中 70%`；
  - `UI_READ_SUB`：所有含 `开合 70%`。
- `uivalue` 类 → `io_of = in_read`（`r` 码），EEZ 生成真实 Label；控件表类名「UI 读数」。

## 注意

- 邻近判断只收 `%`/`K` 等控件单位，避免把旁边的定时/状态文案误判（灯详情 `22:30 自动关灯` 已排除）。
- 进度条数值单独用显式映射，因数值常位于轨道下方。
- 滑条拖动 → 数值实时更新属第⑦步行为接线，本次只定分类与标注。
