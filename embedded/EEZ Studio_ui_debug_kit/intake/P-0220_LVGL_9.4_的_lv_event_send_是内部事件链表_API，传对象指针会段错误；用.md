# P-0220 · LVGL 9.4 的 lv_event_send 是内部事件链表 API，传对象指针会段错误；用 lv_obj_send_event

- **工程**：w78-tabview-smart-home
- **日期**：2026-10-30
- **工具**：Qoder
- **状态**：fixed
- **标签**：LVGL,event,API,段错误,导航,自证
- **关联提示词**：PR-0404

## 现象（看到什么）

导航自证程序 bind 完成后立刻段错误（exit 139），没有任何 FAIL 输出；同样代码在旧写法下无法跑断言。

## 复现（怎么稳定重现）

在 LVGL 9.4 下调用 lv_event_send(obj, LV_EVENT_CLICKED, NULL)，obj 是 lv_obj_t*；头文件实际声明是 lv_event_send(lv_event_list_t*, lv_event_t*, bool)。

## 根因（真正的原因）

lv_event_send 是内部事件链表 API，公开的对象事件接口叫 lv_obj_send_event；把对象指针当事件链表传，运行期解引用崩溃。

## 修复（做了什么）

导航自证改用 lv_obj_send_event(hit, LV_EVENT_CLICKED, NULL)；同时在 nav_init 里先 lv_obj_update_layout(scr)，否则子对象坐标还是 0×0，所有边都 MISS。

## 证据（数字 / 命令输出）

修复前 333 条边全 MISS/段错误；修复后 [NAV] bind edges=333 miss=0、RESULT edges=333 pass=333 fail=0。

## 沉淀（新增断言 / 案例 / 文档）

⑤ 导航自证代码；本记录。后续 LVGL 9.x 事件注入一律用 lv_obj_send_event，发事件前先 update_layout。
