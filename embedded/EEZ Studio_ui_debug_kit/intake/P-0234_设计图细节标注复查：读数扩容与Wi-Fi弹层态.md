# P-0234 设计图细节标注复查：读数扩到 97 条 + Wi-Fi 弹层态单独标

> **检索别名**：设计图细节没标 / 数量没标 / 状态没标 / 时间版本 / Wi-Fi 密码页没标 /
> 弹层控件 / 幽灵标注框 / 高清设计图细节。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`
- **触发**：用户要求复查设计图里是否还有控件（细节）没标注。

## 复查方法

1. 取每页设计帧的所有 `<text>`，排除落在已有控件框内的；
2. 人工分类：设备读数/状态 → 应标；标题、字段名、说明、空态、装饰字符 → 不标；
3. 检查弹层/对话框控件是否只存在于控件表、设计图上没有位置。

## 补标

**设备读数从 63 → 97 条**，新增类型：

- 数量：`12 个设备在线`、`4 个房间`、`18 个设备 · 4 个房间`、`3 条 · 2 条未读`；
- 状态：`已布防 · 离家模式`、`客厅 · 1080P · 已加密`、`设备已接入`、`正在连接…`、
  `网关离线…`、`客厅主灯已开启`、`设备未连接`；
- 时间/计划：`22:30 自动关灯`、`07:00 缓慢亮起`、`今晚 23:30`、`07:00 — 08:00`、
  `4 个动作 · 每晚 23:00 自动执行`；
- 信息：`版本 1.0.0 · 构建 …`、`网关 8C:4F:… · 在线`、`3000K`。

**Wi-Fi 弹层态**：

- 基础 Wi-Fi 页只标 base 控件（返回/断开/扫描/列表）；
- 新增两张展开态卡：`Wi-Fi 密码半页`（密码框/连接/关闭/键盘）与 `忘记网络`
  （忘记/断开/取消），用 `wifi_sheet_frame`/`wifi_dialog_frame` 渲染；
- 之前弹层控件的框被画在基础页上（幽灵框），已去掉；弹层卡编号是本状态内序号。

## 结果

- 控件行 245 → 279（读数 97）；H5 高清设计图默认全部带号；`eez_check` A1–A12 PASS；
  导航 72/72 PASS。
- D5 因用户要求不再反复开 EEZ，最新修正后的全量结果仍是 98.03%（确认标记待刷新）。

## 仍然不标（有意）

- 字段名/标题：电源、亮度、色温、模式、风速、上限、下限、设备名称、云台、主控、场景、房间…
- 说明/步骤：请保持、约需、仅支持、点「扫描」、添加后…
- 空态文案：本房间暂无设备；装饰字符：只读、✓、!、#。
- 场景动作描述（关闭/开启/调至 10%）属于配置文案，不是设备读数。
- 纯数字角标（通知未读“2”）暂不单独成控件。
