# P-0233 D5 抓错页：页树与控件树同名文本，点到 label 后拼了别的页面

> **检索别名**：D5 抓错页 / 相似度假高 / 并排图拼错页 / EEZ 树同名 /
> Pages tree / Widgets Structure / 客厅拼成 Wi-Fi 密码。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`
- **触发**：自查发现 D5 并排图上下不是同一页：客厅下拼了 Wi-Fi 密码页，灯详情下拼了主控。

## 根因

`d5_pages.py` 点树节点时按“文本等于页 ID”找元素，再取“含根页 main 的那棵树”。
加入设备读数控件后，页面里出现与页名同名的 label（主控页的房间卡「客厅/主卧/厨房/浴室」），
Widgets Structure 树也满足“含 main”，于是点到了 label 而不是 Pages 树里的 page 节点；
双击后画布没切页，`grab` 抓到的仍是上一页（Wi-Fi 半页/主控），但相似度仍 >20% 阈值，
被当成有效结果记录下来。

## 修复

- `CLICK_JS` 传入全部页 ID；只选**同时包含 ≥3 个页 ID 的那棵树**（Pages 树），
  再从这棵树里找目标 leaf；找不到直接 `MISS_TREE`，不再回退到任意同名元素。
- 命中自证保留；`MISS_*` 直接打印，不再吞成“画布未取到”。
- 新增 `D5_KEEP_ALL=1` 用于自查时保留每页并排图。
- 验证：客厅、灯详情重新抓图均为正确页；24 页全量重跑平均 **98.03%**，最低 96.07%（灯详情）。

## 坑

- 页名可能同时出现在 Pages 树和当前页 Widgets Structure；只靠“含 root”区分不够。
- 抓错页的相似度可能落在 96%~99%，光靠“差异>20% 重试”拦不住，必须限定树。
- 整轮只启动一次 EEZ；不要为了单页反复开关窗口（用户 2026-11-05 再次强调）。
