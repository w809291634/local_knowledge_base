# P-0227 · 仿真目检抓到三处布局/层序缺陷：筛选胶囊吞字、视频卡压行、场景格空胶囊

- **工程**：w78-tabview-smart-home
- **日期**：2026-11-05
- **工具**：Qoder
- **状态**：fixed
- **标签**：仿真,目检,z-order,布局重叠,胶囊,场景格,EEZ生成器
- **关联提示词**：PR-0509

## 现象（看到什么）

整屏仿真截图逐张看 24 页，发现：

1. 「全部设备」页的筛选胶囊（全部/灯/空调/传感/窗帘）**只有底色、没有文字**；
2. 「摄像头」页视频卡的「码率 1.8 Mbps · 延迟 120 ms」**压在「移动侦测」行标题上**；
3. 「主卧」晚安模式格右上角有一个**空胶囊**（有底色、没文字）。

## 根因（真正的原因）

1. 生成器把「与控件重叠且面积 < 2000」的装饰矩形判成 **over（画在标签之上）**。
   筛选胶囊 68×28=1904 < 2000 → 胶囊底被抬到文字上面，文字被盖住；同页的只读小药丸也一样。
2. 摄像头视频卡设计高度 300（104→404），而「移动侦测」行从 y=364 开始，
   卡片本身覆盖了两行；码率文字在 y=380，正好落在行标题上。
3. 设计源 `tile()` 对**所有**格子都画「详情」按钮，但控件表里场景格（晚安模式）只登记「执行」；
   生成器按控件表不生成按钮，只留下设计帧里的按钮底 → 空胶囊。

## 修复（做了什么）

- `design/eez_gen.py`：over 判据从 `面积<2000 或 min(w,h)≤10` 收紧为
  `面积<400 或 min(w,h)≤10`——只有信号条/圆点这类小件上浮，胶囊/卡片一律在下层。
- `design/pages.py` 摄像头帧：视频卡 300→252，内框 200→168，码率文字挪到 y=336（卡内）。
- `design/simple_control.py` `tile()`：`scene=True` 时不再画「详情」，只画「执行」。

## 证据（数字 / 命令输出）

- 24 屏整屏截图拼图：`designer_annotated/sim_ui_contact.png`。
- 修复后筛选胶囊文字可见、摄像头行不重叠、场景格无空胶囊。
- 导航 72/72 PASS；D5 24 页平均 **98.48%**（Wi-Fi 页 99.48%）；D1–D8 全 PASS。

## 沉淀（新增断言 / 案例 / 文档）

- over/under 阈值不再按"看着小"定，必须只放行细条与圆点。
- 设计源画了控件、控件表却没登记时，会留下"空壳"；这类视觉残留靠整屏目检抓。

  运行时文案不在子集里。修：标题/SSID/说明统一挂运行时字库 `cn12f`，按钮也挂 `cn12f`。
