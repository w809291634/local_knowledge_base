# P-0250 控件模板不是标准新建值：带入了源工程配色/字体/尺寸

> **检索别名**：模板不是默认值 / 新建控件标准模板 / 源工程样式残留 /
> defaults.json / classInfo.defaultValue / validate_templates。

> **已被 P-0258 取代（2026-11-06）**：现行模板以 EEZ UI 拖拽保存对象为准，
> 不再按 `classInfo.defaultValue` 复位；本条仅作历史记录。

- **时间**：2026-11-05
- **工程**：`eez-widget-templates`；经验库 `reference/eez_widget_syntax`
- **触发**：用户追问“核对的到底是不是新建一个控件获取的标准控件模板”。

## 核对结论

P-0249 的模板**字段集**来自真实拖拽控件，但**属性值没有复位**，带入了源工程的定制：

| 类型 | 原模板（源工程值） | EEZ 新建标准值 |
| --- | --- | --- |
| Switch | 60×30；iOS 绿/灰 localStyles | 50×25；localStyles 空 |
| Button | 84×30；蓝底 radius8；子 Label “刷新”+`cn14` | 100×50；子 Label “Button”，仅 align CENTER |
| Label | 448×26 px；“Two-State Styles” | 80×32 content；“Text” |
| Slider | 200×24；value 0 | 150×10；value 25 |
| Bar | 200×22；RANGE；animation 开 | 150×10；NORMAL；animation 关 |
| Arc | 60×60；value 0 | 150×150；value 25 |
| Dropdown | 200×40；“Red/Green/Blue/Yellow” | 150×32 content；“Option 1/2/3” |
| Led | 48×48；红色 | 32×32；`#0000FF` |
| Panel | 200×78；带子 Label | 300×200；无子控件 |
| Textarea | 340×40；oneLine；max 64 | 150×70；非 oneLine；max 128 |
| Scale | 448×48；0–100 | 240×40；10–40 |
| Checkbox | “Check me”；flags 缺 ADV_HITTEST | “Checkbox”；标准 flags |

结论：**P-0249 的模板是“真实但被改过”的控件，不是新建控件标准值。**

## 标准值从哪来

- 直接读取本机 EEZ Studio `app.asar` 里各控件的
  `classInfo.defaultValue` 与 `lvgl.defaultFlags`（新建拖拽时使用的同一份数据）；
- 落到 `eez-widget-templates/defaults.json`，19 类全部收录；
- 模板仍从真实拖拽工程取字段集，只把属性值复位为标准值。
- **采集动作不是拖拽模拟**：本工程不现拖控件；EEZ 工程 JSON 也不记录“是否拖拽过”。
  是否标准只看字段集、默认值、标志、localStyles 四项，已逐类校验。

## 修复

1. `build_templates_project.py` 增加 `apply_defaults()`：
   几何/单位/标志/文本/选项/值域/`localStyles` 全部按 `defaults.json` 复位；
   清空非 Button 子控件；删除 Roller 遗留 `visibleRowCount`。
2. Button 按 classInfo 标准：100×50 + 一个子 Label（“Button”，align CENTER）。
3. `validate_templates.py` 增加逐项标准值核对，任何非标准值 FAIL。
4. 项目 README、经验库 README、AGENTS 8、NO_FLOW ⑩、reference/07 写入“模板值必须标准”。
