# P-0274 · 读数 Label 用控件热区盒导致大数字整体偏移 8–10px

- **工程**：多参数监护仪 UI（multipara_monitor_ui）
- **日期**：2026-11-08
- **工具**：Trae
- **状态**：fixed
- **标签**：EEZ,Label,读数,热区盒,生成器
- **关联提示词**：PR-0625

## 现象（看到什么）

主监护 78/98 与设计图相比左移 8px、下移 9px，右侧数值卡成差异热点。

## 复现（怎么稳定重现）

设计源里同一 read 控件同时有「H5 点击热区盒」和「原文实测文字盒」；生成 Label 时取热区盒，B1 与设计 SVG 一等一比对即可看到 8–10px 偏移。

## 根因（真正的原因）

read 控件生成 Label 时用了 H5 控件热区盒，而不是设计原文实测盒。

## 修复（做了什么）

read Label 取原文字实测 x/y/w/h（y 再 -2 补偿基线），热区盒只给 H5 点击/标注。

## 证据（数字 / 命令输出）

78 包围盒 design(572,117)-(643,166) vs B1(572,117)-(639,167)；main 95.05%。

## 沉淀（新增断言 / 案例 / 文档）

- 生成器 read → Label 的几何只取原文实测盒（x / y-2 / w / h+4），热区盒不参与 Label 定位。
- 文档：NO_FLOW §2.2 规则 ⑮、`reference/16` §3 规则 8、CHANGELOG v0.9.189。
