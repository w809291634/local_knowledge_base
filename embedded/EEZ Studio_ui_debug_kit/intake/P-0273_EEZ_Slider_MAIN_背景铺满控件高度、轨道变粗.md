## 根因（真正的原因）

Slider 的 MAIN 背景是整控件高度，不能只靠 pad 得到 6px 轨道；轨道 y 需按设计 track.y 计算。

## 修复（做了什么）

独立 6px 容器当轨道，Slider MAIN bg_opa=0；top=track.y-9；KNOB pad=-4 得 16px 旋钮。
