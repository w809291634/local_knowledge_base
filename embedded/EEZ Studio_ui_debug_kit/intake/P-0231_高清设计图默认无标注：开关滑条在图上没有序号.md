# P-0231 高清设计图默认无标注：开关/滑条在图上没有序号

> **检索别名**：设计图没标注 / 高清设计图无序号 / 开关没标 / 滑条没标 /
> H5 标注 / marks:false / 标注开关。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`（24 屏，H5 182 条控件）
- **触发**：用户反馈设计图里很多控件（开关、滑条等）没有标注。

## 根因

控件表本身是完整的（182 条，含 28 开关 / 8 滑条 / 输入 / 图表），
但 H5 第三视图「高清设计图」生成时写死 `marks:false`：

```js
mark(p,{marks:false,lane:false,hotBack:true})   // vDesign()
```

分层总览、跳转演练、停靠栏放大图都有标注，唯独用户用来确认设计的主视图没有，
所以看起来“好多控件没标”。

## 修复

- `overview_pro.py` 增加 `marksOn = true`；高清设计图改为 `marks: marksOn`。
- 顶栏新增「标注：开/关」按钮，可一键看净图，默认开。
- 重生成 `designer_simple/overview_pro.html` / `.fragment.html`；
  `node --check` 通过，H5 统计 24 页 / 182 控件。
- 工作流补充：**高清设计图默认必须叠加全部控件标注（开关/滑条/按钮/输入/图表都要有号）**，
  不得以“无标注净图”作为唯一设计视图。

## 验证

- 高清设计图截图：主控 L1 的 4 场景卡 / 4 房间卡 / 头部按钮 / 安防 pill 全部有号；
  L2 房间格每格“整卡开关/滑条 + 详情”两条编号都在。
- 无头截图：`C:\Users\yjt54\AppData\Local\Temp\h5design.png`（过程件，可重拍）。
- 控件表同步注明：每条在 EEZ 中必须是真实控件（A12）。

## 说明

房间格这类“整卡就是开关/滑条”的控件，序号标在整卡左上角，代表整块交互区；
真控件是卡内的小开关/滑条（P-0230）。不是漏标。
