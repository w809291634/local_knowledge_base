# P-0252 智能家居 815 控件字段集统一到标准模板

> **检索别名**：所有控件从标准模板改 / 字段集不一致 / Button 子标签最小样板 /
> Slider valueLeft / Bar valueStart / hiddenFlag 基础字段 / A14。

> **已被 P-0258 取代（2026-11-06）**：现行模板是 UI 拖拽保存语法，**不含 `hiddenFlag`**；
> 本条"模板补 hiddenFlag 基础字段"的做法作废，仅作历史记录。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`；标准库 `eez-widget-templates`
- **触发**：用户令——“确认eez所有控件是从标准模板中修改过来的”。

## 核对结论

初查 **不是**：815 个控件里有 424 个字段集与标准模板不一致。

| 问题 | 数量 | 具体 |
| --- | --- | --- |
| Button 子 Label 是精简复合样板 | 104 | 缺 style/widgetFlags/units/children/eventHandlers 等 16 个标准字段 |
| 多 `hiddenFlag` | 104 Button + 203 Container + 1 Keyboard + 3 Textarea + 2 Wi-Fi overlay | 标准模板未带该基础字段 |
| Slider 缺 range 字段 | 8 | 缺 `valueLeft/valueLeftType/previewValueLeft` |
| Bar 缺 range 字段 | 1 | 缺 `valueStart/valueStartType` |

其余 391 个（24 Screen + 335 Label + 28 Switch + 3 Chart + 1 List）字段集本已一致。
所有控件都由 `fresh(DEFAULTS[...])` 克隆；`base()` 是死代码，没有手写控件。

## 修复

1. 标准模板补基础字段 `hiddenFlagType: literal`、`hiddenFlag: false`；
   `build_templates_project.py` 的 `_apply_fields()` 持久化该复位，重建 gallery 通过。
2. `design/eez_defaults.json`：
   - Button 子标签改为完整 `LVGLLabelWidget` 字段集，保留 align CENTER/font/颜色；
   - 补 Slider `valueLeft*`、Bar `valueStart*`；
   - 所有样板恢复 `hiddenFlagType: literal / hiddenFlag: false`；
   - 按钮子标签 `widgetFlags` 设为空，生成代码与迁移前逐行一致。
3. `eez_check.py` 新增 **A14**：逐控件字段集必须等于标准模板库，多/少字段即 FAIL。

## 口径

- **字段集**：必须等于标准模板（A14）。
- **值/flags/样式**：允许按设计修改；w78 的开关样式、容器去 CLICKABLE 等保留。
- `defaults.json` 只列 classInfo defaultValue；`hiddenFlag` 是基础字段，模板统一带 false。
