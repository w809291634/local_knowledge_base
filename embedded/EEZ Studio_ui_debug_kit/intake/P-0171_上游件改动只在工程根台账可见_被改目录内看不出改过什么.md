# P-0171 · 上游件改动只在工程根台账里可见，翻到被改目录看不出它被改过什么

- **工程**：watch-app-list-rxroller
- **日期**：2026-10-22
- **工具**：Qoder
- **状态**：fixed
- **标签**：移植,开源件,账单,就地可见,假门禁,正则全量比对
- **关联提示词**：PR-0284、PR-0285、PR-0287

## 现象（看到什么）

`src/native/rxroller/` 里同时躺着上游原文与补丁产物，但目录内没有任何说明；
要知道改了哪 14 处必须先知道工程根有 `PORTLOG.md`。
另外 PORTLOG 的账单表编号是 `1,2,3,4,5,6-10,7`，与 `diff -u` 的 14 个 hunk 根本对不上号。

## 复现（怎么稳定重现）

打开 `src/native/rxroller/`，问：这个 `.c` 相比上游改了哪几处？目录内答不出来。

## 根因（真正的原因）

改动记录写在了「离改动最远」的地方（工程根），而且账单表是手抄的，抄的时候编号就乱了。
更糟的是防漂移门禁最初写成「文档里有没有 `14 hunks` 这个串」——
文档里本来就有好几处，把其中一处改成 `99 hunks` 后门禁仍然绿，属于典型的存在式假判据。

## 修复（做了什么）

1. 新增 `src/native/rxroller/README.md`（就地账单：上游身份、5 个文件各自归属、
   14 个 hunk 逐条含上游行号与所在函数、撤回记录）。
2. 把 diff 导出件从工程根移进同目录 `Rxroller_port.diff`。
3. PORTLOG §3 表格按 `diff -u` 真实 hunk 头重排。
4. preflight 第 4 组改为**正则抓出文档里每一个 `<N> hunks`，要求每一处都等于实测值**；
   历史数字（撤回记录里的旧账单）改用中文量词 `10 个 hunk`，不参与对账。

## 证据（数字 / 命令输出）

```
OK   目录内有就地说明件 src/native/rxroller/README.md
OK   目录内有逐字对照件 Rxroller_port.diff
OK   目录说明件 记的 hunk 数全等于实测 14（文中 2 处）
OK   PORTLOG 记的 hunk 数全等于实测 14（文中 3 处）
```
反向：把说明件里一处改成 99 → `FAIL … 文档里出现了 [99]，实测是 14`。

## 沉淀（新增断言 / 案例 / 文档）

preflight 第 4 组 4 条新断言；经验库 [[feedback-port-open-source-keep-portlog]]
补「改动说明要与被改文件同目录」。
