# P-0238 H5 批注改为右键菜单：控件序号处弹出删除/修改/加提示

> **检索别名**：批注右键菜单 / 控件序号右键 / 删除控件菜单 / 页面落点 /
> 不要批注开关 / H5 交互改版。

- **时间**：2026-11-05
- **工程**：`w78-tabview-smart-home`
- **触发**：用户认为“批注开关 + 左键面板”效果不行，要求右键控件标注弹菜单。

## 改法

- 去掉 `批注：开/关` 与左键采集；批注入口改为**右键**：
  - 右键控件序号/本体 → 菜单：标记删除（可取消）/ 修改说明 / 在控件上加提示标签 /
    清除该控件批注；
  - 右键页面空白 → 在光标位置加提示标签；右键已有 pin → 修改/删除提示。
- 菜单用 HTML 浮层（fixed，自动夹在视口内），点空白/Esc 关闭。
- 删除仍只做 H5 预览（控件 opacity .18 + 红框「删」）；导出 `w78_annotations.json` 不变。
- 底部「N 条批注 · 导出并返回 ④」保留。

## 自证（Edge headless + CDP）

| 操作 | 结果 |
|---|---|
| 右键 `g[data-rn="2"]` | 菜单显示 `主控 · #2 离家按钮` |
| 点「标记删除」 | 控件 `opacity=.18`，localStorage 记录 action=delete |
| 右键页面 (400,192) | 菜单 `主控 · 页面` → 加提示 → 面板 `主控 · (400,192)` |
| 保存提示 | localStorage 出现 pin 记录 |

## 约束

- 右键菜单不改变控件左键跳转/停靠行为；批注关闭时红框/pin 仍显示。
- 浏览器不改工程；导出 JSON 给 AI 改设计源后重生成。
