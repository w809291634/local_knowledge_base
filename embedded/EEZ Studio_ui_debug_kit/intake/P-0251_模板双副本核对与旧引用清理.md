## 核对结果

| 检查项 | 结果 |
| --- | --- |
| 经验库 19 个模板 vs 工程 19 个模板 | 逐文件一致（`diff -r` 无输出） |
| 两边的 `defaults.json` / `manifest.json` | 一致 |
| 两边标准值校验 | 各 `[TPL_CHECK] PASS（19 个模板）` |
| 示例工程 gallery | 18 页；每页控件类型/identifier/值/flags/localStyles 与模板 0 不符 |
| 生成代码 `screens.c` | 18 种 `lv_*_create` 齐全；尺寸/文本/选项/值/颜色 0 不符 |
| Switch | 50×25，`lv_switch_create`，无 `remove_flag(CHECKABLE)` |
| 源工程样式残留 | 无 `cn14` / `5B7CFA` / `3A3A3C` / `34C759` / “Two-State Styles” |
| `manifest.json` 溯源 | 19 条源工程与 identifier 全部存在 |
| EEZ 构建 | `Build successfully finished` |

gallery 故意把控件放在 (40,60)，所以只跳过 `left/top` 比对；模板本身 `left/top=0`。

## 口径

- 采集动作仍是“真实字段集提取 + 按 EEZ classInfo 复位”，不是拖拽模拟；
- EEZ 工程 JSON 不记录是否拖拽，标准与否看字段集/默认值/flags/localStyles 四项；
- 两处副本内容相同，任一处改动后必须重跑校验并重新同步。
