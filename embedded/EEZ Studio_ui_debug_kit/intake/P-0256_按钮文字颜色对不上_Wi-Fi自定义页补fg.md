# P-0256 按钮颜色对不上：Wi-Fi 自定义页补设计文字色

> **检索别名**：按钮颜色 / 扫描白字 / 连接白字 / make_button fg /
> Wi-Fi 自定义页 / 按钮背景核对。

- **时间**：2026-11-06
- **工程**：`w78-tabview-smart-home`
- **触发**：用户反馈“我看到按钮颜色对不上”。

## 根因

- 通用页 `build_page` 会从设计帧 `<text fill>` 给按钮子标签写 `text_color`，背景从设计矩形取；
- **Wi-Fi 页是自定义 `build_wifi_page`**，`make_button()` 只设背景/圆角/字体，
  没有文字色，所以扫描、连接、忘记/断开/取消等按钮沿用样板白色：
  - 扫描设计是琥珀 `#F2B45C`，EEZ 白字；
  - 连接设计是深色字 `#05080F`（琥珀底），EEZ 白字；
  - 忘记设计是红字 `#FF7A6B`。

## 修改

1. `make_button(..., fg=None)` 增加文字色参数，写子标签 `text_color`；
2. `build_wifi_page` 按设计源补色：
   - 返回 T1 `0xF4F7FB`
   - 扫描 ACCENT `0xF2B45C`
   - 半页关闭 T2 `0xB9C4D4`
   - 连接 BG `0x05080F`
   - 忘记 RED `0xFF7A6B`
   - 对话框断开/取消 T1 `0xF4F7FB`
3. 通用页按钮仍由设计帧文字色驱动，不改。

## 自证

- 按钮背景 vs 设计矩形：**0 处不符**。
- 按钮文字色 vs 设计 `<text fill>`：实际不符只剩“‹ 变成 < / − 变成 - / › 变成 >”的字符替换，
  颜色本身正确；Wi-Fi 扫描/连接/对话框已对齐。
- D5：平均 **98.19%**、最低 **96.32%**、Wi-Fi **99.57%**（文字色修正前 99.56%）。
- NAV 72/72、UI 行为、flowtest/uitest/quittest、D1–D9 全 PASS。
