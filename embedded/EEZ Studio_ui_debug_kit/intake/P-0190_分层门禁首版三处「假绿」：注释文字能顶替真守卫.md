# P-0190 · 分层门禁首版三处「假绿」：注释文字能顶替真守卫

- **工程**：app-wifi-scan-conn-no-flow
- **日期**：2026-10-24
- **工具**：Qoder
- **状态**：fixed
- **标签**：门禁,假绿,include匹配,预处理指令,反向测试
- **关联提示词**：PR-0361

## 现象（看到什么）

新写的 [分层] 门禁对四种违例全部报绿：往 logic 里加 #include "../../ui/screens.h" 不报；删掉 pc 文件的 #ifndef WIFI_PLATFORM_DEVICE 不报。

## 复现（怎么稳定重现）

tmp/_negtest_layers.py：逐条注入违例跑 preflight --skip-cli，看 rc 与「违例」行。

## 根因（真正的原因）

三类写法错误：① include 匹配用 `#include "<needle>` 前缀串，相对路径写法（../../ui/screens.h）永远匹配不上；② 宏守卫用整文件 substring 判断，正文注释里提到宏名就算通过；③ 目录扫描只 listdir 一层，子目录里的文件不在覆盖面内（同 P-0188 族）。

## 修复（做了什么）

① 先把每条 #include 的目标规范化（剥掉前导 ../，同时登记全路径与 basename），再按 needle 等于或前缀命中规范化结果；② 宏守卫只认「strip 后整行等于 #ifndef/#ifdef 宏名」的预处理行；③ 覆盖面一律 os.walk 递归。

## 证据（数字 / 命令输出）

修复后四条规则各自 rc=1 并打印违例文件（app/ 建子目录、logic 引 screens.h、model 引平台头、pc 缺宏守卫）；全部复原 rc=0；preflight --with-sim 全绿。
