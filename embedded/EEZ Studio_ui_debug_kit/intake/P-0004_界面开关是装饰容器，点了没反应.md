# P-0004 · 界面开关是装饰容器，点了没反应

- **工程**：spilcd_spiopt_eez_lv_port_pc_tem_atks3
- **日期**：2026-09-23
- **工具**：WorkBuddy
- **状态**：fixed
- **标签**：交互,开关,控件类型
- **关联提示词**：（无）

## 现象（看到什么）

SmartHome/Light/AC/Security/Schedule/WakeWord 共 16 个开关点击无任何反应

## 复现（怎么稳定重现）

点任意开关，无状态变化（它不是控件，只是 box+圆点画出来的图形）

## 根因（真正的原因）

build_voice_ui.py 的 switch() 用 box()+box() 画了一个胶囊和一个圆点（装饰容器），容器默认不可交互；EEZ 其实有原生 LVGLSwitchWidget，但 json2eez.py 的 TYPE_MAP 没登记该类型

## 修复（做了什么）

json2eez.py 注册 switch->LVGLSwitchWidget + FLAGS(含 CHECKABLE) + checkedState；build_voice_ui.py 的 switch() 改为输出真控件（MAIN/INDICATOR/KNOB 三 part 配色）

## 证据（数字 / 命令输出）

工程内 LVGLSwitchWidget=16、checkedState=16；screens.c 内 lv_switch_create=16；LVGL lv_switch.c:124 构造函数自带 LV_OBJ_FLAG_CHECKABLE（点击即原生切换）；门禁 A8 仍 46/46/46、G2/G3/G4 PASS

## 沉淀（新增断言 / 案例 / 文档）

新增断言 A9（生成码用到的部件必须在 lv_conf.h 开启，防『本地能跑、上机炸』）
