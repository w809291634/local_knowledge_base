# 动效素材：渠道与筛选流程（2026-10-30 定，watch2 实测）

用来回答两个问题：**去哪里找 UI 动效**、**怎么把一堆候选筛到能用的那一两个**。
本文件只讲"素材获取与筛选"；落地播放方式见 NO_FLOW §2.0 与各工程 `SPRITES`/`ANIM` 口径。

## 1. 渠道清单（按实测可用性分三档）

### A. 可直接抓（不用登录、不经 Cloudflare）★ 首选

| 站 | 拿什么 | 抓法 | 授权 |
| --- | --- | --- | --- |
| **lottiefiles.com** | Lottie 动画的 GIF 预览 | `GET https://lottiefiles.com/free-animations/<单词>` 的 HTML 里直接有 `assets-v2.lottiefiles.com/**.gif`，一页约 50 个 | Lottie Simple License；**选中后必须回动画页确认是 Free 还是 Premium** |
| **opengameart.org** | 精灵表 / 逐帧 | `GET /content/<slug>`，页面里 `/sites/default/files/*.png|gif`；授权写在 `License(s):` 后 | CC0 / CC-BY / CC-BY-SA / GPL，逐条看 |
| **commons.wikimedia.org** | 体育/生活类 GIF | API：`action=query&list=search&srsearch=filemime:image/gif <词>&srnamespace=6`，再 `prop=imageinfo&iiprop=url|size|mime|extmetadata` | 多为 CC BY-SA / CC0 / PD，`extmetadata.LicenseShortName` 直接读 |

**LottieFiles 的 slug 只认单词**：`running` `jogging` `workout` `fitness` `sprint` 都能出卡片；
`running-line` 这种多词 slug 返回的是一张没有卡片的通用页（实测 0 个 GIF）。想要另一种风格就换单词，别再拼短语。

### B. 站点能开但抓不到文件（别浪费时间爬）

- **icons8.com / iconscout.com**：curl 直接吃 `Just a moment...`（Cloudflare 5 秒盾），HTML 里没有任何动画资源地址。
- **lordicon.com**：页面 200 可读，但下载/JSON 要走账号。
- 结论：这几家**只适合让用户自己登录下载**，AI 侧不要试图抓。

### C. 不能进产品（只能当参考）

- Giphy / Tenor / soogif：网友上传，版权不明。
- 千图/包图/千库/摄图/站酷海洛：要会员，授权书要单独下载存档；能用于产品但必须留凭证。

## 2. 筛选流程（一步步）

**给用户看的一步步（用户自己也能照着做）**

1. 说清需求即可（如"要心跳动画"）；风格轴（线条/扁平/实心/像素）只当**标签**不当过滤器，所有类型进同一张总览（§7）。
2. 打开 `lottiefiles.com/free-animations/running`（或 jogging/workout/fitness/sprint），搜索框里换词可以继续扩。
3. 鼠标划过卡片就能看到"在动"，先按风格挑 5~8 个，记下画面特征（"线描小人""扁平跑步女"这种），别记标题——**站内标题和卡片经常错位**。
4. 挑中后进它的动画详情页，看右上角是 **Free** 还是 **Premium**，记下作者名。
5. 需要单色效果时告诉 AI"要线条/要染成强调色"，AI 会把整条动画染成单色再出预览。

**给 AI 的一步步（可脚本化）**

1. 抓候选：`GET https://lottiefiles.com/free-animations/<单词>`，正则取 `https://assets-v2\.lottiefiles\.com/[^"']+?\.gif`，去重后每页 ≈50 个。
2. 批量下载预览 GIF（每个 30~2500 KB），得到"候选池"。
3. **抠底**：取像素四角，若四角同色（白/灰/绿底都常见），把 |RGB−角点色| ≤18 的像素置透明；四角不同色视为真透明，跳过。
4. **量化筛风格**（见 §3 判据）：算 ink（可见像素占比）、颜色数（RGB//40 量化后去重）、细度（`边界像素/可见像素`）。
5. **染色**：取 alpha 通道 + 目标色填充（`纯白` 或 `STYLE["accent"]`），得到可直接上深色界面的版本。
6. **出全览**：统一 200×200 格、保留各自原速，写成**一张** SVG（`<image href="x.gif">`，10 列网格、连续编号、一页滚动），浏览器打开即循环；全类型合格件都上页，编号给用户点选（§7）。
7. 用户选定后：核准标题/作者/授权 → 拉 Lottie JSON 或帧序列 → 写 `PORTLOG.md`（URL、授权条款、作者、下载日期、每帧/每文件 SHA256）。
   **JSON-LD 对账法（2026-11-01 实测，解坑 1 的标题错位）**：free-animations 页 HTML 内嵌 JSON-LD，
   每条记录形如 `{"@type":"ImageObject","contentUrl":"<预览gif>","name":"<标题>",...isPartOf.url:<详情页>,creditText:<作者>}`
   —— **gif 与紧随其后的 name 同属一条记录**（不是前一个）；按 contentUrl 定位后取后向的 name/详情页，
   再 GET 详情页，`<title>` 以 "Free" 开头即 Free 款。两步可脚本化，不用人眼对卡片。
8. 播放方式三选一，第④步按实测定：`lv_gif` 直播 GIF（最省事）/ 转帧序列（可控） / ThorVG 播 Lottie JSON（体积最小，P4 无 GPU 要量每帧耗时）。
9. **收口必做**：把在用的每张原件归进一个专用目录（如 `design/assets/_originals/`）并出清单（§8），换过件的停用帧表直接删。

## 8. 原件归集与留档（2026-11-03 用户定）

- 一个工程只留**一个原件目录**：放"当前设计源引用的每张动图"的站内原始 GIF（未裁框、未染色、未压缩）。
- 同目录写 `MANIFEST.md`：页面 → 帧表 → 原件 → 名称/作者/许可 → 直链 → 字节数 + SHA256；机器可读版 `manifest.json` 一起给。
- 收集脚本**已存在不重下**（站内会重渲染同一 GIF，重下会把凭证换掉）；缺件才按 meta 里的直链补。
- 校验分三层：SHA 一致 → 同源；SHA 不符 → 目检首帧 + 对"去重帧数/整轮时长"，画面一致即留，注明"站内重渲染"；出厂时序一律以帧表 `meta.json` 为准。
- 停用/候选帧表（换掉的旧件、未接入的备选）**删**，留档职责由原件目录承担；台账里指向它们的行同步改写，不留"已删除"式修订注。


## 3. 判据（watch2 实测数字）

| 风格 | ink（可见占比） | 颜色数 | 细度 | 实测样本 |
| --- | --- | --- | --- | --- |
| 线描 | < 0.10 | ≤ 8 | > 0.30 | `001.gif` ink=0.04、6 色 → 线描跑步小人（选中） |
| 单色实心 | < 0.10 | ≤ 8 | < 0.25 | `008.gif` ink=0.05、8 色 |
| 扁平插画 | 0.05~0.20 | 20~70 | — | `004/030` 跑步女（20~40 色） |
| 像素/游戏精灵 | 视尺寸 | 多 | — | OpenGameArt 50×50 精灵表 |

**三个坑（都踩过）**

1. **标题错位**：从 DOM 上下文抓的标题与卡片不一一对应（抓出"跑步舞"其实是咖啡杯）。命名以画面为准，授权以详情页为准。
2. **假透明**：有些 GIF 用棋盘格画"透明"，角点键色会把棋盘留下；这类直接剔除。
3. **抠底后帧被合并**：PIL 保存 GIF 会丢掉与上一帧完全相同的帧，**但不补时长**；循环会变短，必须自己合并重复帧并累加时长（详见 intake P-0216）。

## 4. 授权口径（医疗/对外产品一律照此）

- **CC0**：可商用、免署名，最省事；账里记来源即可。
- **CC-BY**：可商用，**必须在说明书/致谢署名作者**。
- **CC-BY-SA**：署名 + **改动后的图要同样开源**；改过色/裁过尺寸就算改动，慎用。
- **LottieFiles 免费区**：Lottie Simple License，可商用；**每个动画仍要单独确认 Free/Premium**。
- 所有素材入库都要在工程 `PORTLOG.md` 记：URL、授权条款原文、作者、下载日期、SHA256；注册资料要能追溯。

## 6. 精灵动图合成三坑（watch2 2026-10-30 实测）

1. **底图必须跳过精灵控件。** 逐帧动图叠在整页底图上时，底图里若还画着精灵控件，第 0 帧小人就留在背景里，第 1 帧起"两个人重叠"（用户原话："和背景图片中的人重叠了"）。落地：`compose_page(page, skip_ids=(精灵控件 id,))`。
2. **坐标单一真值。** 控件 x/y/size 与 `SPRITES` 的 anchor_pick 必须是同一组值；两套值漂移就会出现"预览图和动图不一致"。渲染期断言"控件值 == 口径值"，不等即漂移告警。
3. **门禁要量化且做反向测试。** 幽灵像素门禁：数底图精灵区内染色像素，跳过→0 静默、不跳过→460 检出；表圈门禁：bbox 四角须在内圈安全半径（屏心−8）内，越出告警"骑在表圈上"。取色阈值用 alpha>60：细线款缩到 48px 后单像素 alpha 常 <200，用 200 会空集报错（SLP-155 实测），并兜底空集。

落地：watch2 `design/design_sprite.py page_with`、`design/design_view.py _check_sprite_overlap`；见 P-0222。

**进 EEZ：用 AnimationImage 控件（不是静态 Image）**。EEZ `LVGLAnimationImageWidget` 映射 LVGL `lv_animimg`，
属性三件套 `images`（帧位图名数组）/ `duration`（整轮 ms）/ `repeatInfinite`；帧位图按显示尺寸内嵌 bpp32（保透明）。
样板＝`EEz_stidio_examples/w1-animation-image`（build_example.py 生成 JSON；CLI 构建后确认 `ui_image_*` 与字体已产出）。
watch2 实测：12 个 animimg + 383 帧，④-A 321/321 差异=0、PC 仿真链接通过；Flash ≈ 383×48×48×4≈3.5MB（可再压 bpp16）。
编辑器画布只显示首帧，播放看 Run/仿真/固件。

**性能：只播当前页（默认配置，2026-11-03 用户定）**。lv_animimg 在隐藏屏上仍走定时器；
切屏事件里对当前屏 `lv_animimg_start`、其余 `lv_animimg_delete`（watch2 实测 14 条定时器不再空跑，+2KB Flash）。
该模块由生成器默认产出（`emit_watch_anim()` → `src/native/navigation/watch_anim.c`），**不是手工补丁**；
帧数默认 **每页 20 帧、单帧间隔 ≤100ms**（I4 → 精灵帧 464KB、P4 app 1.49MB）。
顺带：帧名必须与生成器一致——用**原始帧下标**（f00/f02/…），别按抽取序号重命名，否则引用的还是旧帧。

**清晰度四条（2026-11-02 watch2 实测，用户报"图像被压缩"后定）**：
1. 帧按**显示尺寸**用 LANCZOS 缩好再内嵌（别嵌 160px 原画布、也别用最近邻），位图 bpp32/ARGB8888 保透明不量化。
2. 上屏尺寸取布局安全余量的**上限**（圆表上带 60px：离表圈 12px、离标题 11px），48px 在 466 屏上偏细。
3. 嵌帧必须应用 `tint`（alpha + 页面色），否则 EEZ 显示原始帧、与设计图不一致（本例小人曾显示白/橙而非黄）。
4. 判"糊"必须**同尺度**对比（设计页 PNG vs 仿真截图，1:1）；200px 预览格 vs 48px 上屏不能下结论。编辑器放大看位图有锯齿是显示层现象。另：CLI 构建后必须补烘字体（P-0140），否则文字/链接出问题。

## 7. 全量单页总览（2026-11-01 用户定，替代"一次只做一种风格"）

用户给一句需求 ⇒ AI 把词表扩全：同义词+动作词+器械/场景词+形状词（40+ 词起步，`?page=N` 翻页翻到空为止），
一次抓完、全类型合格件放**同一张 SVG** 供用户滚动挑；不再按风格分多轮小批量问。
**搜索广度是硬要求（2026-11-01 用户重申）**：每一个动图需求都跑满本流程——词表只扩不缩、翻页到空、合格件不设上限，宁多勿少；不存在「少搜一点先给看看」。

**判据分层当标签、不当单一过滤器**：① 风格（线描/单色/扁平，ink/色数/细度）② 节拍（逐帧面积占比摆幅
ratio+峰值数，专捞"缩放跳动"类）③ 形状（参数轮廓模板 IoU，如心形 0.65~0.70 阈）④ 深底（四角同暗色，
直接适配深色表盘）。每件带标签，**语义最贴用户原话的置顶**（如"心+ECG"组排最前）。

**教训（watch2 心跳件三轮返工）**：只用风格判据会把对口的件挡掉——心形+ECG 款首帧近空、ink 极小，
被"线描 ink<0.10"筛了三遍才靠节拍判据捞出。首帧空的件一律改测全帧并集。

**执行入口（照抄即可，下个需求 5 分钟起跑）**：工程侧脚本三件套——`design/anim_search.py`
（抓页/抠底/逐帧染色/打分公共函数）、`design/anim_*_full.py`（整页普查主线：GROUPS 分组词表 →
翻页到空 → 下载 → 分层打标签 → 单页 SVG 前缀编号）、`design/anim_heart_shape.py`（参数轮廓 IoU 形状筛）。
新需求＝复制 `anim_*_full.py`，只改 GROUPS / 输出目录 / 编号前缀；watch2 实测：消息页 40 词 → 830 下载 → 614 格单页，
睡眠页 44 词 → 1300+ 下载。选定编号后走 §2 步骤 7（JSON-LD 核授权）+ §6 合成门禁 + PORTLOG 记账。

**提速版（2026-11-02，默认用它）**：`design/anim_fast.py::sweep_fast(page, prefix, groups, budget)`——
① `analyze()` 一次采样同时出节拍+风格（旧版两函数各解码一遍），8 帧×96px + numpy 向量化：打分 1.6s → 284ms/件，
6 线程有效 ~73ms/件；② 全局 CDN 缓存 `_cdn/<md5(url)>.gif` + 全局分数库 `_scores.json`，跨页/重跑直接命中；
③ 抓页 4 线程、下载 6 线程；④ 扫页**不重编码 GIF**（SVG 直接引用原始 gif），只对最终入选件抽帧/染色。
实测 700 件整页：冷跑 277s、全缓存 127s（旧流程约 20 分钟）。旧账本 `catalog.json` 可硬链接灌 CDN（一次 6000+ 件）。
