# B20 仿真器滑动调试与设计对照（逐拍注入取证 + 四方对账）

> **检索别名**：仿真器调滑动 / 滑动跟手怎么验证 / 无头回归 / 逐拍注入 / 中间帧截图 /
> 设计与仿真对比 / 设计源单一真值 / 声明层对账 / 界面差异怎么判 / PC 仿真滑动看不见。
>
> 与 [B19](B19_表盘自环Tabview（单滚动带循环＋磁吸自愈＋边缘过界手势）.md) 的关系：
> **B19 是"滑动怎么长成这个样子"（结构/机制），B20 是"怎么在仿真器里把它调出来、怎么证明设计图与运行图一致"（工装/判据）**。
> 两者配套使用：先照 B19 定结构，再照 B20 建回归与对照。

## 现象

1. 在 PC 仿真器里调横滑：鼠标拖动**要么完全没反应，要么时灵时不灵**，
   同一个手势在 EEZ Run 预览里正常、在仿真器里不触发；无法靠"手感"判断对不对。
2. 只有"页面切过去了"这一个观察点时，**内容偏半页、点不同步、松手瞬间画面跳变**这类问题
   全都看不出来——切页逻辑是对的，画面是错的。
3. 设计图（`designer/*.png`）与运行态（EEZ 画布 / PC 仿真器快照）**多源**，
   肉眼并排看很费劲，也没有"差多少算不合格"的判据，改一次界面就要人工重看 25 页。

## 证据

1. **SDL 鼠标注入在无头模式下不可用**（本项目实测）：仿真器进程里 indev 状态已是 `PRESSED`，
   但 `act_obj = NULL` → LVGL 拿不到按压对象，手势链根本不启动。
   独立 POINTER indev 逐拍喂点则完全可复现。
2. **LVGL 手势"低速清零"**：每次读点 `|v| < 3px` 即清空 `gesture_sum_x/y`，累计满 `50px`
   才发 `LV_EVENT_GESTURE`（常量硬编码、无 API 可调）。SDL 逐事件直通时粒度 1–2px，
   慢速段反复命中清零 → 攒不满。**"预览正常 ≠ 仿真器正常 ≠ 真机正常"**（详见 B13）。
3. **只断言逻辑状态不够**：一次复现里逻辑槽位正确（指示点高亮正确页），
   但 `scroll_x` 落在 `2.7 页宽`处、内容整体右偏 ≈70px。
4. **声明层对账能量化**：`audit_declared.py` 输出
   `声明条目 353 / 工程控件 353 / 页 25 / 字体 11 / 位图 14，差异=0`。
   一旦设计源与工程不同步（漏控件/漏字体/漏页），这里立刻非 0 退出。
5. **画布抓图有硬前置**：EEZ Studio 会话内字体提取约 90s，早抓的图中文是缺字/方框（P-0125）。
6. **字节序**：`LV_COLOR_FORMAT_XRGB8888` 在小端下内存序是 `B,G,R,X`，正好等于 32 位 BMP 的
   `B,G,R,0` 像素序 → 仿真器可以直接写 BMP，**不需要**像 B8 那样在 Python 侧对调通道
   （对调一次就把颜色搞反，是 B8 的经典误判）。

## 曾经的误判

1. **直调状态机 = 验证了滑动**（第一版回归直接 `watch_nav_test_left_from()`）
   → 绕过了手势层与滚动器，"能切页"只证明状态机自洽，证明不了跟手。
2. **在仿真窗口里用鼠标拖**：以为拖得够快就行。实际是无头/窗口下 SDL 注入都不稳定，
   而且输入粒度与真机不同，结论不可迁移。
3. **断言"逻辑槽位 == 目标槽"就算过**：掩盖了"内容偏半页"（见证据 3）。
4. **松手后立刻截图**：归位动画 180ms 还没跑，截到的是"松手瞬间"，
   与其他时刻混在一起比较，误判成"画面突然消失"。
5. **以为 `compare.py` / `sim.py` 现成可用**：本工程里两者是**占位脚本**（直接 `sys.exit`），
   对比判据必须自己接（见下面的四方对账）。

## 真因

> 滑动与界面一致性都**不能靠肉眼**，要靠两类可复现的机械判据：
> ① 交互层——**逐拍注入 + 物理量断言 + 中间帧截图**；
> ② 界面层——**单一设计源派生四方产物 + 声明层对账 + 运行态截图对照**。

- 交互能否跟手，取决于**滚动器收到的连续位移序列**，而不是"最终落在哪一页"。
  所以必须自己造一条"每拍都有位移"的输入流（相当于真机 30ms 轮询）。
- 界面是否一致，取决于**同一份设计数据**是否同时驱动了效果图、EEZ 工程、标注图和运行代码；
  任何一环手工改动都会漂移，所以判据要落在"声明条目的对账"上，而不是"看起来差不多"。

## 修法

### A. 滑动怎么实现（结构 → 事件 → 参数）

#### A1. 单滚动带结构（跟手的唯一来源）

设计源把滚动宿主 `strip_host` 放成 watchface 页的**第一个控件**（EEZ 按声明顺序创建，
宿主必须先出生），其余表盘控件在 init 时整体搬进槽 0：

```c
/* strip_host_init()：宿主=表盘屏子件，槽 0 装表盘内容（永久不搬回） */
lv_obj_t *tab = strip_new_tab(host, 0);
uint32_t i = 0;
while (i < lv_obj_get_child_count(objects.watchface)) {
    lv_obj_t *c = lv_obj_get_child(objects.watchface, i);
    if (c == host) { i++; continue; }        /* 宿主自己留在屏上 */
    lv_obj_set_parent(c, tab);
}
```

槽位约定：`0=表盘 → 1..N=勾选功能页 → 末槽=「+」页`，页宽 = 屏宽 466。
功能页内容只在**表盘屏激活时**搬进槽（离开就搬回各自 screen），否则从其他入口进来会是空页：

```c
go_screen(scr):  scr == watchface ? strip_home()     /* 滚回槽 0 + attach */
                                  : strip_release(); /* 内容搬回各自 screen */
```

#### A2. 宿主配置（每一条都对应一个已修的 bug）

```c
lv_obj_set_scroll_dir(host, LV_DIR_HOR);
lv_obj_remove_flag(host, LV_OBJ_FLAG_SCROLL_ELASTIC);   /* 边界不弹：槽0右拉时 main 一动不动
                                                           lv_indev_scroll.c:647 边界 elastic_diff 钳 0 */
lv_obj_remove_flag(host, LV_OBJ_FLAG_SCROLL_MOMENTUM);  /* 不要甩动（会跨多槽） */
lv_obj_remove_flag(host, LV_OBJ_FLAG_GESTURE_BUBBLE);   /* 手势接收点 = 宿主自己 */
lv_obj_add_flag(host, LV_OBJ_FLAG_EVENT_BUBBLE);        /* 按压事件继续冒泡到屏（拉窗用） */
lv_obj_remove_flag(objects.watchface, LV_OBJ_FLAG_SCROLLABLE);
```

子树上必须**补回**两个 flag（EEZ 生成物会按"属性面没勾"显式去掉）：

```c
enable_scroll_chain_tree(tab);   /* SCROLL_CHAIN_HOR：控件上起手也能把拖动交回宿主 */
enable_gesture_bubble_tree(tab); /* GESTURE_BUBBLE：非默认 flag，不补按压事件停在控件上 */
```

#### A3. 三个滚动事件的分工

```c
lv_obj_add_event_cb(host, strip_scroll_begin_cb, LV_EVENT_SCROLL_BEGIN, NULL);
lv_obj_add_event_cb(host, strip_scroll_cb,       LV_EVENT_SCROLL,       NULL);
lv_obj_add_event_cb(host, strip_scroll_end_cb,   LV_EVENT_SCROLL_END,   NULL);
```

- `SCROLL_BEGIN`：**先判"本层程序化滚动"**（`s_strip_anim_program || s_strip_suppress_end`）→ 直接
  `drag_from = -1; return;`；再判"正在拉快捷窗"→ 放过；最后才记录用户拖动起点
  `s_strip_drag_from = s_tab_slot`，末槽时顺手 `strip_loop_arm()` 预放槽 0。
- `SCROLL`：只做一件事——拉窗期间把 `scroll_x` **当场钳回 0**（自愈，不用"临时关 SCROLLABLE"，
  后者漏一次 RELEASED 就永久滑不动）。
- `SCROLL_END`：**每次重算落点**（自愈），绝不用一次性异步闸门。

#### A4. 磁吸落点（自愈式，不用 `lv_async_call`）

```c
if (s_strip_drag_from >= 0) {
    int start = s_strip_drag_from * W, turn = W / 8;      /* 1/8 页宽 ≈58px */
    if (x >= start + turn)      slot = s_strip_drag_from + 1;   /* 一次最多翻一页 */
    else if (x <= start - turn) slot = s_strip_drag_from - 1;
    else                        slot = s_strip_drag_from;
} else slot = (x + W / 2) / W;                            /* 程序化：最近槽 */
s_strip_drag_from = -1;
if (slot < 0) slot = 0; if (slot >= n) slot = n - 1;

if (LV_ABS(x - slot * W) > 2) {          /* 没对齐：立刻起归位动画（只启动 anim，不重入滚动器） */
    s_tab_slot = slot; quick_tabs_show(slot);   /* 指示点先跟到目标页 */
    strip_scroll_only(slot, LV_ANIM_ON);
    return;
}
```

状态位职责（缺一个就会出"卡半页 / 点不同步 / 抢滚动"）：

| 状态位 | 作用 |
|---|---|
| `s_strip_suppress_end` | 程序化**瞬时**滚动会同步发 `SCROLL_END`，必须屏蔽 |
| `s_strip_anim_program` | 下一次 `SCROLL_BEGIN` 是本层起的动画 → `drag_from=-1`，绝不当用户拖动 |
| `s_strip_drag_from` | 用户拖动起始槽；`-1` = 程序化。用于 ±1 钳制与 1/8 阈值 |
| `s_strip_loop_pending` | 槽 0 已临时排到末尾（循环切页预备） |
| `s_strip_loop_canceling` | 循环没拉过去：**先动画吸回末槽，END 再搬槽** |

`strip_scroll_only()` **只滚不改状态**；要同步状态/指示点必须显式写
（否则归位完成时 `slot == s_tab_slot`，指示点永不重建——这是"点不同步"的根因）。

#### A5. 末槽左滑回 main（像普通换页，不是回卷）

```c
/* arm：槽 0 临时排到末槽右边，只扩范围不滚动（此刻屏幕是末槽，搬动不可见） */
lv_obj_set_pos(s_strip_tabs[0], n * W, 0);
lv_obj_update_layout(host);
s_strip_loop_pending = true;

/* 手指一路左拖 → 跟手看到 main 滑入；END 按最近页判定 */
if (nearest >= n) { if (x >= n*W - 2) strip_loop_finish(); else scroll_to(n, ON); return; }
if (x > (n-1)*W + 2) { s_strip_loop_canceling = true; scroll_to(n-1, ON); return; }  /* 先吸回末槽 */
strip_loop_cancel();       /* 已回合法范围，立刻搬槽不会跳变 */
```

顺序反了（先搬槽、后吸回）= 可滚范围同帧缩小、scroll 被硬钳 → **右侧 main 突然消失**。

#### A6. 快捷窗跟手（`translate_x`，不进滚动带）

```c
/* 面板宽 310，手指在 466 圆屏最多走 ~230 → 1.5 倍增益：拉一下就能全开又不失跟手 */
want = s_drawer_base + dx * 3 / 2;
if (want < -(int32_t)WATCH_QUICK_DRAWER_W) want = -WATCH_QUICK_DRAWER_W;
if (want > 0) want = 0;
lv_obj_set_style_translate_x(s_quick_drawer, want, LV_PART_MAIN);
```

- 起手位置判定用**当前可见宽度**：`visible_w = 310 + translate_x`，
  `press.x <= visible_w` ⇒ 这次手势只驱动小窗（左滑缩回、右滑伸出），绝不给 main 翻页。
- 松手过 1/2 全开（220ms），否则收起（200ms）。
- 窗可见时有一层**全屏遮罩**（盖在宿主之上、窗之下）：main 区触摸只作用小窗。
- 按钮必须用 24px 判据（LVGL 只在**单帧位移 > `scroll_limit`(50px)** 时抑制 CLICKED，
  慢速拖动松手仍会触发按钮点击）。

### B. 在仿真器里怎么调（工装与操作步骤）

#### B1. 三条命令

```bat
design\sim_cmake\run_sim.bat build      :: 只构建（0 error/0 warning 才算过）
design\sim_cmake\run_sim.bat            :: 构建并开窗口（控制台会打印按键提示）
tmp\run_autotest.bat                    :: 无头回归（WATCH_AUTOTEST=1 + WATCH_AUTOEXIT=1）
```

- 构建目录私有（`design/sim_cmake/build_rel`），exe 私有（`build_rel/bin/main.exe`），
  不与共享工程互相覆盖。
- 启动前必须把 SDL2 / mingw 加进 PATH（脚本里已做）；直接双击 exe 会
  `STATUS_DLL_NOT_FOUND (0xC0000135)`。
- 链接失败先查**残留进程占用 exe**（`Get-Process main | Stop-Process`），不是代码错。

#### B2. 独立测试 indev：把"手指"变成可编程位移序列

```c
static lv_indev_t *s_test_indev;
static int s_sw_x0, s_sw_x1, s_sw_y, s_sw_left, s_sw_total = 10;
static int s_sw_stop;      /* >0：喂到这一拍就停住保持按压（截中间帧用） */

static void test_indev_read(lv_indev_t *indev, lv_indev_data_t *data)
{
    if (s_sw_left <= 0) { data->state = LV_INDEV_STATE_RELEASED; data->point = 终点; return; }
    if (s_sw_stop > 0 && s_sw_total - s_sw_left >= s_sw_stop) {
        data->state = LV_INDEV_STATE_PRESSED;        /* 停住不动，保持按压 */
        data->point.x = x0 + (x1 - x0) * s_sw_stop / s_sw_total;
        return;
    }
    data->state = LV_INDEV_STATE_PRESSED;            /* 每拍都有位移 */
    data->point.x = x0 + (x1 - x0) * (s_sw_total - s_sw_left) / s_sw_total;
    s_sw_left--;
}
```

要点：
- **每拍必须有位移**，否则 LVGL 的 `gesture_sum` 会被"无位移拍"清零；
- 10 拍分摊 120px ≈ 12px/拍，等效真机 30ms 轮询的手感；
- 用例侧的封装：`finger_swipe(x0,x1,y)`（走完+松手+动画）、
  `finger_drag_to(x0,x1,y,stop,pump)`（拖到中途停住）、
  `finger_drag_release()`（松开并 pump 90 帧等归位）、
  `finger_drag_release_quick()`（只 pump 2 帧，断言"松手瞬间"不能跳变）、
  `finger_drag_redirect(x1)`（保持按压换方向，验"拉出后反向缩回"）。

#### B3. 判据要打在**物理量**上

| 断言 | 证据类型 | 抓的是什么 bug |
|---|---|---|
| `watch_nav_strip_aligned()`（`scroll_x % 466 ∈ [0,2]∪[464,466]`） | 物理偏移 | 卡半页 / 不磁吸 |
| `watch_nav_quick_tab_dot()`（真正画出的高亮下标） | 渲染态 | 点不同步 |
| `watch_nav_drawer_offset()`（`translate_x + 310`，0=收起 / 310=全开） | 跟手位移 | 拉窗不动/瞬移 |
| `watch_nav_quick_tab_active()` | 逻辑槽 | 只用来辅助定位，**不能单独当通过条件** |

```c
/* 例：快滑三次后必须仍然整页对齐 */
for (int i = 0; i < 3; i++) finger_swipe(400, 100, 233);
expect_true(watch_nav_strip_aligned(), "连续快滑后仍磁吸整页");
expect_int(watch_nav_quick_tab_active(), 3, "连续快滑落点");
expect_int(watch_nav_quick_tab_dot(), 3, "指示点同步");
```

#### B4. 中间帧取证（"跟手"唯一可信的证据）

```c
finger_drag_to(400, 100, 233, /*stop=*/5, /*pump_ms=*/20);   /* 拖到一半停住 */
take_shot("shot_mid_strip");                                  /* 此时应看到两页同屏 */
```

- `take_shot()`：`lv_snapshot_take(lv_screen_active(), LV_COLOR_FORMAT_XRGB8888)`
  → 手写 54 字节 BMP 头（宽高 + **负高度=自上而下** + 32 位）→ 落 `tmp/sim_shots/`。
- 中途帧能看到"末槽正在左滑出、表盘从右侧滑入"，才算真正跟手；
  只看"最终落在哪页"永远证明不了跟手。

#### B5. 键盘/物理按键入口（不写死跳页）

```c
/* 导航层：自定义事件，输入源只发布，订阅者执行跳转 */
static lv_event_code_t s_evt_open_applist;          /* watch_nav_init 里 lv_event_register_id() 注册 */
static void open_applist_event_cb(lv_event_t *e) { go_applist(); }
void watch_nav_open_applist(void) {
    if (!s_evt_open_applist) return;                /* 注册前调用=空操作 */
    lv_obj_send_event(objects.watchface, s_evt_open_applist, NULL);
}
```

```c
/* 仿真器：SDL 事件里只置位，主循环再发布（SDL_PollEvent 跑在 LVGL timer 里，
   直接在事件回调里加载屏幕会绕过刷新时序） */
static int key_event_watch(void *u, SDL_Event *e) {
    if (e->type == SDL_KEYDOWN && e->key.keysym.sym == SDLK_a && !e->key.repeat)
        s_key_applist_pending = 1;
    return 0;                                        /* 0=不吞事件，键盘 indev 照收 */
}
```

回归里可以**真灌一个事件**验证整条链（不是直调函数）：

```c
SDL_Event ev; SDL_zero(ev); ev.type = SDL_KEYDOWN; ev.key.keysym.sym = SDLK_a;
SDL_PushEvent(&ev);                                  /* 事件 watchdog 置位 */
for (int i = 0; i < 8; i++) sim_frame(5, 5000);      /* 与运行时同一个帧函数 */
expect_scr(objects.applist, "键盘 A → applist（SDL 事件链）");
```

### C. 界面怎么对比（单一设计源 → 四方产物 → 四层判据）

#### C1. 单一设计源派生四方产物（禁止单独画图）

```
design/design_source.py  ← 唯一真值（页面/控件/坐标/颜色/字体档/几何宏）
   ├─ design/design_view.py       → designer/*.png          ① 效果图（第①步给人确认）
   ├─ design/build_watch_ui.py    → watch.eez-project       ② EEZ 工程（控件与样式真值）
   │     └─ design/eez_build.py（EEZ CLI --build-project）→ src/ui/*.c|h   ③ 运行代码
   ├─ design/eez_font_engine.py   → src/ui/fonts/ui_font_cn*.c             ④ 字体烘焙
   └─ design/design_annotate.py   → designer_annotated/*.png + _tree.svg   ⑤ 控件/跳转标注
```

改界面 = 只改 `design_source.py` → 四条命令重跑（`build_watch_ui.py` → `eez_build.py`
→ `eez_font_engine.py` → `design_view.py` + `design_annotate.py`）。
任何一个产物手改，下一次生成就会被覆盖，且对账立刻报差异。

#### C2. ④-A 声明层对账（第一站，判据=差异 0）

```bat
python design\audit_declared.py
:: 声明条目 353 / 工程控件 353 / 页 25 / 字体 11 / 位图 14，差异=0   → 退出码 0
```

三方对账：`declared_manifest.json`（生成器自称写了什么）↔ `.eez-project`（工程实际有什么）
↔ `CONTROLS` 清单表（设计源声称的控件/跳转）。

- 逐项比 identifier / 类型 / 坐标 / 尺寸 / 文本 / 字体 / 颜色；
- 每个控件的跳转目标页必须在 `pages[]` 里；每个 `text_font` 必须在 `fonts[]`；
- native 建的宿主 identifier 不带"页_页_"前缀，要单独映射（`al_roller → al_roller_host`、
  `qs_host → strip_qs_host`），否则会误报"落点 0 个"。

#### C3. ④-B1 画布逐屏截图对照（第二站，静态样式主核）

```bat
python design\eez_b1_shots.py
:: 产物 tmp/b1/eez_<page>.png + _b1_compare.png（左=EEZ 画布，右=designer/ 同名设计图）
:: 硬判据：缺页/抓取数≠页数 → exit 2（绝不拿空图拼图报成功）
```

操作要点（都是踩过的坑）：

- 固定端口 **9223**（避开旧会话的 9222，否则 node 脚本连错实例、全页静默失败）；
- 起 EEZ 后**等 ~90s 字体提取**再抓，否则中文缺字；
- 切页 = 在 Pages 树里按**文本**找叶节点并派发 `mousedown/mouseup/click`；
- 抓图 = CDP `canvas-shot`（画布本身就是 LVGL wasm 渲染，不是截图缩放）；
- 结束 `taskkill /F /T`，别留下僵尸 EEZ 占端口。

#### C4. 运行态快照（真 LVGL + 真生成代码）

- 无头回归里逐屏 `take_shot()`，落 `tmp/sim_shots/*.bmp`（32 位、自上而下、BGR 顺序）；
- 与 `designer/<page>.png` **同尺寸 466×466**，可直接并排/叠差；
- 颜色若不对，先怀疑读取端通道顺序（B8），本项目直接写 BMP 所以天然正确；
- 观感差异仍靠人眼，但**几何/文本/跳转**已经由 C2/C3/B3 机械判掉了。

#### C5. 四层判据分工（不要用一层去证另一层）

## 通用化

| 问题 | 跨栈对照 |
|---|---|
| 仿真器里手势/滑动难复现 | 任何引擎都别依赖宿主鼠标注入；**自建可控输入源**（逐拍位移/固定采样率），把"输入粒度"这一变量消掉 |
| "切过去了"不等于"对" | 断言必须打**物理量**（偏移倍数、对齐、透明度、位移），逻辑标志位只能辅助 |
| 证明"跟手" | 只有**中间帧**能证明；终态图证明不了过程 |
| 设计↔实现对比 | 单一设计源 + 多产物派生 + **声明层对账**（可量化）> 人工并排看 |
| 多源出图 | 固定端口/固定产物目录/硬判据（缺页即失败），否则"成功"是假的 |
| 事件入口 | 输入源只**发布事件**，跳转由订阅者执行；键盘/触摸/物理键共用同一入口，避免各写一份跳页 |

### 参数调节手册（本形态实测值）

| 参数 | 值 | 说明 |
|---|---|---|
| 页宽 | 466（=屏宽） | 条带所有计算都按页宽整数倍 |
| 翻页阈值 | 页宽 1/8 ≈ 58px | 短促快滑也能落到相邻页 |
| 对齐容差 | ±2px | `watch_nav_strip_aligned()` 判据 |
| 点击/滑动分离 | 24px | 慢速拖动松手不误触按钮 |
| 拉窗增益 | 1.5× | 面板宽 310、可走 ~230 |
| 拉窗开合阈值 | 1/2 | 松手过半分全开 |
| 开/收动画 | 220ms / 200ms | 全开 / 收起 |
| 归位动画 | LVGL 默认 `anim_duration` | 无头回归需 pump ≥ 250ms 再断言终态 |
| 测试 indev 拍数 | 10 拍 / 120px | 每拍必须有位移 |
| 键盘入口 | `A` | SDL 事件 → 置位 → 主循环发布 LVGL 自定义事件 |
