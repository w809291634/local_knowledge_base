# B25 复用旧 H5 模板导致批注整块缺失（右键只绑两处）

## 现象

在新工程的 H5 评审页上，用户在两个“看起来应该能批注”的位置右键，均无菜单：

- 分层总览页面卡片下方的跳转胶囊（`1.新建患者 → 患者信息`）；
- 高清设计图页签的页面卡片（带控件标注的大图）。

顶栏同样没有「导出批注」，无法产出 `annotations.json`。

## 证据

```bash
grep -c "contextmenu\|annotations\|导出批注" design/overview_pro.py
# 修复前 0，修复后 4+
```

无头浏览器实测修复结果：

```text
data-selftest="y|3|y|1"
# 跳转胶囊右键 → 菜单 3 项；高清卡片空白右键 → 菜单 1 项
```

## 曾经的误判

第一轮只补了“右侧控件清单行”和“跳转演练 / 停靠栏大图”的右键，
并用 selftest 验证这两处通过，就报告“批注已可用”。
实际用户右键的是总览胶囊与高清卡片——两个完全没覆盖的面。
**教训：验证面必须等于使用面，不能只验自己实现的那一个容器。**

## 真因

1. **模板代差**：`overview_pro.py` 从早期工程整体复制，早于 `reference/14 §8` 的批注模式；
   三视图/停靠栏/标注都在，批注模块整块不存在，复制时没有任何告警。
2. **右键命中面用“容器白名单”而不是“全量语义选择器”**：
   写死 `#bigbox svg, #dock svg` 和 `[data-cpage]`，新视图（高清卡片）与胶囊不在名单里。
   同一份界面在多个容器渲染（缩略图 / 演练大图 / 停靠栏 / 高清卡片），只验一个容器必然漏。

## 修法

1. 批注模块补齐：localStorage、右键菜单、图钉、导出 JSON、顶栏计数。
2. 右键命中改为语义全量：
   - `[data-cpage]` 覆盖清单行、跳转胶囊、静态胶囊、图上控件标注框；
   - `svg[data-page]` 覆盖所有 `mark()` 产物（缩略图、演练大图、停靠栏、高清卡片）。
3. 胶囊组件补 `data-cpage / data-cn / data-cname`，`tags(d)` → `tags(d,p)` 传页名。
4. 门禁 C7：H5 必须含「导出批注按钮 / contextmenu / annotations.json / localStorage」，
   缺一 FAIL。

## 验证

- `step1_gate` C7 PASS；
- 无头 selftest：跳转胶囊菜单 `y|3`，高清卡片空白菜单 `y|1`；
- 门禁总览仍 PASS（28 业务页 + L0 / 275 控件）。

## 通用化

- **复制旧版 H5 生成器 = 引入未知代差**。复制前先按当前模板的“必备模块清单”逐项 grep：
  批注、图钉、导出、localStorage、三视图、停靠栏、标注开关。
- **右键/热区这类“命中面”规则，永远用语义选择器，不用容器白名单**：
  只要元素带 `data-page` / `data-cpage`，就应该能命中，不枚举它现在长在哪个容器里。
- 可执行的防复发判据优先于文档：把“必备模块”写成门禁断言，比在 README 里写一句
  “记得补批注”有效得多（PLAYBOOK §2.9 第 4 步）。
