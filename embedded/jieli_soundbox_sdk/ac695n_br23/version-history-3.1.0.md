# 版本史与配套工具（soundbox SDK 1.0.0 → 3.1.0）

> 出处：`doc/AC695N_soundbox_发布版本信息V2.0.pdf`（14 页）。
> **读这份表最大的坑：条目编号跨版本连续累积**（3.0.6 从 7 号起、3.0.4 从 17 号起、3.0.0 从 26 号起、2.0.0 从 29 号起），

## 1. 官方问题分级（p3）

| 级别 | 含义 | 客户动作 |
|---|---|---|
| **A 类** | 问题修复 | **必须修复** |
| B 类 | 性能优化 | 可选修复 |
| C 类 | 功能增加 | 可选择 |

## 3. 配套工具版本（3.1.0）

烧写器 V2.26.1 · 一拖八 V3.1.7 · 测试盒 V12.6 · **配置工具 V2.0.2** · **工具链 2.4.6** · effectTool 0.1.8 · FW 编辑 2.0.47。
工具链随版本演进：1.0.0/2.0.0 = 2.3.7 → 3.0.x = 2.4.2 → **3.1.0 = 2.4.6**。
**升 SDK 必须同时升工具链**，否则编译/链接行为不一致。

音效说明文档的位置：调音工具 → 关于 → 帮助 → `<EffectTool_UserManual>`（3.1.0 配套说明没有独立 PDF）。
3.1.0 配套《音箱配置工具使用说明》。

## 4. 手册自身的版本信息

`AC695N_soundbox_SDK_介绍V2.0.pdf` 的 V2.0 修改日志（p4）只写"建立初始版本 / 定义文档格式"，
**手册没有更早版本可比**，不要指望从手册改动记录反推 SDK 演进。

## 5. 用版本信息做事的三个习惯

1. **报障先对齐到 A/B/C 级别**：A 类（如 3.0.3）意味着官方认为不升就有风险，客户侧应当作强制项。
2. **"生产不开机"在 3.0.6 与 3.1.0 各出现一次** —— 同一个问题复发过；遇到批量不开机先确认基线版本。
3. **跨版本移植时按编号追累积清单**，不要按"本次改了几条"理解，编号是全局连续的（见开头那条）。
