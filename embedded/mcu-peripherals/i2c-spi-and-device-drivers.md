# I2C / SPI 协议与器件驱动笔记

> `⚠校核` 指向 `ERRATA-单片机外设和调试基础知识.md`。

## 1. I2C 协议要点（通用）

| 项 | 结论 |
|---|---|
| 空闲 | SDA、SCL **同时为高** |
| 起始(S) | SCL 为高期间 **SDA 高→低** |
| 停止(P) | SCL 为高期间 **SDA 低→高** |
| 数据变化 | 只允许在 **SCL 低电平期间**变化 |
| 地址 | 起始后第 1 字节 = **7 位地址 + R/W**（MSB 在前）；10 位地址占 2 字节 |
| 应答 | 第 9 个时钟由**接收器**把 SDA 拉低 = ACK，高 = NACK；主机读最后一个字节后要发 NACK |
| 上拉 | 两根线都需上拉到 VCC（开漏） |
| 换算 | 驱动里 `addr = device_address_7bits << 1`，读用 `addr + 1`（F1 通用 iic_read/write 即如此） |
| SSD1316 实测时序 | 起/停最小 0.6us、停止后空闲最小 1.3us、建立 100ns、保持 ≥300ns/最大 900ns；作者按 **2.5us 周期**估算延时 |
| 未覆盖 | 时钟拉伸(clock stretching)与硬件 I2C 外设寄存器配置只引了手册描述，无实操笔记 |

## 2. 三套"软件模拟 I2C"的实现差异（复用时的第一道坎）

| 平台 | 引脚与配置 | 速度控制 | 注意 |
|---|---|---|---|
| **CC2530** | SCL=P0_0、SDA=P0_1；`P0SEL &= ~0X03; P0DIR |= 0X03`；`SDA_IN` = `P0DIR &= ~0X02` | `delay_us(d)` 宏为 `for(x=0;x<delay-1;x++)`，**实测 1→1.25us、2→2.25us、5→5us、100→97us**（非线性！）；旧 `iic_delay_us` 0→最小 4us、1000→972us | **必须用逻辑分析仪实测**，不能按名义值推 |
| **STM32F1** | PB1=SCL、PB0=SDA，`GPIO_Mode_Out_PP`（**推挽**，非开漏）；`SDA_OUT/IN` 直接写 CRL/CRH（0x3 输出 / 0x8 输入） | `I2C_SPEED_DELAY=2` | `⚠校核`：`SDA_IN` 里 `CRH &= ~0XF<<SDA_NUM*4` **未减 8**，num≥8 时位移越界 |
| **STM32F4** | 正点原子版 `GPIO_OType_OD` + `PuPd_NOPULL`；**PLUSB(HTU21) 版却是 `GPIO_OType_PP` + `PuPd_UP`** | `I2Cx_PERIOD=128` 空转延时 | 两版风格不一致，移植时以波形为准 |

**跨版本最大的坑：`iic_write_byte` 的返回值语义全文有三种口径**（1=ACK / 0=ACK / 注释与代码相反）
⇒ 换文件复用**必须先读实现**，不能靠函数名猜。`⚠校核B`

## 3. SSD1306 / SSD1316 OLED

| 项 | 值（照抄） |
|---|---|
| 器件地址 | `0111 10 SA0 R/W#` ⇒ 写 `0x78`、读 `0x79` |
| 控制字节 | `0x00`=命令、`0x40`=写 GRAM(D/C#=1)、`0xC0`=Co=1 连续写数据 |
| 寻址（页模式） | `0x20, 0x02`；页 `0xB0 + y`；列低 4 位 `0x00~0x0F`、列高 4 位 `0x10~0x1F`；起始行 `0x40~0x7F` |
| 初始化序列 | `0xAE → 0x20,0x02 → 0xB0,0x00,0x10 → 0x40 → 0x81+对比度 → 0xA1 → COM 方向 → 0xA6 → 0xA8+(Max_page*8-1) → 0xD3+0x00 → 0xD5+0x80 → 0xD9+0x22 → 0xDA+0x12 → 0xDB+0x20 → 0x8D+0x14(9V；0x15=7.5V) → 0xAF` |
| 显存 | GDDRAM 128×64 bit、8 页；写入时 **D0=最上行、D7=最下行** |
| 96×32 正装 vs 128×64 倒装 | 只有两处差异：`Max_Column/Max_page` = 96/4 vs 128/8、对比度 `0x45` vs `0xAA`、COM 方向 `0xC0` vs `0xC8`（作者注"其他部分代码一样"） |
| 取模设置 | Pctolcd2002：**阴码、列行式、逆向、8 位/列** |
| OLED vs LCD 的本质差别 | OLED 页模式一次写 8 位 = **一列**（填矩形）；LCD RGB565 一像素 = 16 位（填线） |
| `⚠校核` | 表里 `0x00`/`0x10` 高低位注释互换；`0xAE` 被注释成"开启显示"（实为关）；出现不存在的"C1H"；`OLED_Fill` 注释"页 0~4"却循环 `i<8`；`Refresh_Gram/DrawPoint` 硬编码 8 页 128 列，与 `Max_page/Max_Column` 宏在 96×32 上不自洽 |
| 资料状态 | **"SSD1316 手册没有找到"**，命令表实为 SSD1306 + 二手教程 ⇒ 别当一手依据 |

## 4. 常见 I2C/类 I2C 器件速查

| 器件 | 关键结论 | 范围 |
|---|---|---|
| 24C02 | 2Kbit = 256 字节；写 `0xA0`/读 `0xA1`；**读前需 DUMMY WRITE + 重复起始** | 通用器件 |
| PCA9685 | 12 位分辨率(0~4095)、40Hz~1000Hz；`PRE_SCALE=0xFE`，默认 0x1E→25MHz 下 200Hz；`prescale=round(25e6/(4096*freq))-1`；寄存器 `MODE1=0x00`/`MODE2=0x01`/`LED0_ON_L=0x06`（通道 = `offset*4`），高字节 bit4=FULL ON(0x1000)；`0x11`=sleep+ALLCALL、`0xA1`=RESTART\|AI\|ALLCALL、`0x21`=AI\|ALLCALL；**SLEEP 清 0 后要等 ≥500us 才能 RESTART**；7 位地址 `0x40+A5:A0`、All Call `0xE0`、软复位 0x06；舵机 20ms 周期 / 0.5~2.5ms ⇒ 4.88us 步进、角度分辨率 ≈0.439° | 器件专属；**作者标注"周期延时是错误的，未修改"⇒ 整节未验证** |
| PCF8563 RTC | 7 位地址 `0x51`（驱动传 `ADDRESS<<1`）；寄存器 SECOND `0x02`…YEAR `0x08`、`TIME_SIZE=0x07`；月寄存器有 `CENTURY_BIT 0x80`；掩码 秒/分 `0x7f`、时/日 `0x3f`、周 `0x07`、月 `0x1F`；`data[0]&0x80` = 低压检测位；**星期由芯片自动计算（写 wday 无效）**；报警 `0x09~0x0c`（`ALARM_DISABLE=0x80`）、定时器 `0x0e/0x0f` | 器件专属 |
| TM1650 数码管 | 类 I2C、**不带从机地址 ⇒ 只能软件模拟**；显存 `0x68/0x6A/0x6C/0x6E`，显示命令写 `0x48`；8 级亮度、7×4=28 键、约 1KHz 动态扫描；硬件 4.7k 上拉、段串 100Ω、VCC 0.1μF、DIG-Kx 串 2kΩ、**必须共阴** | 器件专属；作者注"需按实际硬件调整"；`⚠校核`"0x48,0x51=5 级亮度"的注释存疑 |
| GT911 触摸 | 1.8V 接口下 400Kbps + 2K 上拉；时序 tlo 0.9us/thi 0.8/tst1 0.4/tst3 0.4/thd1 0.3/tst2 0.4/thd2 0.4us；**中断一直触发 = 没读状态寄存器**；无应答 = 地址设置时序不对或 GPIO 未配好 | 器件专属 |
| MAX30102 | 660nm/880nm 双波长、PPG 反射式；INT 开漏低有效；文档同一处写"1.8V 电源"另一处写"VIN 1.6V~5.5V" `⚠校核B` | 器件专属 |
| BMP280 | 只留了链接 + 官方库；**作者标注"原始链接的海拔计算公式有错误"、代码未贴** ⇒ 无可提炼内容 | — |
| PLUSB / 垃圾桶 项目 | I2C 引脚 PLUSB SensorA=PB8/PB9、板载=PA1/PA0；垃圾桶 PCA9685 `ADDR1=0x82(A0=1)`、`ADDR2=0x84(A1=1)` | **项目专属，只作线索** |

## 5. SPI 协议与 STM32 实现

| 项 | 结论 | 范围 |
|---|---|---|
| 模式定义 | `CPOL` = 空闲电平（0 低 / 1 高）；`CPHA`=0 在**第一个边沿**采样、=1 在**第二个边沿**采样 | 通用 |
| 常见用法 | W25QXX 例程用 **Mode3**（CPOL_High + CPHA_2Edge）；DM9051 用 **Mode0**（POLARITY_LOW + PHASE_1EDGE，手册允许 0/3）；RT-Thread 的 `RT_SPI_MODE_2` = CPOL1/CPHA0 | 器件/通用 |
| 速率 | SPI1 挂 APB2，最高 84MHz，÷256 ⇒ 最低 328.125kHz；HCLK=168/PCLK2=84/PCLK1=42；SPI2/3 时钟 42M；文档"F4 最大 SPI 时钟 37.5Mbits/s"（**无手册佐证**）`⚠校核C/D` | F4 |
| 分频 | `CR1` 位 3-5 清零（`CR1 &= 0XFFC7`）后写 BR[2:0]，2~256 共八档；`⚠校核` 文档同时混用"brp 1~1024""Fdiv=brp+1""库函数已减一"三种口径 | F1/F4 |
| NSS 陷阱 | `CR1` 位9 SSM、位8 SSI；`CR2` 位2 SSOE。**MSTR=1 且 SSOE=0 时 NSS 被拉低 ⇒ 主模式故障、MSTR 自动清零**；建议软件管理片选省 IO | STM32 |
| 存储器到存储器 | 只有 DMA2 支持等细节见 `timer-pwm-adc-dma.md` | — |

## 6. SPI 器件驱动要点

| 器件 | 关键结论 |
|---|---|
| **W25Q128** | 128Mb = 16MB；**1 页 = 256B、1 扇区 = 16 页 = 4KB、1 块 = 16 扇区 = 64KB**；最小擦除单位=扇区；**单条写指令最多一页 256B**；命令：`06h` 写使能、`05h` 读状态(BUSY=bit0)、`02h` 页编程(24bit 地址)、`20h` 扇区擦、`C7h` 片擦、`90h` 读 ID(返回 EF 17)、`03h` 读；**W25Q256/512 用 4 字节地址，与 3 字节驱动不兼容** |
| **DM9051**（SPI 以太网） | 写寄存器 = `opcode \| 0x80`，读 = 直接发地址；burst 命令 `SPI_WR_BURST=0x78`（带写使能高位即 0xF8）、`SPI_RD_BURST=0x72`；**PHY 通过间接访问**：`EPAR=0x0C`（基址 0x40）、`EPDRL/EPDRH=0x0D/0x0E`、`EPCR=0x0B`（写 0xA、读 0xC，轮询 bit0） |
| **GC9A01 圆形彩屏** | `0x36(MADCTL)`：`0x68`/`0xA8` 两种横屏、`0xC8` 反向竖屏；RGB565 红=`0xF800`、蓝=`0x001F`；**小端机发 SPI 必须做大小端交换，否则红显示成绿** |
| LCD 类示例 | 文档明确"LCD 相关示例统一存放到《LCD触摸屏幕原理.docx》" ⇒ 本库不重复 |

## 7. 通用性判断

上面 **I2C 时序规则、SPI 模式定义、DMA/NSS 陷阱、各器件命令表**都是跨芯片可复用的；
但**三套软件 I2C 的引脚写法、寄存器直写 CRL/CRH、`I2C_SPEED_DELAY` 数值**属于具体 MCU + 具体工程，
移植时只能当参考实现，不能当标准。
