# 音频：I2S 时钟 / WAV 文件 / WM8978

## 1. 三个时钟的关系（通用，做音频第一步就要算对）

| 信号 | 公式（照抄文档并核对无误） |
|---|---|
| `BCLK`（位时钟） | **`BCLK = 2 × fs × 位宽`**（立体声；2 就是左右声道） |
| `WS` / LRCLK（帧同步） | 频率 = `fs`（采样率） |
| `MCLK`（主时钟） | **`MCLK = 256 × fs`**（固定倍数） |

例：44.1kHz / 16bit 立体声 ⇒ BCLK = 2×44100×16 = 1.4112MHz，MCLK = 11.2896MHz。

## 2. STM32F4 的 I2S 时钟来源与分频（型号专属）

- `I2SxCLK = (HSE / M) × N / R`（走 **PLLI2S**）。
- 当 `MCKOE = 1`（要输出 MCLK）时：**`fs = I2SxCLK / [256 × (2 × I2SDIV + ODD)]`**。
- 参数范围：`N: 192~432`、`R: 2~7`、`ODD: 0/1`。
- **44.1kHz 的推荐组合：`N=271`、`R=2`、`I2SDIV=6`、`ODD=0` ⇒ 误差 0.0183%**
  （44.1k 这类非 2 幂采样率必须靠 ODD 位凑，凑不出来就是硬件倍频系数选错）。
- 帧格式：16/24/32 位；**24bit 数据存在 32 位帧里，需要 2 次读写 `SPI_DR`**（易漏一半数据）。
- DMA：`SPI2_TX = DMA1_Stream4_Ch0`（I2S 复用 SPI 外设与 DMA 映射）。

## 3. WAV 文件结构（通用，必须能背下偏移）

| 偏移 | 字段 | 值/说明 |
|---|---|---|
| 0x00 | `RIFF` | `0x46464952`（"FFIR"，**小端**） |
| 0x04 | Size | **整个文件长度 − 8** |
| 0x08 | `WAVE` | — |
| 0x0C | `fmt ` | `0x20746D66` |
| — | 格式 | PCM = `0x0001` |
| — | `ByteRate` | `fs × 声道数 × 位深/8` |
| — | `BlockAlign` | `声道数 × 位深/8` |
| 可选 | `fact` | 压缩格式才需要 |
| — | `data` | `0x61746164` |
| — | 数据 | **小端，低字节在前**；16bit 立体声 = 4 字节/采样点，24bit = 6 字节 |

**常用坑**：`ByteRate` 不是 `fs×位深`（少乘声道数）；把 `Size` 写成整个文件长度（应 −8）；
24bit 数据按 3 字节读但 CPU 按 4 字节对齐搬 ⇒ 尾部错位产生"咔哒"噪声。

## 4. WM8978 编解码芯片（器件专属）

| 项 | 内容 |
|---|---|
| 接口分工 | **I2S 4 线**（ADCDAT / DACDAT / LRC / BCLK）传数据；**2/3 线（IIC 兼容）配置寄存器** |
| 关键寄存器 | `R0` 软件复位；`R1[3] BIASEN`（**最先要开**）；`R2` 耳放使能；`R3` 喇叭使能； |
| 数据格式 | `R4`：`WL[6:5]` = `00`→16bit、`10`→24bit；`FMT[4:3]` = `10`→I2S 标准格式 |
| 时钟 | `R6` = 外部提供 MCLK/BCLK 的配置位 |
| 音量 | `R52~R55`，**最高位是 HPVU**（音量更新位，必须置 1 才生效 —— 常见"调音量没反应"就卡在这） |
| 混音 | `R50/R51` DAC 输入 mixer；`R49` **SPKBOOST**（提升喇叭输出功率） |
| 术语 | 采样率 `fs`、比特率 `BCLK`、主时钟 `MCLK` 三者关系见 §1 |

## 5. 通路小结（文档给的实操路径）

1. PC 上用**音频转换软件**把素材转成 WAV（指定 fs / 位深 / 声道）；
2. 固件里按 §3 解析头，把 `data` 段的采样点喂给 I2S/DMA；
3. `I2SDIV/ODD` 用 §2 公式凑出目标 fs，**并用示波器量 BCLK 与 WS 验证**（软件算对不代表配了生效）；
4. 录音是反向通路：ADC → WM8978 ADCDAT → I2S 收 → DMA → 存 WAV（记得先写 `ByteRate/BlockAlign`，最后回填 Size）。

## 6. 校核结论

`BCLK = 2×fs×位宽`、`MCLK = 256fs`、WAV 各字段偏移与大小端、PLLI2S 分频式、RGB565 位域等**核对无误**；
唯一明确错处是**"常用采样率 196Khz"应为 192kHz**（同节常量都写 192000），已入 ERRATA A 类。
文档未给：**多路并发播放上限、DAC/I2S 直连与功放级的音量档位换算、录音回环的延迟指标**（未涉及，勿假设有）。
