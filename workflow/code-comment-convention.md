# C / C++ 函数与文件分区注释规范

适用范围：所有 C 和 C++ 工程，不限定芯片、操作系统、框架、平台或业务领域。

## 1. 文件内职责分区

一个源文件中存在两个及以上职责区域时，使用以下格式作为一级分区标题：

```c
/******************** 网络事件处理 ********************/
```

适用场景：

- 初始化、资源释放、事件处理、线程或任务、协议收发等逻辑分区；
- 状态机的“状态迁移 / 定时处理 / 数据上报”等区域；
- 驱动、库或应用文件的“私有数据 / 初始化 / 读写接口 / 回调处理”等区域。

规则：

- 标题应描述职责，不能只写“功能 1”“其他”。
- 不需要为了凑分区而过度添加；单一职责的小文件可以不使用分区标题。
- 同一文件的分区标题格式与星号数量保持一致。

## 2. 函数三行注释

每个新增或修改的函数定义前，统一写三行中文 `//` 注释：

```c
// 函数作用：说明该函数完成的职责。
// 参数：说明每个参数的含义；无参数时写“无”。
// 返回值：说明返回值语义；无返回值时写“无”。
```

适用于：

- 对外公开函数；
- `static`、匿名命名空间或私有辅助函数；
- 线程、任务、事件和回调处理函数；
- C++ 成员函数、静态成员函数与模板实现函数。

## 3. 组合示例

```c
/******************** 网络事件处理 ********************/

// 函数作用：处理网络地址获取事件并通知上层。
// 参数：event：事件数据。
// 返回值：无。
static void on_address_ready(const event_t *event)
{
    // ...
}

/******************** 配置加载 ********************/

// 函数作用：加载远端配置并更新运行时信息。
// 参数：无。
// 返回值：0 表示成功；其他值表示加载或解析失败。
int load_remote_config(void)
{
    // ...
}
```

若项目使用 Doxygen、Javadoc 风格或其他 API 文档工具，头文件/公开接口仍保留完整契约；源文件中的分区标题和三行注释用于帮助快速阅读实现。
