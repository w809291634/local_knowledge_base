# B3 某类控件内的子元素被整体偏移（默认主题 padding）

> ⚠️ 本案曾被**误判两次**，是最值得精读的一例。

## 现象

- 一类**带底部标签栏的页面**，画布**最后一行仍有文字墨迹** → 说明底部文字被切
- 只有带标签栏的页面有问题，其他页面正常
- 偏移"看起来只有 1px"，但怎么挪都挪不干净

## 证据

**① 水平方向最干净（垂直方向有基线歧义，不要用它）**

| 控件 | 声明坐标 | 实测墨迹 | 偏移 |
|---|---|---|---|
| 容器内的对照标签 | left = 201 | x = 201 | **0** ✓ |
| **按钮内**的图标 | left = 25 | x = 39 | **+14** |
| **按钮内**的文字 | left = 18 | x = 32 | **+14** |

→ 容器里的元素**没有**偏移，按钮里的元素**横向 +14、纵向 +9**。

**② 旁证**：某个"返回"按钮里的箭头被挤出按钮外，在角落里形成一个可见的怪方块。

## 曾经的误判（两次）

**误判 1：把现象当规律。**
量到"框顶 +10..+21"恰好是墨迹范围，就据此把标签整体上移 5~6px。
→ 结果只压到 1px，**没根治**（因为偏移量本身是控件样式带来的，不是固定常数）。

**误判 2：归因于字体度量差异。**
认为是"预览用的字体与设备的字体 ascent 不同"。
→ 方向接近（确实存在度量问题），但**解释不了横向也偏移 14px** —— 字体只管纵向。

**推翻它的是什么**：拿**容器内的同类标签**做对照组，发现它偏移为 0。
同样是同字号文本，换个父容器就没事 → 问题在**父容器的类型**，不在字体。

## 真因

**框架的默认主题给"按钮"这类控件加了内边距**，其子元素被整体推开：

```
容器（Container）  → 默认 padding = 0        → 声明坐标 == 渲染坐标
按钮（Button）      → 默认 padding = (14, 9)  → 子元素被推开 (x+14, y+9)
```

影响是**成片的**：所有"按钮里放图标/文字"的地方都偏了，不只是标签栏。

## 修法

**在样式里显式清零**，让"声明坐标 == 渲染坐标"：

```python
# 所有按钮统一走一个构造函数，样式里显式写 0
st = {"bg_opa": "0", "border_width": "0", "radius": "0",
      "pad_top": "0", "pad_bottom": "0", "pad_left": "0", "pad_right": "0"}
```

然后**按设计坐标**摆子元素（**不要"反向补偿"那个偏移** —— 补偿是打补丁，
清零才是根治，否则以后改布局还得想着这个偏移）。

**为什么这是根治**：清零后，"工程里写的坐标"与"渲染位置"一一对应，
所有布局计算、静态体检、视觉对照才有一致的基准。

## 验证

```bash
# 1) 与声明框对比，dx/dy 应为 0（用紧包单个元素的 box）
python tools/ink_check.py <原生图>.png --box X Y W H --against L T W H

# 2) 全页触边检查：最两行不应再有内容墨迹
python tools/ink_check.py <原生图目录>/

# 3) 生成物里应能看到清零样式
grep -c "pad_top\|pad_left" <生成代码>        # 期望 >0
```

修复后：图标墨迹与声明框左右边界一致、文字同理；
**所有页面的最外两行亮像素全为 0**。

## 通用化

**这是跨框架最普遍的坑之一**：默认主题给常用控件加"看不见的包围盒"。

| 栈 | 默认被加了什么 | 清零方式 |
|---|---|---|
| 组件树框架默认主题 | 按钮的 `pad_all`（实测两方向不同值） | 样式 `pad_* = 0` |
| HTML | `<button>` 的 UA 默认 padding/border | `padding:0; border:0; box-sizing:border-box` |
| Android | 主题 `?attr/buttonStyle` 的 insets | 自定义 style / `background=null` |
| Flutter | `Button` 的 `padding` + `minimumSize` | `style: ButtonStyle(padding: 0, minimumSize: Size.zero)` |
| Qt | `QPushButton` 样式表边距 | `setStyleSheet("padding:0;border:0")` |

**通用判别法（三步，照做就能定位）**：

1. **同类控件横向对比**：同类元素放进容器 vs 放进目标控件，看偏移是否只在后者出现
2. **用水平墨迹量偏移**：`实际墨迹左边界 − 声明左边界 = padding_left`（水平无歧义）
3. **看两个方向的偏移是否不等**：本例是 (14, 9)，两方向不同值 → 几乎可以确定是控件自带 padding；
   而坐标换算错误会让两个方向**同比例**偏移
