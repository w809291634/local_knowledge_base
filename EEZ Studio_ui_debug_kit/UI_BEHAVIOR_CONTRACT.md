# UI 行为 / 动画契约（自测判定基準）

> 用途：本契約は「界面应该怎么动作」の仕様であり、同時に自動自テストの**判定オラクル**である。
> 実機 or シミュレータで「操作 → 期待変化」を照合し、一致しなければバグ。
> 作成日：2026-09-30。対象：eez-test / LVGL 9.4 / 800×480 / EEZ 生成コード。

## 0. グローバル操作モデル

- **左レール（rail）＝ 大区分ナビ**（对话 / 音乐 / 通知 / 设置）。クリックか**内容区の横向きスワイプ**で切替。
  - 切替時、**レールの該当項だけ青背景＋縦バーでハイライト**、他は解除（① 修正済：VALUE_CHANGED → 純 EEZ flow 遷（Clear×N + GetActiveTab→局所変数 → Compare(var,i).True → AddState 第 i 組）；2026-09-30 から native sync_rail 退役、P-0030）。
  - 动画：内容区が**横向きに 180ms でスライドイン**（LV_ANIM）。
- **状态栏**：常に「常听」指示を表示。**语音聆听页(03) のみ非表示**。
- **内容区の縦向きスクロール**＝リスト内スクロール（タブ切替ではない）。タブは横向きスワイプ / レールクリックのみ。
  - ⚠️ ユーザ元発言「上下滑动左边tab没跟着变」＝縦スワイプはタブを変えない仕様。**もし縦スワイプでもタブが変わるべきなら設計変更が必要**（確認要）。
- **配色**：開=蓝(`0x5b7cfa`)、閉=灰(`0x2a3044`)、白ノブ。スイッチは LVGL 原生翻转。
  - ⚠️ **真机面板は BGR**。シミュレータは RGB で描画するため、**色が全体で色相反転していてもシミュレータでは一切見えない**。実機で蓝が橙っぽく見える等あれば色順序設定が怪しい（最優先で実機確認）。

## 1. 待机主屏 (01_standby)

- 进入：起動默认第一页。
- 左レール 4 項：对话 / 音乐 / 通知 / 设置 → 内容区横向き切替＋レールハイライト跟随。
- 待机卡片：最近对话表示（设备设定「唤醒后主动对话」形態）。マイク入口なし。
- タイル（音乐 / 通知 等）：クリック → 該当ゾーンへジャンプ、**レールハイライト跟随**（main_nav tab が変わる）。

## 2. AI 对话 (02_ai_chat)

- 进入：レール「对话」 or 待机タイル。
- 输入框：底部入力欄、送信 fab（円形ボタン）→ クリックでメッセージ送信コマンド発行。
- 期待动画：送信气泡**上にスライド＋フェードイン**で登場；AI 応答气泡は少し遅れて同様に登場。
- 现状Gap：バブル登場动画は EEZ 既定（淡入）のみ。より「業界標準」な弹性/スライドが欲しければ強化要。

## 3. AI 语音聆听 (03_voice)

- 进入：对话页から音声 orb クリック、または唤醒詞。
- orb：呼吸アニメーション（拡縮）。状态栏の「常听」指示**この页のみ非表示**。
- クリック orb → `action_voice_stop` → `voice_stop` コマンド発行 → 对话页へ戻る。

## 4. 会话历史 (04_history)

- 纵向リストスクロール。各履歴項目タップで該当会話を開く（未実装なら無反応でも許容だが要確認）。

## 5/6. 音乐 正在播放 (05) / 曲库 (06)

- 进入：レール「音乐」→ 子タブ 正在播放(0) / 曲库(1)。
- 正在播放：封面回転动画（再生中のみ）、プログレスバー。再生/一時停ボタン→コマンド。
- 曲库：纵向リストスクロール、タップで再生遷移。

## 7. 设置主页 (07_settings)

- 进入：レール「设置」→ 内容区左栏カテゴリ rail（无线 / 显示 / 唤醒 / 通用）。
- 各カテゴリクリック → 右内容切替＋カテゴリハイライト跟随（純 EEZ flow 遷、§0 同款、P-0030）。
- 行内スイッチ（语音唤醒 / 勿扰）：クリック→原生翻转（蓝⇄灰）＋ `mic_toggle` / `dnd_toggle` コマンド。

## 8. 设置·语音唤醒 (08_wake_word)

- 総開關（语音唤醒 使能）：蓝⇄灰、コマンド発行。
- 免打扰行スイッチ：`wake_dnd_toggle`。
- 唤醒词 / 感度 / 免打扰時間 の表示。

## 9. 设置·网络 (09_network)

- ⭐ **无线网络 行クリック → 下拉浮层**（遮罩 `wifi_pop_bg` ＋ カード `wifi_pop`）。
  - **期待**：浮層が**フェード/スライドで登場**、他の行を**押し下げない**、画面全体が下にスライドしない（② 修正済）。
  - 閉じる：閉じるボタン or 遮罩クリック → 浮層収納（HIDDEN）。
  - **现状Gap：浮層は onShow/onHide＝HIDDEN フラグのみで、登場/収納にトゥイーン(アニメ)がない＝瞬間出現**。ユーザ「好看」要求に対して弱点。slide/fade 动画の追加を推奨。
- 自动亮度等スイッチ：コマンド発行。

## 10. 设置·显示与音量 (10_display)

- 主音量 / 画面亮度：スライダー（原生ドラッグ）。スイッチ類はコマンド発行。

## 11. 通知中心 (11_notifications)

- 进入：レール「通知」。
- 通知カード縦スクロール。既読/クリア等は要確認。

## 12. 自テストが現在 捕捉できない 項目（= 実機で「問題多発」の怪しい箇所）

1. **真机 BGR 色順序**（最優先）：シミュレータでは不可視。実機で全体の色相がおかしいなら色順序設定を疑う。
2. **真实タッチ命中判定**：シミュレータはオブジェクトハンドルに直接イベントを投下するため、**座標ヒットテストを通らない**。透明コンテナがタッチを奪う等は見えない。
3. **真实ジェスチャスワイプ**：現在の冒煙テストは「プログラム切替(animated:false)」経路のみ。真の横向きスワイプ手势→タブ切替→レール跟随 の end-to-end は未検証（① の修正は配線のみ保証）。
4. **动画の「質」**：トゥイーン有無・方向・イージング・滑らかさは 25% ピクセル差閾値では弾けない。
5. **スクロール/オーバーフロー**：リストが画面を超えた際のスクロール挙動・慣性は未検証。
6. **状態の保持/復元**：スイッチを切り、頁を出て戻った際の状態維持/初期化は未検証。
7. **フォント描画忠実度**：ベイク済フォントと設計の差は閾値 25% では甘い。

## 13. 自テストプロセス改訂案

- A. 本契約をオラクルに、シミュレータ冒煙テストを**操作→状態変化**の assert リストに拡張
  （ジェスチャシミュ・命中判定・状態保持を含む）。
- B. ピクセル差閾値を厳しく（例 25%→8%）し、視覚退行を弾く。
- C. 実機専用チェックリスト（BGR 確認 / 真タッチ / 真ジェスチャ）を別途作成し、**実機でしかできない項目はユーザに依頼**。

## 14. UI 制御の実装選定 鉄律（2026-09-30 ユーザー定稿）

> 「后期要求优先输出用EEZ里面控制UI，包括各个控件的联动，仅仅控制外部硬件的允许使用用户代码，如果实在没有办法的话，需要通知我」

- **UI 制御＋ウィジェット連動**（ハイライト / 表示切替 / スタイル / 画面切替 / 連動）→
  **EEZ 優先**：flow チェーン / LVGL 組み込みアクション / 状態スタイル。
- **外部ハード制御**（wifi・オーディオ・RTC 等への命令）のみユーザーコード
  （A 通道 user action / B・C 変数）。
- **EEZ で表現不可能な場合**は実装前にユーザーへ通知（黙って native に逃げない）。
- 判例：レールハイライト追従＝ウィジェット連動 → 純 EEZ flow（native sync_rail 退役、
  intake P-0030 / skills.md §11.17）；`mic_toggle` コマンド＝ハード → user action。
