# P-0023 · DSL 容器创建后未挂载：歌词块整块消失

- **工程**：eez-test (LVGL 9.4 / 800x480)
- **日期**：2026-09-28
- **工具**：WorkBuddy+EEZ Studio 0.29
- **状态**：fixed
- **标签**：build_ui,DSL,容器,挂载,children
- **关联提示词**：PR-0035

## 现象（看到什么）

正在播放屏实机右侧无歌词区，ui.json 里搜不到「飞机飞过天空」等歌词文本；G5 05 屏差异 90.25%

## 复现（怎么稳定重现）

DSL 里创建容器/控件后不 append 进父 children，ui.json 即缺该子树——可对任意 pane 复现。

## 根因（真正的原因）

build_ui.py pane_nowplaying 里 lyr=box(...) 创建并填充 children 后，漏了 right["children"].append(lyr)；hd 是靠后面 insert(0,hd) 挂上的，lyr 没有对应动作

## 修复（做了什么）

补 right["children"].append(lyr)（build_ui.py:1216 实证在位）

## 证据（数字 / 命令输出）

grep ui.json 无「飞」字；修复后 05 屏差异 90.25%→15.45%，歌词五行全部渲染

## 沉淀（新增断言 / 案例 / 文档）

DSL 纪律：**创建即挂载**——box()/label() 等构造函数不会自动挂进父节点，每个新建节点必须有对应 append/insert；review DSL 改动时用「构造行数 vs append 行数」粗检。关联 B5（嵌套容器二次偏移）同属容器挂载语义族
