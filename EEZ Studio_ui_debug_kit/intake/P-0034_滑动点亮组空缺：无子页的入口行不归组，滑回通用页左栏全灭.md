# P-0034 滑动点亮组空缺：无子页的入口行不归组，滑回通用页左栏全灭

- **状态**：fixed
- **发现日期**：2026-09-30
- **提示词**：PR-0060
- **标签**：高亮跟随, rail_cats, onTabChange, 点亮组, tab=None, pop行, 断言写成规格

---

## 一、现象（用户原话：「wifi 页 tab 有时候没有高亮」）

设置左栏「网络与连接」行的高亮**时有时无**：
首次进设置页亮（初始 `checked`），但从显示/唤醒页**滑回通用页后全灭**，
且在显示/唤醒页点「网络与连接」开浮层时高亮会跳到 wifi（与页面不符）。

## 二、复现

`python design/all.py --shots` 看断言：
`[swipe] sett down: tab=0 cats=000`（修复前）——通用页左栏三行全灭。

## 三、根因

两层问题叠加，第二层最隐蔽：

1. **点亮组空缺**：滑动同步链（§11.9/§11.17）= VALUE_CHANGED → clear 全部可点行
   → GetActiveTab → 按页分组 add。分组代码只收 `switchTab.tab is not None` 的行：
   ```python
   cats_add = [[] for _ in range(3)]
   for _row in cats:
       if _t is not None: cats_add[_t] = [_row]
   ```
   「网络与连接」是 pop 行（tab=None，点它开浮层不切页）→ **不进任何分组**，
   `cats_add[0]` 空组 → json2eez 跳过不建 Compare/Add。滑回通用页：clear 执行了、
   add 无处可去 → 全灭。而初始 `checked` 恰好给了它 → 「有时亮有时灭」。
2. **断言把 bug 写成了规格**：sim.py 的 swipe 断言当时写死
   `(expect 0 / 000)` 并注释「wifi 不参与高亮」——把错误语义固化成验收标准，
   冒烟测试永远绿，直到用户肉眼发现。

## 四、修复

`design/build_ui.py`：

```python
# tab=None 的 pop 行归入通用页（tab 0）点亮组 —— 每页都必须有归属高亮
for _row in cats:
    _t = _row["switchTab"]["tab"]
    if _t is not None: cats_add[_t] = [_row]
    else:              cats_add[0] = [_row]
```

`design/build_ui.py::rail_cats`：pop 行点击**不动高亮**（switchTab 不挂 clear/add，
json2eez 按 `or []` 生成空动作链，只剩 onShow 开浮层）——高亮跟随页面，
在显示/唤醒页点它开浮层，左栏不该跳蓝。

`design/sim.py`：断言期望 `sett down: 000 → 100`；base 行改 `(info)` 并注明
「前序点击遗留 + set_tv_layer 强切（不发 VALUE_CHANGED）= 测试伪态，真实路径不存在」。

## 五、证据

`all.py --shots` EXIT=0：
```
[swipe] sett up:   tab=1 cats=010 (expect 1 / 010)  ✓
[swipe] sett down: tab=0 cats=100 (expect 0 / 100)  ✓（修复前 000）
[ok] 09_wifi_popup（pop 行点击开浮层流程不受影响）
```
对照 11 屏平均 8.62% 无缺屏。

## 六、沉淀

- `skills.md §11.19` 补「点亮组完备性」：**每个 tab 的点亮组都不能留空**——
  无子页的入口行（pop）必须显式归入它语义上归属的页；点击入口行≠切页，不动高亮。
- 方法论：**断言期望值来自设计推导，不是把现状打印出来抄一遍**——
  「expect 0/000」就是把 bug 固化成规格。
